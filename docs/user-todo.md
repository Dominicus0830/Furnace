# 확정 버그 (사용자 접속 시험 2026-10-31, 수정 작업 진행)
통과 확인: T4 걸어 오르기·주민 직업/종/발광(T3), 워든(T6), 스컬크(T8), NBT·소환(T7), 넉백·화살, 토템·마법 부여, 겉날개, 피스톤(플레이어도 밀림), 시작 스크립트·fat jar.

**U1~U7 처리 결과 (2026-11-01 병합):**
- **U1 폭죽 자해**: 원인 확인·수정(폭죽 소유자 미전달, 겉날개 폭죽 이중 피해도 수정). 단, 폭발 5칸 안은 바닐라도 소유자 포함 피해를 받으므로 짧게 나는 폭죽은 주민에게 약한 피해를 줄 수 있다(즉사 수준의 몸통 폭발만 사라짐).
- **U2 파괴수**: 나뭇잎 파괴 코드는 이미 바닐라와 같았고 시험으로 부서짐을 확인. "안 부순다"는 서버 코드상 재현 안 됨 — **다시 보시면 어떤 블록 앞이었는지 알려 주세요**(경로가 나뭇잎 앞에서 멈추는 경우일 수 있음). 대신 빠져 있던 방패 막힘(기절·밀치기)을 구현.
- **U3 주민 문**: 코드와 바닐라가 줄 단위로 같음(20틱 쿨다운, 문에서 3칸보다 멀면 닫지 않음, 울타리 문은 바닐라도 안 엶). 안 열리는 상황이면 주민에게 `/data get entity @e[type=villager,limit=1,sort=nearest] Brain.memories` 결과를 알려 주세요.
- **U4 말**: 재탑승 쿨다운 60틱(3초)과 말 능력치·교배 공식이 바닐라와 같음. 3초보다 오래 안 타지면 **Shift 를 완전히 뗀 뒤 3초 후 우클릭**해 보시고, 그래도 안 되면 알려 주세요(웅크림 입력이 서버에 남는 레이스가 추정 원인, 재현 못 함).
- **U5 방어구 표시**: 원인(플레이어 방어 속성을 클라이언트로 보내지 않음) 수정.
- **U6 좀비 연타**: 바닐라에도 있는 동작(목표 재시작 시 공격 대기가 0 으로 비워짐)으로 결론, 코드 안 건드림.
- **U7 몹 능력 점검**: `docs/feature-parity/mob-ability-audit-2026-10-31.md`. 상위 항목은 이후 라운드에서 대부분 구현.

# 바닐라와 같은 동작으로 확인됨 (버그 아님, 2026-10-28 디컴파일 조사)
- 벌이 한 번 쏘고 다시 안 쏨: 바닐라도 쏘면 침을 잃고(`hasStung`) 다시 화나도 공격하지 않음. 쏜 뒤 시간이 지나면 죽음.
- 앉은(퍼치) 드래곤이 화살을 불붙여 튕겨 냄: 바닐라 동작(피해 0, 화살에 1초 불). 튕김의 회전 난수·아이템 드롭은 Furnace 가 달라서 수정 중.
- 활로 맞춘 드래곤이 살짝 멈칫: 바닐라도 넉백(0.4)이 적용됨. 넉백 방향 계산·난수가 Furnace 와 달라서 수정 중.
- 폭발 무적 시간: 바닐라와 같음(한 폭발은 파트 중 가장 큰 피해 하나로 수렴).
- 부활 드래곤 처치 때 알이 안 생김: 바닐라도 첫 처치 때만 생김.
