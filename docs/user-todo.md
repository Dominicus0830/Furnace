# 사용자 결정 필요
- **RCON IP당 연결 상한 4:** 같은 기계에서 패널·봇 등 RCON 도구를 4개보다 많이 동시에 쓰신다면 알려 주세요(상한 조정). RCON 은 평문 프로토콜이라 공개 포트에 열지 말고 방화벽/loopback 권장. 인증 실패 제한(연결당 5회, IP당 60초 10회)과 연결 상한 16 때문에 NAT 뒤에서는 정당한 관리자도 막힐 수 있습니다.
- **BungeeCord 레거시 포워딩(2026-11-03 구현, 기본 꺼짐):** 사용자가 지원을 결정한 항목이 아니라 Paper·Spigot 대비 미구현 목록에서 고른 후보라 `bungeecord=false` 가 기본입니다. 레거시 포워딩은 서명이 없어 서버 포트가 열려 있으면 누구나 아무 UUID 로 들어올 수 있습니다 — 켤 때는 방화벽으로 프록시만 접속하게 하세요. 새 프록시는 Velocity 모던 포워딩(`velocity-secret`)을 권합니다. 두 설정은 함께 켤 수 없습니다(기동 실패).
- **`/tps` 의 "서버 TPS" 정의:** Furnace 는 region 마다 따로 틱하므로 전역 박동 TPS(Paper 와 같은 창)와 차원별 가장 느린 region TPS 를 함께 보입니다(`docs/feature-parity/tps-mspt-2026-11-03.md`). 플러그인용 `getTPS()` 를 만들 때 어느 값을 돌려줄지 정해 주세요(제안: 전역 박동 값).
- **`spawn-animals=false` / `spawn-npcs=false`:** 이제 바닐라처럼 이미 있는 동물·주민도 지웁니다(이전에는 자연 스폰만 막았음). 이 옵션으로 운영 중이라면 첫 기동 때 기존 동물이 사라집니다.
- **lz4 지역 파일 압축:** 읽기·쓰기 구현(2026-11-03), 형식은 바닐라 바이트코드와 대조해 같음(2026-11-06). 바닐라 lz4 월드를 한 번 열어 봐 주시면 끝입니다(위 표 "외부 프로그램").
- **Paper/Spigot 월드 가져오기 (2026-11-03):** 첫 기동 때 `world_nether/DIM-1`·`world_the_end/DIM1` 을 `world/` 안으로 **복사**합니다(원본 보존). 네더·엔드 크기만큼 디스크가 더 필요하고, 확인 뒤 원본은 직접 지우세요. Bukkit 월드별 게임 규칙·날씨는 가져오지 않고 주 `world/level.dat` 값을 씁니다. 상세: `docs/feature-parity/bukkit-world-import-2026-11-03.md`

## 생성 청크 저장(F-14)
- 생성만 한 청크도 바닐라처럼 디스크에 남는다 — 탐험한 만큼 월드 폴더가 커진다(크기 제한 없음). 디스크 여유 확인
