## 다차원 호스팅 — 네더·엔드 (이식 완료, 실접속 미확인, 중요)
실제 클라이언트로 확인할 시나리오:
1. 오버월드에서 네더 포탈 점화 → 4초 뒤 네더 도착, 1/8 좌표에 포탈 생성, 로딩 화면 정상 종료
2. 같은 문으로 돌아올 때 기존 오버월드 포탈로 오는지(새로 만들지 않는지)
3. 엔드 포탈 → 단상 도착, 드래곤 보스바·드래곤 생성
4. 출구 포탈 → 크레딧 → 오버월드 리스폰, 인벤토리·경험치 유지
5. 네더에서 죽으면 오버월드 리스폰
6. 네더에서 재접속하면 네더로 들어오는지, 비 오는 날 네더에 비가 안 보이는지
7. 다른 플레이어가 차원 오갈 때 탭 목록 유지·엔티티 사라졌다 나타남
8. 서버 재시작 후 `DIM-1`, `DIM1` 청크·드래곤 전투 상태 유지
- 알려진 차이: 차원 이동이 비동기라 몇 틱 늦게 도착, 보더 차원 공유, 침대·리스폰 정박기 없음(리스폰 차원은 오버월드 고정), 네더 포탈에서 좀비 피글린 미구현
- 결정 필요: 차원마다 region 스레드 풀을 따로 둠(쉬는 차원은 거의 비용 없음). 하나로 공유하는 구조는 측정 후 최적화 후보
