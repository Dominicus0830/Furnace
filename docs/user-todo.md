# 공유 스케줄러 S4 (병합됨, 기본 꺼짐)

# 바닐라와 같은 동작으로 확인됨 (버그 아님, 2026-10-28 디컴파일 조사)
- 벌이 한 번 쏘고 다시 안 쏨: 바닐라도 쏘면 침을 잃고(`hasStung`) 다시 화나도 공격하지 않음. 쏜 뒤 시간이 지나면 죽음.
- 앉은(퍼치) 드래곤이 화살을 불붙여 튕겨 냄: 바닐라 동작(피해 0, 화살에 1초 불). 튕김의 회전 난수·아이템 드롭은 Furnace 가 달라서 수정 중.
- 활로 맞춘 드래곤이 살짝 멈칫: 바닐라도 넉백(0.4)이 적용됨. 넉백 방향 계산·난수가 Furnace 와 달라서 수정 중.
- 폭발 무적 시간: 바닐라와 같음(한 폭발은 파트 중 가장 큰 피해 하나로 수렴).
- 부활 드래곤 처치 때 알이 안 생김: 바닐라도 첫 처치 때만 생김.

# 결정 기록
- `sync-chunk-writes` 기본값: **false** 로 바꿈(2026-10-28 사용자 결정). 전원 차단·OS 크래시 때 청크가 손상될 위험은 감수. `server.properties` 에 `sync-chunk-writes=true` 로 켤 수 있음.
- 공유 스케줄러 S4: 프로젝트 방향(처리량·멀티스레드)에 맞으면 진행. 기본값은 측정에서 현행보다 나빠지지 않는 것이 확인될 때까지 꺼 둠, 롤백 스위치 유지.
- Mojang jar 히스토리 정리·오래된 커밋 trailer 정리: 프로젝트가 거의 끝날 때 사용자가 지시. 지금은 하지 않음.
- 생성 청크 저장(F-14): 바닐라처럼 저장(확정).
- **아직 결정 안 된 것 — CI**: `.github/workflows/ci.yml` 은 기본 ubuntu-latest 러너·push/PR 전체 트리거로 만들어 둠. 러너 종류(자체 호스팅 여부), 브랜치 제한, 캐시 정책, 바닐라 jar 추출(3-1)용 외부 접근 허용 여부를 정해 주세요. 시작 스크립트(`start.sh`/`start.bat`)는 실제 기동을 확인하지 못함.
