# 동작 보증 목록

이 문서는 Furnace 가 **바닐라 1.21.1 과 같은 관측 결과**를 보장한다고 말할 수 있는 항목과, 아직 보장하지 못하는 항목을 나눠 적는다. 기술 플레이어와 플러그인 개발자가 "Furnace 가 바닐라와 같은가"를 판단할 근거다.

근거: `docs/feature-parity/` 의 바닐라 차이 점검과 봇 시험 문서들. 불만 표 101번(차이 회귀 시험 공개).

## 1. 읽는 법

- **보증**: 봇 시험 또는 바이트코드 대조로 같은 결과를 확인한 항목. 회귀 시험이 있거나 시험 문서가 있다.
- **목표**: 구현하거나 설계상 같게 만들었지만 아직 전 범위를 확인하지 못한 항목.
- **제외**: 바닐라와 결과가 다르다고 알려진 항목. 이유와 기본값을 함께 적는다.

보증 상태는 이 문서에서만 올린다. 상태를 올릴 때는 근거 문서나 시험 이름을 같이 적는다.

## 2. 현재 목록

### 2.1 보증

아직 보증으로 올린 항목은 없다. 시험 문서를 항목별로 다시 확인한 뒤 이 표에 올린다.

| 영역 | 내용 | 근거 |
|---|---|---|

### 2.2 목표 (근거 문서가 있지만 보증 확인 전)

| 영역 | 내용 | 근거 후보 |
|---|---|---|
| 접속 | 로그인·이름 확인·스폰 위치 기본 흐름 | 봇 접속 시험 문서 |
| 이동·청크 | 플레이어 이동, 청크 로드·저장 결과 | 청크 입출력 점검 문서 |
| 월드 가져오기 | Paper/Spigot 월드 폴더 복사 후 같은 지형 | 월드 가져오기 메모 |
| 몹 AI·전투 | 기본 몹의 목표 선택과 피해 계산 순서 | 차이 점검 문서 |
| 아이템 | 컴포넌트가 붙은 아이템의 표시와 상호작용 | 차이 점검 문서 |
| 레지스트리 | 블록·아이템 등록 값과 바닐라 ID 대조 | 차이 점검 문서 |
| 명령·채팅 | 기본 명령의 출력 문구 | 차이 점검 문서 |

### 2.3 제외 (바닐라와 다름)

| 항목 | 이유 | 기본값 |
|---|---|---|
| 채팅 신고 끄기 옵션 | 운영자가 서명 채팅을 시스템 메시지로 바꾸는 옵션 | 꺼짐 |
| 운영 편의 옵션 전반 | 바닐라 결과를 바꾸는 옵션은 모두 기본 꺼짐 | 꺼짐 |

게임플레이를 바꾸는 옵션(활성 범위·엔티티 제한 등)은 넣지 않는다. 넣게 되면 이 목록의 제외 항목에 먼저 적는다.

## 3. 클라이언트 한계

서버가 보내는 값이 같아도 클라이언트 표시가 다를 수 있다. 1.21.1 클라이언트에 없는 기능(예: 1.21.2 이후 장비 컴포넌트, 위치 표시줄)은 Furnace 가 할 수 없다. 이런 항목은 보증 목록에 올리지 않는다.

## 4. 갱신

- 시험을 새로 추가하거나 바닐라 차이를 발견하면 이 문서를 같은 PR 에서 고친다.
- 마인크래프트 버전을 올릴 때는 2장 전체를 다시 검토하고, 버전마다 보증 상태가 바뀔 수 있다는 점을 적는다.
