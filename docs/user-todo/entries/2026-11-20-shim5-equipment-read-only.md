# 플레이어 장비 칸을 읽는 플러그인에게 "읽기 전용 사본"을 준다 (2026-11-20, NMS shim 5a-2)

**추천대로 적용함. 급하지 않음.**

## 무엇
voxy 같은 플러그인이 서버 내부 이름으로 "이 플레이어가 머리에 쓴 것·손에 든 것"을 읽는다(`getItemBySlot`). 바닐라·Paper 는 그 칸에 든 아이템 객체
자체를 준다. 그래서 플러그인이 그 객체의 개수를 줄이면 플레이어 인벤토리도 바로 줄어든다.

Furnace 에서 그 칸은 플레이어를 맡은 스레드가 들고 있어서 같은 객체를 줄 수 없다. 그래서 지금 칸의 **사본**을 주되, 사본을 고치려고 하면
"읽기 전용이다, copy() 하거나 Bukkit 인벤토리로 바꿔라"는 오류를 낸다.

예) voxy 가 먼 플레이어의 갑옷을 그리려고 머리 칸을 읽는다 → 다이아몬드 투구가 보인다(문제 없음).
예) 어떤 플러그인이 손에 든 돌의 개수를 `shrink(1)` 로 줄인다 → Paper 는 인벤토리에서 하나가 빠진다. Furnace 는 오류가 나고 아무것도 바뀌지 않는다.

## 안 하면 어떻게 되나
- 사본을 주면서 막지 않으면: 플러그인은 줄였다고 믿는데 인벤토리는 그대로다(조용히 다른 결과 — 찾기 어려운 버그).
- 아예 안 주면: voxy 의 먼 플레이어 모습 기능이 오류로 멈춘다.

## 다른 길
- 고치면 칸에 되쓰는 "살아 있는 사본": 쓰기마다 플레이어 스레드로 넘기는 장치가 필요하고, 쓰는 플러그인 표본이 아직 없다. 표본이 나오면 그때 설계.
