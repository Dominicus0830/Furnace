# T-204 FAWE 블록 쓰기 부수 효과 — 위임 결정 기록 (2026-11-16)

근거: `docs/feature-parity/compat-nms-t204-side-effects-design-2026-11-16.md`

## 결정됨(코디네이터 위임 범위, 바꾸고 싶으면 알려 주면 된다)

**청크 "틱 단계"(getFullStatus)를 바닐라 값으로 알려 준다**
- 쉬운 말: 플러그인이 "이 청크가 지금 돌아가고 있나?"를 물을 때 Furnace 는 바닐라 규칙(시야 거리 안이면 '엔티티까지 돈다')으로 답한다. Paper 는 시뮬레이션 거리 기준으로 답해서 시야 거리가 시뮬레이션 거리보다 크면 답이 다르다.
- 예: 시야 10·시뮬레이션 6 에서 플레이어로부터 8청크 떨어진 곳. Paper 는 "그냥 올라와만 있음", Furnace 는 "엔티티까지 돈다"(바닐라도 그렇게 답한다).
- 보이는 차이: FAWE 가 한 칸씩 블록을 바꿀 때(다른 플러그인이 WorldEdit API 로 놓을 때 등) 그 거리의 블록 변경을 Furnace 는 접속자에게 바로 보내고, Paper 는 보내지 않아 다시 접속할 때까지 옛 블록이 보인다. 월드에 남는 결과(블록·틱)는 같다.
- 안 하면(Paper 값을 따라가면): 서버가 실제로 돌리는 것(바닐라 규칙)과 플러그인에게 말하는 것이 달라진다.
- 추천: 바닐라 값(적용함).
