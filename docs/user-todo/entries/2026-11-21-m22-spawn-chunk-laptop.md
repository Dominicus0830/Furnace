# M-22 스폰 청크: 결정이 필요한 것

## 1. 스폰 청크 규칙 기본값을 0 으로 바꿀까요? (추천: 지금은 바꾸지 않기)
- 쉬운 설명: "스폰 청크"는 월드 스폰 근처 49칸을 사람이 없어도 계속 켜 두는 바닐라 기능입니다. 끄면(규칙 0) 빈 서버가 훨씬 한가해집니다.
- 측정(노트북): 사람이 없을 때 CPU가 0.23코어 대 0.025코어, 메모리 약 100MB 차이. 사람이 걷는 동안은 차이가 있어 보이나 크기가 들쭉날쭉했습니다. 플레이어가 받는 청크는 같았습니다.
- 예시: 접속자가 거의 없는 서버를 여러 개 한 PC에 띄우면 끄는 쪽이 이득입니다.
- 안 하면: 바닐라와 똑같이 동작하고 빈 서버가 조금 더 바쁩니다. 대신 스폰 근처 레드스톤·농장이 사람 없이도 도는 바닐라 동작을 유지합니다.
- 추천: 기본값은 바닐라와 같게 두고, 끄고 싶은 사람이 게임 규칙으로 직접 끄게 안내만 합니다.

## 2. 직접 확인(선택)
- 노트북 측정만 했고 표본이 3판입니다. 다른 PC 값이 필요하면 도미니코가 그 PC를 쓰지 않을 때 알려 주세요. 이번 측정은 데스크탑에서 하지 않았습니다.
