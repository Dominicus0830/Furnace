# 2차 CSP B6(플러그인 API·호환) 결정 (2026-11-14)

보고서: 공유 폴더 `furnace/reviews/opt-review-r2/B6-api-compat.md`. 인기 플러그인 18개 소스를 훑으니 어댑터에 없는 Bukkit API 클래스가 737개였고(플러그인마다 import 의 25~66%), FAWE 는 NMS 어댑터가 없어 블록을 못 고친다. 이벤트 처리 속도는 1차에서 5배 빨라져 이제 이벤트당 약 5µs 다.

1. **호환 쪽에서 API 표면 확장(T-141: 엔티티 인터페이스·블록 상태·ItemMeta 하위·점수판 등을 물결로)을 2차 최적화 TASK 보다 먼저 할지.** 플러그인이 `NoClassDefFoundError` 로 안 켜지거나 리스너째 떨어지는 것이 속도보다 크다. 예외로 작은 것 셋(T-140 블록 읽기 빠른 길, T-034 접속, T-035 채팅)은 함께 간다. 추천: 예.
2. **일반 NMS 어댑터 N1+N2a 를 언제 열지.** FAWE 가 쓰는 NMS 기호 664개 중 330개가 없다. 추천: T-141 1물결과 나란히 지금 연다(파일이 안 겹침). FAWE 가 자기 스레드에서 구역을 직접 쓰는 N2b 는 region 소유권과 부딪히므로 설계 문서를 먼저 쓴다.
3. **(선택) paper-api 1.21.1 jar 를 공유 폴더(`/mnt/project-files/uploads/`)에 올려 줄지.** 클라우드 컨테이너는 papermc 에 못 닿아 1.21.1 의 정확한 클래스·메서드 목록을 못 뽑는다. 없으면 플러그인 소스에서 1.21.9 이후 이름(구리 골렘 등)을 손으로 걸러 "가정"으로 적는다. 추천: 올려 주시면 좋음.
