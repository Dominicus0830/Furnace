## 알아 둘 것 (결정 아님)
- 설계 원칙: 바닐라에 있는 후처리(빛·하이트맵·저장 표시·클라이언트 알림)는 바닐라처럼 플러그인 몫으로 두고, Furnace 에만 있는 캐시는 Furnace 가 책임진다.
- FAWE 로 실제 편집이 되려면 N2b 외에 N3a(청크 보내기·ChunkMap)와 FAWE 어댑터 초기화 기호(`SharedConstants`·`DataComponentPatch` 등)가 더 필요하다. 마지막 단계(N2b-6)에서 **테스트 노트북에 Paper 1.21.1 + FAWE 2.16.2 와 Furnace + FAWE 2.16.2 를 같은 월드로 띄워 같은 명령 결과를 비교**할 예정이다 — 그때 Paper jar 준비가 필요하다(이 클라우드에서는 papermc 에 못 닿고, Paper 저장소에도 1.21.1 소스 ref 가 없다).
