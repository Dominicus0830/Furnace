# FastAsyncWorldEdit 올리기 1단계 — 2026-11-11

설명: `docs/feature-parity/compat-fawe-2026-11-11.md`.

## 결정할 것

- **FAWE 편집용 어댑터를 어떻게 할까?** FAWE 는 블록을 바꾸는 모든 명령을 버전 어댑터(NMS)로 한다. 추천은 A — Furnace 가 FAWE 용 어댑터를 직접 만들어 FAWE 가 실릴 때 붙인다. B(NMS shim 확장)는 청크 구조가 달라 정확하게 못 만들고, C 는 켜지기만 하고 편집은 안 된다.

## 직접 확인하면 좋은 것

- 실제 `FastAsyncWorldEdit-Paper-2.16.2.jar` 로 서버를 켜서 "You are attempting to run the Paper FAWE jar on a Spigot server" 와 "PlayerInteractEvent does not exist" 가 사라졌는지, 다음에 어떤 오류가 나는지(로그를 스레드에 붙여 주면 이어서 고친다). 컨테이너에서는 Central 판으로만 쟀다.
- 나무 도끼(`//wand`)로 블록을 좌·우클릭할 때 선택 메시지가 나오는지(어댑터 없이도 선택은 Bukkit 이벤트로 된다).
