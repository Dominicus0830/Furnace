# 클라이언트 청크 로딩 속도 — 2026-11-11

설명: `docs/audit/chunk-loading-diagnosis.md`.

## 직접 확인하면 좋은 것

- 실제 클라이언트로 새 빌드에 접속해, 이미 가 본 곳(재접속)과 처음 가는 곳에서 청크가 차오르는 속도가 전보다 빨라졌는지. 컨테이너에서는 바닐라 클라이언트의 속도 계산을 흉내 낸 봇으로 쟀다(시야 10: 22초 → 약 10초).
- 겉날개·순간이동으로 빨리 움직일 때 발밑·앞쪽에 빈 청크(구멍)가 보이는지.
- 원격 서버(같은 기기가 아닌)로 접속했을 때도 같은지 — 수정 전에는 한 청크마다 왕복 시간이 끼어 원격일수록 더 느렸다.
- 확인할 때 서버를 `-Dfurnace.chunktrace=true` 로 켜면 로그에 `[CHUNKTRACE]` 가 5초마다 찍힌다. 느리면 그 줄(특히 `client.want`·`batch`)을 붙여 주면 된다.
