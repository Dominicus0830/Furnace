# 이동·텔레포트 정합 (movement) — 2026-11-08

`PlayerMoveEvent` 간격(시선만 돌려도 발화, 작은 떨림 무시)과 `Entity#teleport` 의 진짜 반환값을 Paper 1.21.1 대로 맞췄다. 자세한 구조: `docs/feature-parity/context-notes/2026-11-08-movement.md`.

- **결정(작음):** 엔티티를 다른 region·다른 차원으로 `teleport()` 하는 경우가 지금은 `false` 다(이전에는 Bukkit 어댑터가 거짓으로 `true`). Paper 는 어디로든 옮기고 `true` 를 돌려준다. 후보: ① 지금처럼 `false`(안전, 먼 곳 텔레포트를 쓰는 플러그인은 실패로 보임), ② 이후 묶음에서 region 핸드오프·차원 이동을 구현(추천 — 비동기 스케줄러 정리와 함께). 답이 없으면 ① 그대로 두고 ② 는 후속 작업 후보로 둔다.
- **직접 확인(클라이언트):** 시선 감지·AFK 플러그인에서 가만히 서서 시점만 크게 돌렸을 때 이동 이벤트가 오는지, 마우스를 아주 조금 흔들 때는 안 오는지.
