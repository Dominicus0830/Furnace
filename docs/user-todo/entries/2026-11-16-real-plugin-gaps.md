## 결정
**T-204(FAWE 블록 쓰기 부수 효과 묶음)를 지금 시작할까?**
- 쉬운 말: FAWE 가 블록을 한 칸씩 놓거나 "이웃 갱신·물 흐름"을 켜고 편집할 때 쓰는 길이 Furnace 에는 아직 없다. 일반 `//set`·`//paste` 는 이미 잘 되고, 이 길은 다른 플러그인이 WorldEdit API 로 블록을 놓을 때와 물·레드스톤 편집에서 쓰인다.
- 안 하면: 그런 편집은 `UnsupportedNmsCall` 로 그 호출만 실패한다(서버는 계속 돈다). 일반 편집은 영향 없음.
- 추천: **T-198(블록 엔티티)·T-197(빛) 뒤에 시작**. 셋이 같은 청크 거울 일지를 쓰므로 한꺼번에 설계하는 편이 안전하다.
