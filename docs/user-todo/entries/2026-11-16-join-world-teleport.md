# 조인 이벤트에서 다른 월드로 텔레포트 — 직접 확인 (2026-11-16)

기록: `docs/feature-parity/context-notes/2026-11-16-join-world-teleport.md`. 결정할 것은 없고, 실제 클라이언트로 한 번 보면 좋은 것만 있다.

| # | 확인할 것 | 상태 | 방법 |
|---|---|---|---|
| JW1 | 접속하자마자 플러그인이 네더(또는 다른 월드)로 보낼 때 실제 마인크래프트 클라이언트 화면이 멈추거나 "지형 불러오는 중"에 걸리지 않는가 | 대기 | 로비·스폰 플러그인(예: 접속 시 스폰 월드로 보내는 것) 또는 `tools/bot-test/round-jtp/probe` 시험 플러그인을 넣고 이름이 `Neth` 로 시작하는 계정으로 접속. 봇 시험(mineflayer)은 통과했다 |
| JW2 | 접속 뒤 다른 월드로 보낼 때 체력·배고픔·경험치·효과 아이콘이 그대로 보이는가 | 대기 | 위 플러그인에서 `Late` 로 시작하는 이름(2초 뒤 네더로). Paper 처럼 리스폰이 "속성만 유지"라 나머지는 서버가 다시 보낸다 |

안 하면: 봇이 못 보는 화면 표시(불러오기 화면·HUD) 문제가 있어도 플러그인을 쓰는 사람이 처음 알게 된다.
