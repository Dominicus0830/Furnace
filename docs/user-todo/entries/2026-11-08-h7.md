# NMS 호환 변환·값 shim (H7) — 2026-11-08

서버 쪽은 시험으로 확인했다(시험 안에서 컴파일한 NMS 플러그인 jar 를 헤드리스 서버에 올림). 설계·한계: `docs/feature-parity/compat-h7-2026-11-08.md`. 직접 확인·결정할 것:

- **결정(H7d, Spigot 이름 변환표):** Spigot 이름으로 컴파일된 NMS 플러그인(매니페스트에 `paperweight-mappings-namespace` 가 없는 jar 대부분)을 돌리려면 Spigot→Mojang 이름표가 필요합니다. 표의 출처(Mojang 공식 매핑 + Spigot BuildTools 매핑)는 이 컨테이너에서 받을 수 없고(우회하지 않습니다), 서버에 실어 배포해도 되는지 라이선스 판단도 필요합니다. ① 서버 첫 실행 때 사용자 컴퓨터에서 받아 만들기(Paper 와 같은 방식, 추천) ② 하지 않기(Mojang 이름 jar 만 지원) 중 골라 주세요. 답이 없으면 ②로 두고 로드 보고에 "Spigot 이름이라 그 호출은 실패한다" 를 계속 알립니다.
- **결정(새 옵션 기본값):** `plugins.compat.nms.strict=false`(미지원 NMS 심볼이 있어도 불러오고 그 호출만 실패), `plugins.compat.nms.version-package=plain`(Paper 처럼 접미사 없는 CraftBukkit 이름을 알림). 바꾸고 싶으시면 알려 주세요. 답이 없으면 그대로 둡니다.
- **직접 확인(실제 플러그인, 권장):** NMS 를 쓰는 실제 플러그인 jar 를 `plugins/` 에 넣고 켜면 로그 맨 앞에 `플러그인 X: NMS·CraftBukkit 심볼 N개 중 shim 있음 …` 한 줄과 미지원 목록이 나옵니다. 그 두 줄을 프로젝트 파일 `furnace/real-plugins/` 에 올려 주시면 다음 shim 순서를 거기에 맞춥니다.
- **직접 확인(Paper 원문 대조, 기억 기준):** ① Paper 1.21.1 `ServerCommonPacketListenerImpl#send(null)` 이 무엇을 하는지(여기서는 아무것도 보내지 않음), ② `ClientboundSetEntityMotionPacket` 읽기 메서드 이름이 `getXa()` 이고 1/8000 값을 돌려주는지. 답이 없으면 지금처럼 둡니다.
