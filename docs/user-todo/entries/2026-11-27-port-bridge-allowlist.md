**한 줄:** 호환 계층이 서버 기능을 부르는 새 다리(이식 다리, `docs/roadmap/port-bridge-2026-11-27.md`)는 서버 쪽 코드를 **생성**한다. 그 생성 코드가 `api.internal` 을 쓰려면 어댑터 경계 허용 목록에 올라가야 하는데, 지금 규칙은 "클래스 이름으로 하나씩, 이유를 적고 독립 검토, 목록은 줄어들기만"이다. 생성 패키지를 **접두 한 줄**로 넣는 것은 이 규칙의 변경이라 도미니코 결정이 필요하다(설계 검토 필수 9번).

**무엇이 바뀌나 (예):** 블록 영역이 이식 줄 100개를 더하면 서버에 `BlockPortImpl` 같은 생성 클래스가 생긴다. 접두 줄이 있으면 목록을 고치지 않고 들어간다. 없으면 영역 파일이 생길 때마다 목록 줄과 그 검토가 붙는다.
