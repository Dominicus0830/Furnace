# Axiom 엔티티 놓기·NBT 파일 읽기 후속(5e-3b 검토 권고 4개): 바뀐 점 (2026-11-23)

급하지 않다. 모두 추천대로 적용돼 있다. 다르게 원하면 알려 주면 된다. 근거는 `docs/feature-parity/compat-nms-batch5-axiom-voxy-2026-11-20.md` 의 "5e-3b 후속" 절.

| # | 무엇이 바뀌었나 | 예시 | 안 고치면 어떻게 되나 | 추천 |
|---|---|---|---|---|
| ① | 엔티티 묶음을 넣기 전, 같은 UUID 가 **다른 구역(스레드)** 에 있어도 Paper 처럼 "겹침"(거짓)으로 답한다. 전에는 그 경우만 예외가 났다. | Axiom 으로 붙여넣는 좀비의 UUID 가 멀리 떨어진 곳의 살아 있는 좀비와 같다. | 붙여넣기가 예외로 끝난다(Paper 는 조용히 거절). | 고침(적용됨) |
| ② | 서버가 UUID 겹침으로 거절하면 **거짓**, 스폰 이벤트 취소는 Paper 처럼 **참**으로 구분해 알린다. 전에는 둘 다 "참인데 아무것도 안 들어감". | 검사와 넣기 사이에 다른 구역이 같은 UUID 를 쥐었다. | 플러그인이 "넣었다"고 믿고 없는 엔티티를 다룬다. | 고침(적용됨) |
| ③ | 승객의 저장 위치(`Pos`)가 탈것에서 멀어도, 넣기 전에 승객을 **탈것 자리에 놓는다**. 바닐라는 첫 틱에 탈것이 놓는다. | 저장 파일의 승객 좌표가 5000칸 밖이다. | 승객이 다른 구역에 들어가 탈것과 갈라진다. | 고침(적용됨). 바닐라와 다른 점: 바닐라는 한 틱 동안 먼 칸에 등록돼 있다가 옮겨진다 |
| ④ | `NbtIo` 의 파일 경로판 4개(`read(Path)`, `write(nbt, Path)`, `readCompressed(Path, 한도)`, `writeCompressed(nbt, Path)`)를 넣었다(바닐라 바이트코드대로 열기 옵션·없는 파일 null). 방문자 읽기(`parse`·`parseCompressed`)는 아직 없다. | 플러그인이 `NbtIo.read(Path.of("level.dat"))`. | 그것을 부르는 플러그인이 링크 오류. | 고침(적용됨) |

권고 4(승객이 따로 가진 스폰 이유가 뿌리 것으로 바뀜)는 작은 차이라 그대로 두었다. 이유: 서버가 묶음 전체에 한 이유만 받는다. 바꾸려면 묶음 넣기 API 를 엔티티별 이유로 넓혀야 하는데 쓰는 곳이 없다.
