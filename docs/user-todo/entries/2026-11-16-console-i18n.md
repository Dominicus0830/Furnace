# 콘솔 Paper화 + 언어 설정: 확인 항목 (2026-11-16, 도미니코 요청)

계획서: 프로젝트 폴더 `furnace/reviews/console-i18n-plan-2026-11-16.md`. 아래 결정은 모두 **추천대로 적용**했다(고칠 부분이 있으면 말해 주면 된다).

- **L1 언어 고르는 법**: 서버를 돌리는 환경의 언어를 따른다. 순서는 `-Dfurnace.language` → 환경변수 `FURNACE_LANGUAGE` → `furnace.properties` 의 `language` → (`auto`면) JVM 언어(리눅스 `LANG`, 윈도는 지역 설정). 번역이 없는 언어면 영어.
  안 하면: 도커처럼 `LANG` 이 없는 환경은 한국어 서버도 영어로 나온다 → `language=ko` 로 고정하면 된다.
- **L2 영어로 고정하는 줄**: `Done (…)!`, `Loading X v1`, `Starting minecraft server version` 같은 바닐라·Paper 문구와 `[Backup]` 같은 말머리는 한국어 환경에서도 영어. 호스팅 패널·플러그인이 이 글자를 읽기 때문이다.
- **L3 엔티티 경고**: "엔티티 활성 범위가 켜져 있다"·"Paper 방식 엔티티 기본값" 두 줄을 WARN 에서 짧은 INFO 한 줄로 낮췄다(바닐라와 다르다는 사실은 그대로 알린다).
- **L4 yggdrasil 키 실패**: 인터넷이 없는 서버에서 스택 25줄 대신 한 줄 WARN(원인 + 할 일). 스택은 DEBUG. (Paper 는 스택을 그대로 찍는다 — 다른 점)
- **L5 종료 줄**: `Stopping server` → 플러그인 `Disabling` → `Saving players` → `Saving worlds` → `All dimensions are saved` (Paper 순서). 저장 실패 줄은 실패가 있을 때만. Paper 의 `ThreadedAnvilChunkStorage` 이름은 쓰지 않는다.

## 말머리가 바뀐 곳 (독립 검토 N2)
`[STOP]`→`[Stop]`, `[BACKUP]`→`[Backup]`, `[PAUSE]`→`[IdlePause]`. tick 밀림 줄은 말머리 없이 문장만 둔다. `[핫 리로드]`→`[HotReload]` 는 플러그인 문구를 옮기는 2번째 PR 에서 바꾼다. `[GEN]`·`[SCHED]` 줄은 DEBUG 와 `Chunk system is using …` 한 줄로 합쳤다. 말머리는 어느 언어에서도 영어다(로그 검색용).

## Windows 한글 깨짐 (독립 검토 N3)
콘솔은 UTF-8 바이트를 그대로 쓴다. 한국어 윈도 `cmd` 의 기본 코드 페이지(CP949)에서는 깨지므로 `start.bat` 에 `chcp 65001` 을 넣었다. start.bat 을 거치지 않고 직접 java 로 켜면 `chcp 65001` 을 먼저 실행하거나 패널·터미널(Windows Terminal·PowerShell 7)을 쓰면 된다.

## Paper 와 다르게 남는 것 (이번 PR 기준)
- 콘솔 `help`·`plugins`·`tps` 출력 모양은 Furnace 식(Paper 는 Bukkit 식). 문장 번역은 PR4.
- `Preparing start region for dimension` 은 오버월드만(Paper 는 네더·엔드도).
- `latest.log` 스레드 이름은 `main`·`furnace-global` 등(Paper 는 `Server thread`).
- 퍼센트가 같으면 `Preparing spawn area: n%` 를 반복하지 않는다.

## 2번째 PR(플러그인 로딩·라이브러리·이벤트·메뉴 등 문구) 추가 사항
- `[핫 리로드]` 말머리가 `[HotReload]` 로 바뀐다(어느 언어에서도 영어, 로그 검색용). 플러그인 폴더·라이브러리·스피곳 매핑 안내·이벤트 폐기 경고·명령 이름 충돌 경고는 모두 `-Dfurnace.language`(en/ko)를 따른다. `Loading X v1`·`Enabling X`·`Could not load` 줄은 Paper 문구 그대로 영어다.
- 스피곳 매핑 잠금 파일의 `buildData=수동` 값이 `buildData=manual` 로 적힌다. 예전 값도 그대로 읽는다.
- 시험 JVM 은 `-Dfurnace.language=en` 으로 뜬다(실행 환경 언어에 시험이 흔들리지 않게).

## PR5 (Paper 설정·월드 가져오기 문구)
- `PaperConfigImport` 의 콘솔 줄과 보고서(`paper-import-report.txt` 류)·`BukkitWorldReport` 의 문장을 번역했다. 보고서는 만들 때의 서버 언어로 적힌다(나중에 언어를 바꿔도 이미 만든 보고서는 그대로).
- 월드 이름 규칙 위반은 예외 문구를 읽어 가르지 않고 `WorldCreator.isValidName` 으로 먼저 본다(번역돼도 동작이 같다).

## PR7 (호환 계층 문구)
- Bukkit·Paper 호환 계층(`furnace-compat-paper`)의 운영자 문구(NMS 호환 보고서, 없는 NMS 클래스 요약, paper-plugin.yml 경고, 월드 만들기·나무 심기 경고, 청크 거울 경고 등)도 `-Dfurnace.language`(en/ko)를 따른다. 호환 계층은 서버 클래스(`Lang`)를 볼 수 없어서 `CompatLang` 과 호환 전용 번들(`furnace-compat-lang/{en,ko}.properties`)을 따로 둔다.
- 서버가 고른 언어는 시스템 속성 `furnace.language.active` 로 호환 계층에 알린다(서버가 `Lang` 을 처음 쓸 때·언어를 다시 고를 때 갱신). 속성이 없으면(호환 계층만 따로 시험할 때) 서버와 같은 규칙(속성 → 환경변수 → JVM 로케일 → 영어)으로 고른다. 짝 시험(`CompatLangTest`)이 두 곳의 규칙이 어긋나지 않는지 본다.
- 보고서의 "이름 체계" 값 중 매니페스트가 없을 때의 `Spigot(가정 …)` 는 구조 값(`NmsCompatReport.NAMESPACE_ASSUMED`)으로 두고 문장으로 보일 때만 번역한다.

## 아직 번역하지 않은 것(별도 작업)
- 예외 메시지(`new IllegalStateException("한글…")` 등 약 200개 파일)와 코드 주석·DEBUG 로그 — 운영자 콘솔에 뜨는 줄 중 예외 문구를 그대로 찍는 경우가 있다.
- `UnsupportedNmsCall` 이유 문자열(`NmsGrades.reason` 등)과 shim 의 한글 문구(약 600개).
- 처음 만들어지는 `furnace.properties` 의 한글 주석, `OptionKeys` 설명, `/furnace config` 출력 문장.
