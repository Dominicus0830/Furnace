# 2차 점검 A06 월드젠 바닐라 대조 — 결정 1건, 확인 1건 (2026-11-08)

보고서: `docs/audit/findings/A06-worldgen-parity.md`

## 결정 1. Furnace 월드를 바닐라·Paper 로 옮기는 경우와 데이터 팩 월드젠을 얼마나 급하게 볼까 (A06-01·A06-05)

지금 Furnace 가 만든 구조물은 저장할 때 조각 정보를 바닐라 형식으로 쓰지 않는다. Furnace 안에서는 문제가 없지만, 월드를 바닐라·Paper 로 옮기면 마녀 오두막·네더 요새·해저 신전 같은 **구조물 안 몹 스폰이 영구히 사라진다**. 또 Terralith 같은 **월드젠 데이터 팩은 경고 없이 무시**된다.

| 선택 | 결과 |
|---|---|
| **A. 둘 다 바닐라처럼 고친다, 순서는 다른 높음 항목 뒤 (추천)** | 저장 형식(큼, Opus)과 데이터 팩 월드젠(큼, Opus)을 차례로 한다. 그 전에 데이터 팩 월드젠은 "아직 지원하지 않음" 경고부터 넣는다(작음) |
| B. 저장 형식만 먼저 | 옮기기 호환이 급하면. 데이터 팩 월드젠은 경고만 넣고 미룬다 |
| C. 둘 다 경고만 | 옮겨 갈 계획·월드젠 팩 계획이 없으면. 구조물 스폰 소실 위험은 남는다 |

## 확인 1. 바닐라 실서버 대조를 열지

이번 점검은 바닐라 서버를 돌리지 못해(Mojang 라이브러리 호스트가 막힘, 공개 소스로 빌드해 돌리는 방법은 컨테이너 권한 판정에서 거부) 코드 대 코드 대조까지만 했다. 월드 끝·큰 시드·네더/엔드 구조물 블록을 같은 시드로 실제 대조하려면 바닐라 서버 실행이 필요하다.

- 방법 1: 도미니코 PC 에서 바닐라 1.21.1 서버로 같은 시드 월드를 만들어 `.mca` 를 올려 준다(`tools/parity-audit` 로 대조).
- 방법 2: 클라우드 환경의 네트워크 설정에서 Mojang 라이브러리 호스트를 열어 준다.
