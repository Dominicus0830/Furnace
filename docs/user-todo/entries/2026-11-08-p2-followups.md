# 비동기 스케줄러 후속 (P2 후속) — 2026-11-08
Bukkit 비동기 작업 대기열이 Paper 처럼 전용 관리 스레드에서 돌고, Paper API `getAsyncScheduler()` 도 Paper 모양의 플랫폼 스레드 풀(`Folia Async Scheduler Thread #N`)에서 돌며, 개발 모드 `/plugins reload` 가 끈 플러그인의 비동기 작업을 최대 2.5초 기다립니다. 서버 단위 시험으로 확인했고 직접 확인할 것은 없습니다. 결정할 것도 없습니다(기본값 그대로).

- **알아둘 것:** 개발 모드 리로드 중 비동기 작업이 안 끝나면 그 시간(최대 2.5초)만큼 틱이 멈추고 "Nag author(s)" 로그가 남습니다. 운영 서버(개발 모드 꺼짐)에는 영향이 없습니다.
