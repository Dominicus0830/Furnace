# NMS shim 5번 묶음(VeinMiner 41곳) — 확인 항목

쉬운 말로: VeinMiner 가 부르던 서버 내부 기능 41곳을 채웠습니다. 아래는 Paper 와 다른 점입니다.

1. **허기 소모 이벤트**: Paper 는 플레이어가 허기를 쓸 때 이벤트를 냅니다. 여기선 내지 않습니다. 이 이벤트를 듣는 플러그인은 반응하지 않습니다. 안 하면: VeinMiner 의 허기 소모 설정은 동작하지만 다른 플러그인이 끼어들 수 없음. 추천: 이벤트 다리를 만들 때 같이 처리(급하지 않음).
2. **명령·팩 틀**: 이름과 모양만 있고 실제로 쓰면 "지원 안 함" 오류가 납니다. 안 하면: 해당 기능을 쓰는 플러그인은 그 호출에서 막힘. 추천: 쓰는 플러그인이 나올 때 채움.
3. **인챈트 목록 순서**: Paper 와 순회 순서가 다를 수 있습니다. 추천: 그대로 두고 문제가 보고되면 맞춤.
4. **순간이동 이벤트**: 바닐라 `moveTo` 는 이벤트 없이 자리만 바꾸지만, 월드에 있는 엔티티는 Bukkit 순간이동을 거쳐 이벤트가 납니다. 추천: 그대로(플러그인이 보통 기대).
5. **허기 값 자르기**: 바닐라는 `setFoodLevel` 값을 그대로 넣지만 여기서는 0~20으로 자릅니다. 추천: 그대로.
6. **손 칸 되쓰기**: 칸에 묶인 보기는 값 비교로 되쓰며, 그새 칸이 바뀌면 보기가 떨어져 이후 고쳐도 칸은 안 바뀝니다(바닐라에서 칸에서 빠진 스택과 같음).

## 금 파일 갱신
`scene-compat-asm-prefilter.txt` 의 commandapi-bukkit-plugin 두 줄(default·versioned)의 해시가 바뀌었다. 줄 수·prefilter-hit·changed 는 그대로다. 원인: 이 묶음이 Brigadier 쪽 NMS 명령 인자 클래스·`Style` 이벤트 등을 새로 채워 호환 계층이 다시 쓰는 클래스 내용이 달라졌다(의도한 결과, 호환 계층 면이 넓어진 것).
