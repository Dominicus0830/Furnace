## 모양 증명이 보는 것

- 예: `isBaby()` 의 바닐라 몸통이 "칸 X 를 읽어 Boolean 으로 바꿔 돌려준다"와 **명령 하나까지 같은 꼴**이면 `isBaby()Z -> @idiom(entity-data-get, 칸 X)` 줄을 씁니다. 칸 X 는 바닐라 몸통에서 그대로 뽑습니다.
- **Paper 서버 몸통도 같은 꼴**이어야 합니다. 실제로 Paper 가 이벤트를 더한 쓰기 5개(공기량·자세·화살 수·아이템 엔티티 아이템·앉은 자세)가 여기서 걸러졌습니다.
- 칸에 든 값의 종류(예: 실수 칸)가 메서드 형식(예: float 반환)과 같아야 하고, 제네릭 값(예: `Optional<UUID>`)은 제네릭까지 같아야 합니다.
- 생성기 빌드 검사(이름 규칙·지문·대상 살아 있음)와 껍데기 jar 전부 올리기 시험(연결·초기화 오류 0)을 통과합니다.
