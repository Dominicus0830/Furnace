# T-141 E11 아이템 메타 하위 형 — 도미니코 결정 (2026-11-16)

근거: `docs/feature-parity/context-notes/2026-11-16-t141e11-itemmeta-subtypes.md`. 아래는 Paper 와 같게 구현했거나 추천대로 진행 중이며, 다르게 하고 싶을 때만 답하면 된다.

## 결정
**1. 이름만 있는 머리 아이템에 스킨을 서버가 자동으로 채워 줄까? (PR2)**
- 쉬운 말: 플러그인이 `SkullMeta#setOwningPlayer(오프라인 플레이어)` 로 머리를 만들면 처음엔 스킨 정보가 없다. Paper 는 아이템에 적용하는 순간 Mojang 에 물어 스킨을 비동기로 채워 넣는다(그래서 GUI 머리에 스킨이 보인다).
- 안 하면: 접속 중이지 않은 사람의 머리가 기본 스킨(스티브/알렉스)으로 보인다.
- 추천: **Paper 처럼 채운다**(프록시 뒤 서버 포함, E10 의 조회 기본 플래그 그대로, 조회 스레드 4개 제한). 이미 인벤토리에 들어간 아이템에는 그 칸의 주인 스레드에서 다시 쓴다.

**2. 가죽 방어구의 Paper 형(`ColorableArmorMeta`, 장식 `ArmorMeta` 포함)은 언제?**
- 쉬운 말: 지금은 가죽 방어구가 `LeatherArmorMeta` 만 준다. 장식(trim)을 다루려면 `ArmorTrim`·`TrimMaterial`·`TrimPattern` 이 먼저 필요하다.
- 안 하면: `(ArmorMeta)` 로 캐스트하는 플러그인(방어구 장식 플러그인)이 `ClassCastException`.
- 추천: **E11 뒤 별도 조각(E12)** — 색 쓰기·읽기는 이미 된다.

**3. `ItemFactory#createItemStack(문자열)`·`enchantItem`·`getI18NDisplayName` 은?**
- 쉬운 말: 이 계층에 아이템 문자열 파서·서버 마법 부여·번역표가 없어 `UnsupportedFeature`(이유가 적힌 예외)를 던진다.
- 안 하면: 이 세 가지를 쓰는 플러그인만 해당 기능이 안 된다(서버는 안 멈춘다).
- 추천: **지금은 두고**, 사용 빈도가 확인되면 후속 조각으로.
