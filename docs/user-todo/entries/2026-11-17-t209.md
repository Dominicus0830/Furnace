# 첫 섹션 읽기 가속(T-209) — 알림만 (2026-11-17)

**한 것:** 플러그인(FAWE 등)이 서버 스레드가 아닌 곳에서 청크 블록 자료를 처음 읽을 때 걸리던 시간을 줄였다. FAWE 가 편집 범위를 훑는 꼴로 재면 섹션 하나에
51 µs 걸리던 것이 1.9 µs 가 됐다(섹션 1만 개 편집이면 읽기만 약 0.5 s → 0.02 s). 읽히는 블록 값은 그대로다.

**바로잡은 것:** 이 작업은 "Furnace 가 느려서 FAWE `//fixblocks` 결과가 Paper 보다 자주 갈린다"는 짐작에서 시작했지만, 같은 날 데스크탑 실측에서 갈림은 FAWE 가
여러 스레드로 편집할 때 생기는 FAWE 쪽 문제였고 Paper 가 오히려 더 자주 갈렸다(Paper 10번 중 5번, Furnace 10번 중 1번, FAWE 스레드 1개면 둘 다 0). 그래서 이번
변경의 가치는 속도다.
