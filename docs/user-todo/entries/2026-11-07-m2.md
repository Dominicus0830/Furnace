# 스컬크 촉매와 플레이어 사망 경험치 (M2) — 2026-11-07
바닐라 바이트코드 대조와 서버 시험(`SculkPlayerDeathTest`)·봇(`tools/bot-test/m2`)으로 확인(`docs/feature-parity/m2-sculk-2026-11-07.md`). 이제 플레이어가 죽으면 경험치 구슬이 떨어지고(레벨×7, 최대 100), 스컬크 촉매 근처면 촉매가 가져가 스컬크가 퍼진다. 실제 클라이언트로 남은 것:
- 경험치 레벨 10 정도로 스컬크 촉매 옆에서 죽었을 때 촉매 위에 영혼 입자 두 개와 소리가 나는지, 경험치 구슬이 안 떨어지고 스컬크가 퍼지는지(`/kill @s` 로 충분). 촉매에서 멀리 죽으면 구슬이 떨어지고 리스폰 뒤 경험치가 0인지, `keepInventory` 가 켜진 월드에서는 구슬이 없는지.
