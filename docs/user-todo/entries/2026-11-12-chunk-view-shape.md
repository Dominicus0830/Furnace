# 시야 청크 모양을 바닐라 둥근 모양으로 (2026-11-12)

서버가 이제 바닐라처럼 둥근 모양으로 청크를 보낸다(시야 16 에서 1021청크, 예전 정사각 1089). 결정할 것은 없다.

## 직접 확인하면 좋은 것
- 실제 클라이언트로 시야 16 에서 접속해 F3+G(청크 경계) 또는 지도 모드로 모서리가 둥근지, 동서남북 끝줄이 시야 + 1 칸까지 오는지 보면 된다. 바닐라 서버와 같은 시드·같은 자리에서 비교하면 가장 확실하다.
- 알림: Paper 도 1021 과 맞는다고 O03 보고서에 적혀 있다(코드로는 확인 못 함). Paper 와 다르면 알려 주면 된다.
