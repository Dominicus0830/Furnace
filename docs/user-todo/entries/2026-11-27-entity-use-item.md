# 몹 아이템 사용 시간이 바닐라와 다른 점 (entity-use-item) — 2026-11-27

근거: PR 632(생물 아이템 사용·맞은 흔들림 shim), 독립 검토 승인(11-27). 기록: `docs/feature-parity/context-notes/2026-11-27-entity-use-item.md`.

**결정(2026-11-27, 코디네이터 확정 — 도미니코 위임): U1·U2 모두 A(바닐라처럼). 반영함.**

**한 줄 요약:** 플러그인이 몹에게 "아이템을 쓰기 시작해"라고 시키는 기능을 붙였습니다. 사용 중 표시는 바닐라와 같지만, 몹이 아이템을 다 쓰는 데 걸리는 시간과 빈 손으로 강제로 쓰게 할 때가 조금 다릅니다. 급하지 않습니다.

| # | 물음 | 안 하면 어떻게 되나 | 추천 |
|---|---|---|---|
| U1 | 몹의 아이템 사용 시간을 아이템마다 바닐라처럼(음식 32틱 등) 맞출까 | 지금 서버 몹은 활·쇠뇌·주민 물약처럼 몹이 실제로 쓰는 것 말고는 72000틱(활 기본값)으로 셉니다. 플러그인이 좀비에게 빵을 "먹게" 시키면 바닐라는 1.6초 뒤 빵이 줄지만 Furnace 는 끝나지 않습니다 | **A. 맞춘다(아이템별 사용 시간 표를 서버에 두는 후속 묶음)** |
| U2 | 빈 손으로 강제로 쓰게 했을 때(`startUsingItem(hand, true)`) 계속 사용 중으로 둘까 | 바닐라는 손이 계속 비어 있으면 사용 중 표시가 남습니다. Furnace 서버는 다음 틱에 "손이 비었다"며 멈춥니다. FancyNpcs 처럼 월드 밖 NPC 에 쓰는 경우는 틱이 돌지 않아 차이가 없습니다 | **A. U1 과 함께 바닐라처럼(쓰던 아이템을 기억해 바뀌었을 때만 멈춤)** |

- 접속한 진짜 플레이어에게 이 길로 쓰기 시작·멈춤을 시키는 것은 아직 막혀 있습니다(분명한 오류를 냅니다). 플레이어는 아이템마다 사용 시간이 이미 있어서 같은 후속 묶음에서 엽니다.

## U3 — Paper 가 바닐라와 다른 두 곳 (2026-11-27 추가, 급하지 않음)

PR 641 검토에서 나온 것입니다. 지금 Furnace 몹은 아래 두 곳에서 **바닐라처럼** 동작합니다.

| # | 무엇 | Paper 는 | 안 바꾸면 | 추천 |
|---|---|---|---|---|
| U3a | 다 쓴 뒤 "아이템 쓰기 시작" 신호 | 다 쓰고 손에 남은 것이 있으면 `startUsingItem(hand, true)` 로 한 번 더 쓰기를 시작하며 item_interact_start 게임 이벤트를 또 냅니다 | 스컬크 감지기가 몹이 먹기를 마친 순간 한 번 덜 반응할 수 있습니다(몹이 직접 먹는 일은 드묾) | **지금대로(바닐라)** |
| U3b | 먹는 시간 실시간 보정 | 서버가 느려지면 실제 시간(nanoTime)으로 먹는 시간을 당겨 줍니다(플레이어용) | 서버가 느릴 때 몹이 먹기를 마치는 틱이 Paper 보다 늦을 수 있습니다. 몹에게는 Paper 도 거의 의미가 없습니다 | **지금대로(바닐라, 틱 기준)** |

- 바꾸게 되면 `LivingEntity.completeUsingItem`(U3a)·`tickUsingItem`(U3b) 두 곳만 고치면 됩니다.

## U3c — 물약의 즉시 효과 순서 (2026-11-27 추가, PR 644 검토)

몹이 물약을 마셨을 때 **Paper 를 따릅니다**(프로젝트 원칙: Paper 와 바닐라가 다르면 Paper 쪽).

- 바닐라 1.21.1: 효과 목록을 차례로 돌며 즉시 효과(즉시 회복·피해)도 그 자리에서 적용합니다.
- Paper 1.21.1: 지속 효과를 먼저 모두 걸고, 즉시 효과는 모아 두었다가 맨 뒤에 적용합니다. 둘 다 javap 로 확인했습니다.
- 차이가 보이는 예: [즉시 회복 II, 생명력 강화 II] 순서의 맞춤 물약. 체력 5 인 돼지는 Paper 에서 13, 바닐라에서 10 이 됩니다. 일반 물약은 효과가 하나라 차이가 없습니다.
- **같이 볼 것:** 플레이어가 마시는 길(`Consuming.applyPotion`)은 아직 바닐라 순서입니다. 추천은 **플레이어도 Paper 순서로 맞추기**(다음 묶음, 한 줄 수정)입니다. 안 하면 맞춤 물약에서 플레이어와 몹이 다르게 동작합니다.
