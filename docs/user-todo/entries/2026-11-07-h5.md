# NMS·CraftBukkit 직접 사용 플러그인 지원 설계 (H5) — 2026-11-07

설계와 호출 빈도 표만 있고 코드(shim·어댑터)는 H6·H7 이 만듭니다(`docs/feature-parity/compat-h5-2026-11-07.md`, 표 `compat-h5-nms-calls-2026-11-07.md`). 이 컨테이너는 Maven Central 만 닿아 인기 NMS 플러그인 jar 를 못 받았습니다. 직접 확인·결정할 것:

- **직접 확인(권장, 표본 늘리기):** NMS·CraftBukkit 을 직접 쓰는 것으로 알려진 실제 플러그인 jar(ProtocolLib·WorldEdit·Citizens·EssentialsX·LuckPerms·Vault 등 쓰시는 것)를 한 폴더에 모아 아래를 돌려 주세요. 저장소 문서는 건드리지 않고 `furnace-compat-paper/build/compat-h5-extra-report.md` 만 만들어집니다. 그 파일(또는 jar 를 프로젝트 파일 `furnace/real-plugins/` 에)을 올려 주시면 다음 스레드가 표 순위를 다시 매깁니다. jar 는 저장소에 커밋하지 않습니다.
  `./gradlew -PskipOracle=true :furnace-compat-paper:nmsReport -PextraJars=<jar 가 든 폴더>`
- **직접 확인(Bukkit 원문 대조):** 같은 1.21.1 서버(Paper·Spigot 각각)에서 `Bukkit.getServer().getClass().getName()` 과 `Bukkit.getServer().getClass().getPackage().getName()` 이 무엇을 내는지 알려 주세요. 설계는 "Spigot 은 `org.bukkit.craftbukkit.v1_21_R1.CraftServer`, Paper 1.20.5 이후는 접미사 없는 `org.bukkit.craftbukkit.CraftServer`"라는 기억에 기댑니다(원문 대조 못 함). 답이 없으면 설계대로(접미사 포함을 알리고 두 이름 모두 풀리게) 갑니다.
- **결정:** Spigot 이름(난독화) NMS 플러그인을 돌리려면 Spigot→Mojang 변환표가 필요한데, 원료인 Mojang 공식 매핑·Spigot 매핑을 이 컨테이너가 받을 수 없고 저장소에 Mojang 데이터를 넣지 않는 규칙입니다. 후보: ① 운영자가 매핑 파일을 직접 두고 도구(`tools/compat/gen-nms-mappings.py`)로 표를 만든다(추천, 기본), ② 운영자가 명시적으로 켜면 서버가 매핑을 내려받는다(R1 라이브러리 내려받기와 같은 옵트인·체크섬), ③ 가장 흔한 이름만 손으로 적은 표를 우리가 싣는다(틀린 이름이 섞일 위험이라 비추). 답이 없으면 ①로 가고, 표가 없을 때 Spigot 이름 플러그인은 이유와 만드는 법을 알려 주며 거절합니다(Mojang 이름 플러그인은 표 없이 돕니다).
- **결정:** 새 옵션 기본값. `plugins.compat.nms.enabled`(NMS 호환 변환·shim, 기본 켜짐: 꺼도 NMS 플러그인은 어차피 못 돕니다), `plugins.compat.nms.strict`(미지원 호출이 있으면 플러그인 로드 거절, 기본 꺼짐: 못 쓰는 기능만 실패하고 나머지는 돕니다), `plugins.compat.nms.version-package`(서버가 알리는 CraftBukkit 패키지 이름, 기본 접미사 포함 `versioned`). 바꾸고 싶으시면 알려 주세요. 답이 없으면 괄호 안 기본값으로 갑니다.
- **결정(H4 와 묶임):** NMS shim 이 시그니처에 쓰는 Mojang 라이브러리(authlib `GameProfile` 4개 jar, Brigadier 6개, serialization `Codec` 3개)를 서버 jar 에 싣는가. H4 의 "서버가 줘야 하는 라이브러리" 결정과 같은 문제입니다(그 항목 답에 따릅니다). 답이 없으면 H7b 는 authlib·Brigadier·serialization 없이 값 shim 부터 하고 해당 표면은 미지원으로 표시합니다.
- **참고(코디네이터용):** H4 순위 1("명령·스케줄러·서비스를 `JavaPlugin` 에 연결")은 H5 의 정의가 아니라서 이 묶음에 넣지 않았습니다. 같은 파일(`CompatServer`·`JavaPlugin`)을 H6 도 만지므로 그 묶음을 먼저 병합하고 H6 를 시작하길 권합니다.
