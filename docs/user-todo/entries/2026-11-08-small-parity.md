# 작은 바닐라 차이 정리 (small-parity) — 2026-11-08

바닐라와 대조해 실제로 달랐던 것만 고쳤다(PR 본문·`docs/feature-parity/context-notes/2026-11-08-small-parity.md` 참고). 결정할 것은 없다. 직접 확인하면 좋은 것:

- 용암 가마솥에 서 있을 때 불이 붙고 화상 소리가 나는지, 불붙은 채 물 가마솥에 들어가면 불이 꺼지며 물이 한 칸 줄어드는지, 불붙은 채 가루눈에 들어가면 가루눈이 사라지는지(mobGriefing 을 꺼 둔 상태에서도 플레이어는 녹인다).
- 같은 종류 스폰 알로 동물·좀비를 우클릭하면 새끼가 생기고 알이 하나 줄어드는지(주민 알로 주민 포함, 크리에이티브는 안 줄어듦).
- 접속·리스폰·차원 이동 때 보더 초기화 패킷은 이미 바닐라와 같아서 바꾸지 않았다.
