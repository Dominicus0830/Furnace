## 확인 1. 책 편집을 취소하면 손에 든 책이 어떻게 보이나 (A14-05)

서버 시험으로는 클라이언트 화면을 볼 수 없어 확인을 부탁한다. 실제 클라이언트(1.21.1)로:

1. `PlayerEditBookEvent` 를 늘 취소하는 시험 플러그인을 넣는다(또는 A14-05 를 고치는 스레드가 만든 것을 쓴다).
2. 깃펜 책에 글을 쓰고 "완료"를 누른다.
3. 책을 다시 연다.

- 글이 **비어 있으면**(쓰기 전 상태) 지금 계약이 맞다 — A14-05 는 닫는다.
- 쓴 글이 **그대로 보이면** 클라이언트가 먼저 바꿔 둔 것이다 — A14-05 대로 취소 때 서버가 그 칸을 다시 보내게 고친다.
