- **결정(작음):** 플러그인이 표시 이름을 정하지 않았을 때 바닐라 채팅 "<이름>" 에 팀 접두·접미를 붙일지. 지금은 바닐라처럼 붙는다(Paper 는 붙지 않는다). 후보: ① 지금처럼 바닐라(추천 — "플러그인이 끼지 않으면 바닐라와 같게"), ② Paper 처럼 순수 이름. 답이 없으면 ①.
