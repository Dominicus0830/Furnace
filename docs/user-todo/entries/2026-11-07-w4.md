# 구조물 템플릿 API·청크 티켓 API (W4) — 2026-11-07
서버 쪽은 시험으로 확인(영역 저장 → `.nbt` → 회전·대칭·완전성·팔레트로 다시 놓기, 청크 경계 걸침, 가져오기·내보내기, 내장 템플릿, `/locate` 와 같은 찾기, 티켓 겹침·플러그인 끄기 자동 해제·엔티티 틱 단계). 문서 `docs/api/structures.md`, `docs/api/chunk-tickets.md`. 실제 클라이언트로 확인할 것:
- 플러그인(또는 시험 플러그인)으로 `structures().place(...)` 를 플레이어가 서 있는 곳 근처에 놓았을 때 클라이언트에 블록·상자·액자가 바로 보이고 어색한 조명/깜빡임이 없는지.
- `structures().save(...)` 가 쓴 `world/generated/<네임스페이스>/structures/<이름>.nbt` 를 구조물 블록(불러오기 모드)에서 같은 이름으로 불러와 같은 모양이 나오는지(그 반대 — 구조물 블록으로 저장한 것을 API 로 놓기 — 도).
- `chunkTickets().add(..., ticking=true)` 를 건 청크의 호퍼/가마/레드스톤 장치·동물이 플레이어가 멀리 있어도 계속 도는지(농작물 성장·자연 스폰은 무작위 틱이라 바닐라 `/forceload` 처럼 플레이어 가까이에서만 돈다 — 안 자라는 게 정상), 플러그인을 `/plugins reload` 하면 멈추는지.
- **결정:** 플러그인 한 개가 걸 수 있는 청크 수 한도(지금 16384 청크, 겹침 포함, 코드 상수)를 `furnace.properties` 옵션으로 바꿀 수 있게 할까요? 답이 없으면 지금처럼 상수로 둡니다(대부분의 플러그인에는 충분).
