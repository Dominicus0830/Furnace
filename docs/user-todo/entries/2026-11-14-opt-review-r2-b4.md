## B4-1. `light.async` 기본값

- **효과(이번에 다시 잼)**: 발광석 400개를 4틱마다 켜고 끄는 장치에서 region 틱 평균 **10.4ms → 1.1ms(−90%)**, 튀는 틱(p95) **48ms → 1.8ms**. 6회 모두 같은 방향이고, 빛 계산이 끝난 뒤의 빛 값은 끔과 같습니다.
- **왜 필요한가**: 빛 계산 자체는 1차 이후에도 그대로라(바닐라와 같은 계산), 레드스톤 램프 시계·대량 횃불 같은 장치가 TPS 를 먹는 것을 줄일 다른 방법이 없습니다.
- **켜면 달라지는 점**: 빛 스레드가 밀리면 빛이 한두 틱 늦게 보입니다(그사이 작물·몹 스폰이 옛 빛을 봄). **바닐라도 빛을 메인 스레드가 아닌 별도 작업 줄에서 계산하므로** 같은 성질입니다. 저장은 밀린 빛을 기다린 뒤 하므로 바닐라보다 정확한 쪽입니다.
