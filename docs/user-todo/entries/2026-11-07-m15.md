# 걸음·헤엄 소리 전반 (M15) — 2026-11-07
서버 시험(`StepSoundTest`)과 봇(`tools/bot-test/m15`)으로 패킷의 크기·높이·분류·대상(본인 제외)은 확인. 실제 클라이언트로 귀로 확인할 것:
- 두 사람이 접속해 한 사람이 풀·돌·나무·모래·자갈·눈·유리·양털 위를 걸을 때 다른 사람 귀에 블록마다 다른 걸음 소리가 나는지(본인 걸음은 클라이언트가 내므로 전과 같음), 웅크리면 조용한지.
- 이끼 카펫·눈 층 위를 걸을 때 위 블록 소리와 발밑 소리가 작게 겹쳐 들리는지(조합 블록), 자수정 블록 위에서 맑은 울림이 가끔 섞이는지.
- 소·돼지·닭·양·늑대·좀비·거미·거북·스트라이더(용암 위)·낙타(모래 위)·말(나무 바닥 위, 탄 채 달릴 때 말발굽 소리가 중간에 섞이는지) 걸음 소리가 바닐라와 같은지.
- 물에 들어간 상태로 걷거나 헤엄칠 때 다른 사람이 헤엄 소리를 듣는지(바닐라도 서버가 아는 이동 속도가 작아 아주 작을 수 있음).
