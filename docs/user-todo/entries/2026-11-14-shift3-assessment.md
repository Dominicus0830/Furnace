   - 실(측정): CPU 가 이미 꽉 찬 상태(새 땅 초당 690청크)에서 32명이 동시에 엇갈리는 장면은 가장 느린 region TPS 11.4 → 10.7(−6%, 하위 10% −13%), region 평균 14.1 → 12.9(−8%), 새 청크 전달 −5%. 원인은 모른다(나누기·합치기는 아님 — 독립 검토). 이 장면의 "너무 빨리 움직임" 되돌림은 Full GC 뒤에 나왔고 s3 4판 중 4판, s4 4판 중 1판(봇이 초당 15블록이라 실제 플레이와는 거리가 멂). region 표 조회 한 번 +9~14ns(T-019 키 섞기로 없어짐).
