# 2026-11-16 T-205 FAWE 빛 직접 쓰기 — Paper 처럼 둘지 확인

**결정됨(2026-11-16, 코디네이터 — 도미니코가 위임한 Paper 호환 범위)**: 지금대로, Paper 처럼 무시한다. 확인할 것 없음.

**한 줄**: FAWE 의 빛을 "직접 써 넣는" 몇몇 동작(`//removelighting` 이 빛 배열을 0 으로 지우기, 빛 정보를 담은 붙여넣기)은 **Paper 에서도 서버 빛을 못 바꾼다**.
Furnace 도 Paper 와 똑같이 했다. 그대로 둘지만 확인해 주세요.

- **왜 그런가**: Paper(Starlight)는 플러그인에게 빛 배열의 **복사본**만 준다. FAWE 가 그 복사본을 고쳐도 서버 빛은 그대로다. Spigot(바닐라 빛)은 진짜 배열을 줘서 바뀐다.
- **예시**: FAWE 가 섹션 빛을 0 으로 지우는 길(`removeSectionLighting`)을 타도 Paper·Furnace 모두 그 섹션의 서버 빛은 그대로다. `//fixlighting`(빛 다시 계산, T-197)은 두 서버 모두 정상으로 맞춘다.
- **안 하면(지금대로 두면)**: Paper 서버에서 쓰던 그대로 동작한다. FAWE 가 기본으로 쓰는 빛 다시 계산(T-197)은 정상이다.
- **바꾸면(Spigot 처럼)**: 위 명령이 빛을 실제로 지우지만 Paper 와 결과가 달라지고, 다른 스레드에서 서버 빛 배열을 직접 고치게 되어 거울 일지 같은 별도 설계가 필요하다.
- **추천**: 지금대로(Paper 와 같게). 프로젝트 기준이 "Paper 와 같은 결과"이기 때문.
