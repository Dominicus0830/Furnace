# T141E4a-D1: 다른 월드에서 부른 setKeepSpawnInMemory (2026-11-15, PR #383 검토)

Furnace 는 게임 규칙이 서버 전체에 하나이고, 스폰 청크(spawnChunkRadius 티켓)는 주 오버월드에만 있다.
Paper 는 월드마다 규칙이 따로라, Multiverse 같은 플러그인이 월드마다 `setKeepSpawnInMemory(false)` 를 부르면 그 월드만 바뀐다.
지금 PR 대로면 네더·추가 월드에서 false 를 불러도 **주 오버월드 스폰 청크가 꺼진다**(spawnChunkRadius=0).

- A. 지금대로(어느 월드로 불러도 서버 전체 규칙을 바꾼다). 문서에만 적는다.
- B. 주 오버월드가 아닌 월드의 setKeepSpawnInMemory 는 무시하고 경고 한 줄(T141-D1 시간·날씨와 같은 방침). get 은 지금처럼 전체 값.
- C. 게임 규칙 쓰기 전체(setGameRule·setGameRuleValue·keepSpawn)를 주 오버월드가 아닌 월드에서는 무시+경고.

추천: **B** — 스폰 청크가 오버월드에만 있으니 다른 월드의 "스폰 유지 끔"은 뜻이 없고, 끄는 쪽 실수가 서버 전체 성능·농장에 번진다. 다른 규칙(C)까지 막으면 /gamerule 과 어긋나 혼란.
