# 아이템 사용 잔여 (M18) — 2026-11-07
서버 시험(`EntityDataStackTest`·`DragonBreathBottleTest`·`BundleMenuTest`·`CrossbowMobTest`·`ConsumingTest`·`AnvilMenuTest`·`EntityGameEventsTest`)으로 규칙은 확인(`context-notes.md` "묶음 M18"). 실제 클라이언트로 남은 것:
- `/give @s pig_spawn_egg[custom_name='"Bob"',entity_data={id:"minecraft:pig",NoAI:1b,Silent:1b}]` 을 블록·물에 쓰면 이름이 붙고 움직이지 않는 돼지가 나오는지(Silent 라도 바닐라처럼 생성 순간 울음소리는 한 번 난다). `entity_data.id` 를 `minecraft:cow` 로 바꾸면 소가 나오는지. 같은 방식의 물고기 양동이·배·광산 수레·갑옷 거치대(`ShowArms:1b`)·발사기에서 쏜 알/수레도 이름이 유지되는지.
- 용의 숨결 구름이 남은 곳(엔더 드래곤이 뿜은 것)에서 유리병을 우클릭하면 용의 숨결 병이 되고 구름이 조금 줄어드는지, 구름 곁에 용이 없으면(플레이어가 `/summon area_effect_cloud` 로 만든 것) 아무 일도 없는지.
- 발사기에 라마 카펫(색 카펫)을 라마·말 앞에서 쏘면 입혀지는지.
- 망원경·엔더의 눈을 들고 우클릭을 누르는 동안 "사용 중" 상태(손 올림)가 유지되고 뗄 때 망원경 소리가 나는지.
- 모루에 이름 없는 철 칼을 넣고 이름 칸에 "Iron Sword"(영어 기본 이름)를 그대로 적으면 결과가 나오지 않는지.
- **가방(bundle)**: 서버는 기능 플래그 `minecraft:bundle` 가 켜진 월드에서만 동작한다. 접속 때 켜진 플래그를 그대로 클라이언트에 보내므로(독립 검토 H4) 클라이언트가 가방을 쓸 수 있어야 한다 — 데이터 팩 `features` 로 켠 월드에서 가방에 아이템을 넣고(우클릭으로 슬롯의 아이템을 가방에 올려 넣기·가방 위 우클릭으로 꺼내기) 우클릭 사용 시 내용물이 쏟아지는지 확인하고, 클라이언트 표시가 이상하면 알려 줄 것.
- 몹(스켈레톤 등 쇠뇌를 든 몹)이 다중 발사 쇠뇌로 세 발을 퍼뜨려 쏘는지, 폭죽 로켓을 손에 들면 로켓이 날아가는지.
- 시련 생성기(불길한)가 화살·눈덩이·달걀 같은 발사체 아이템을 아래로 쏘는지, 그 화살은 생존 플레이어가 주울 수 없는지.
- 알려진 차이(결정 필요 없음): 스폰 알을 동물에 써서 새끼를 만드는 동작(`spawnOffspringFromSpawnEgg`)은 아직 없다.
