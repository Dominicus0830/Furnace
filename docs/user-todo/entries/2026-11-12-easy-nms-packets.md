## 결정할 것

- **플러그인 개발용 묶음(API + 서버 클래스 + 소스)을 어디에 올릴까?** 지금 내부 단(`Internals`)을 쓰려면 서버 jar 를 직접 받아 `compileOnly(files(...))` 로 넣어야 한다.
  - 추천: 지금은 CI 산출물·릴리스 첨부 jar 로만 내고, 공개 Maven 저장소(GitHub Packages 등) 배포는 첫 공개 릴리스 때 정한다.
  - 다른 길: 지금 바로 GitHub Packages 에 올린다(받는 쪽도 GitHub 토큰이 필요), 또는 JitPack.
- **원시 바이트 패킷 단(프로토콜 번호 + 바이트 배열)을 열까?**
  - 추천: 열지 않는다. 범용 스키마(E4)가 play 패킷 179종을 이름 붙은 필드로 모두 읽고 쓰게 하므로, 바이트 단은 버전마다 깨지는 길을 하나 더 만드는 셈이다.
  - 다른 길: "불안정" 표시를 달아 연다(ProtocolLib 의 raw 접근과 같은 수준).
