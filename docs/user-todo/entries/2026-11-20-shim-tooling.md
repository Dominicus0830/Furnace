# 넓은 호환 도구 묶음(T-227·228·233·234·238) — 확인 부탁 항목 (2026-11-20)

결정이 꼭 필요한 것은 없다. 아래는 도구를 만들며 알게 된 것이고 추천대로 이미 처리했다.

| # | 내용 | 안 하면 어떻게 되나 | 추천(적용함) |
|---|---|---|---|
| S1 | **서명 관문이 CI 에서 돌려면 Paper 서버 표가 필요하다.** 이 표는 paperweight(Paper 저장소 repo.papermc.io 접근)로 만든다. 평소 CI 는 모든 gradle 에 오라클 끔(`-PskipOracle=true`)이라 이 단계만 오라클을 켠다 | 오라클을 안 켜면 Paper 쪽 멤버가 비교에서 빠져 관문이 약해진다. 대신 없으면 건너뛰지 않고 **실패**하게 했다(규칙 5). 단 Paper 쪽 스냅샷이 바뀌면 기준선이 흔들려 한 번 다시 써야 할 수 있다 | `vanilla-gates` 작업 안에서만 오라클을 켜고, Paper 저장소에 못 닿으면 실패로 둔다 |
| S2 | **서명 기준선 1124줄은 전부 "미분류" 이유다.** 손으로 쓴 shim 이 바닐라·Paper 와 다른 곳(상위 사슬 124, 빠진 인터페이스 536, 서술자 355 …)을 처음 상태 그대로 적은 것 | 지우려면 생성기(T-229~)가 바로잡아야 한다. 지금 일부러 의도했다고 쓸 줄은 아직 없다 | 생성기가 바로잡을 때마다 줄을 지운다. 새 차이가 생기면 CI 가 실패한다 |
| S3 | **Spigot 이름 표본 플러그인 33개는 이 서버(클라우드)에서 분석하지 못했다.** Spigot→Mojang 이름 대응이 필요한데 그 표를 내려받을 수 없는 환경이다 | 지원 비율 숫자가 Mojang 이름 표본(9개 분석 + NMS 안 쓰는 58개)에 치우친다 | 도미니코 PC(대응표가 있는 곳)에서 같은 도구를 한 번 돌려 33개를 더한다 — `docs/ops/compat-sample-ranking.md` 에 명령을 적어 둠(T-234 PR) |
| S4 | **확인 부탁(결정):** 호환 구멍 순위 문서(`docs/feature-parity/compat-gaps-ranking-2026-11-20.md`)에 **공개 플러그인이 부르는 마인크래프트 내부 이름(Mojang 이름) 약 96줄이 글자 그대로** 들어 있다. 서명 기준선은 같은 이유로 지문(해시)으로 바꿨는데 이 문서는 아직 그대로다 | 그대로 두면 "Mojang 이름을 저장소에 올리지 않는다"는 원칙과 어긋날 수 있다. 다만 이 이름들은 Mojang 파일이 아니라 **세상에 풀린 플러그인 jar 가 직접 부르는 이름**이고, 이 문서의 쓸모(어떤 구멍부터 채울지 순서)가 이름에 달려 있다 | 지금은 그대로 두기(플러그인이 부르는 이름이라 Mojang 파일 내용이 아니다). 걱정되면 이름을 지문으로 바꾸고 원문은 돌린 사람 PC 에만 두는 쪽으로 도미니코가 정한다 |
