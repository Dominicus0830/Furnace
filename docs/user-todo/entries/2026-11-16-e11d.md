# T-141 E11d 이름만 있는 머리의 스킨 채우기(서버 쪽) — 도미니코 결정 (2026-11-16)

근거: `docs/feature-parity/context-notes/2026-11-16-e11d-skull-fill.md`. 아래는 추천대로 진행했거나 하기로 한 것이며, 다르게 하고 싶을 때만 답하면 된다.

## 결정
**1. 몹 장비·액자·갑옷 거치대·말 가방 등 "플레이어 인벤토리·떨어진 아이템·상자·머리 블록" 말고 다른 보관 칸에도 같은 훅을 달까?**
- 쉬운 말: 이번에 `/give`·접속 때 불러오기·바닥에 떨어진 머리·상자 속 머리·놓인 머리 블록은 바닐라처럼 스킨이 채워진다. 하지만 `/summon armor_stand`(머리 장착)·몹이 든 머리·액자 속 머리처럼 "엔티티가 든 칸"은 아직 채우지 않는다(이름만 있으면 기본 스킨으로 보인다).
- 안 하면: 그 칸의 머리는 명령(`/data`)으로 보면 이름만 있고 스킨이 없다. 대부분의 서버에서는 거의 안 쓰는 모양이다.
- 추천: **지금은 두고**, 쓰는 서버가 있다고 알려 주면 엔티티 종류별로 한 곳씩(읽기 경로마다 훅 한 줄) 후속으로 한다. 겹치는 구조는 이미 만들어 두었다(`ProfileFill.onStore`).

**2. 오프라인 모드 서버가 이름만 있는 머리를 만났을 때 Mojang 에 물어도 될까?**
- 쉬운 말: 바닐라는 `online-mode=false` 서버도 머리 이름을 사용자 캐시·Mojang 이름 조회로 확인한다(못 찾으면 오프라인 UUID 프로필). Furnace 서버 쪽 경로(`/give`·저장된 아이템)도 같게 구현했다. 플러그인 API 쪽(호환 계층)은 이미 "온라인 모드이거나 프록시 포워딩일 때만 묻는다"로 정해져 있어(E10) 그대로 둔다.
- 안 하면(= 오프라인이면 묻지 않기로 바꾸면): 인터넷이 막힌 오프라인 서버에서 조회 시간 초과가 없어지지만, 바닐라와 결과가 달라진다(머리 스킨이 안 채워진다).
- 추천: **바닐라와 같게(지금 구현)**. 이름을 묻는 요청은 머리가 만들어질 때 한 번이고 10분 캐시가 있으며, Mojang 으로 나가는 요청은 동시에 4개까지만 하고 429·5xx 는 3번까지 다시 시도해 폭주·일시 장애로 스킨 없는 결과가 굳지 않는다. 오프라인 모드에서 Mojang 에 없는 이름은 바닐라처럼 소문자 오프라인 프로필이 된다.

## 확인 대기 (접속 시험)
- 실제 서버(여러 region 스레드)에서 이름만 있는 머리 아이템을 `/give`·바닥에 던지기·상자에 넣기·머리 블록 놓기 후 스킨이 채워지는지. 실제 클라이언트 또는 봇으로 확인하고 결과를 알려 주세요. (자동 시험은 가짜 레벨로만 돌렸다.)
