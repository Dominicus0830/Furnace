# Axiom 이진 NBT·엔티티 놓기(5e-3a·5e-3b): Paper 와 다르게 둔 점 4개 (2026-11-20)

급하지 않다. 모두 추천대로 이미 적용돼 있다. 다르게 원하면 알려 주면 된다. 근거는 `docs/feature-parity/compat-nms-batch5-axiom-voxy-2026-11-20.md` 의 5e-3a·5e-3b 절이다.
