# 2차 CSP B2(월드젠) 결정 (2026-11-14)

보고서: 공유 폴더 `furnace/reviews/opt-review-r2/B2-worldgen.md`(원자료 `B2-repro/`). 월드젠 코드는 1차 이후 그대로라 새 땅 장면 CPU 의 58~75% 가 여전히 월드젠이다. 1차 숫자(장식 레인 −11~17%, 엔드 −26%)는 다시 재도 같았다.

1. **D8(월드 생성 스레드 수 기본값) — 측정 M-02 가 끝났다.** 32명이 새 땅을 걷는 장면(4코어)에서 생성 스레드를 3 → 2 로 줄이면 받은 청크/초가 15% 줄고 TPS 이득은 작았다. 대신 리눅스에서 JVM 옵션 `-XX:ThreadPriorityPolicy=1` 한 줄로 생성 스레드 낮은 우선순위가 처음으로 먹혀, 가장 느린 TPS 최저가 15.5~17.0 → 18.5(일반 사용자)로, 오버월드·네더 동시 새 땅에서는 12 → 17 로 올랐다(받은 청크/초 −3~7%). **추천: 기본값은 지금처럼 코어−1 로 두고, start.sh 와 문서에 그 옵션을 넣는다(T-111). 설정 키 `worldgen-threads` 는 차원 공유 생성 풀(P-O04-09)과 같이 연다.**
2. (알림, 결정 아님) 요새 고리(T-024)를 P2 → P1 로 올렸다. 월드를 열 때 배경에서 미리 계산하면 새 월드 기동이 8.1 → 5.6초다. 다만 다시 켤 때도 무조건 계산하면 2.4 → 3.1초로 늘어서, 1차에 정한 대로 월드 폴더의 Furnace 전용 고리 파일과 같이 넣는다.
