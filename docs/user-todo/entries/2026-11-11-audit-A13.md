# A13 점검 — 도미니코 결정이 필요한 것 (2026-11-11)

보고서: `docs/audit/findings/A13-commands-functions-text.md`

| 번호 | 결정할 것 | 추천 | 이유 |
|---|---|---|---|
| A13-D1 | 텍스트 JSON 해석(`JsonTextSerializer`)을 바닐라처럼 엄격하게 할까? 지금은 모르는 색·틀린 불린·모르는 클릭 종류를 오류 없이 무시한다. 읽는 자리가 세 갈래다: (a) 명령·데이터 팩 입력, (b) 플러그인 API `deserialize`, (c) 저장된 데이터(엔티티 `CustomName`, 아이템 `custom_name`·`lore`, 스코어보드, 보스바, Display). | (a) **엄격**, (b) **너그럽게 유지**, (c) 바닐라가 자리마다 실패 처리가 다르므로 **자리별 대조 뒤 별도 묶음**으로 | 바닐라는 `Invalid chat component` 로 거절한다. 다만 문자열 `"true"` 같은 느슨한 입력을 플러그인 쪽까지 막으면 깨지는 플러그인이 생길 수 있다. 저장 데이터는 엔티티가 경고 뒤 이름 없음, 아이템이 `Tried to load invalid item` 처럼 자리마다 달라 한꺼번에 엄격하게 바꾸면 안 된다. 참고: `hoverEvent.value` 는 바닐라 1.21.1 호버 코덱도 받으므로(`contents` 와 `value` 둘 다) 엄격 모드에서도 계속 받는다. |
