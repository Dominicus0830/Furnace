# Bukkit·Paper 호환 어댑터 뼈대 (H1) — 2026-11-07
서버 쪽은 시험으로 확인(로드·수명·설정·paper-plugin.yml 순서·이벤트 24종 전달과 되돌림). 문서 `docs/api/compat-paper.md`. 실제 플러그인으로 확인할 것:
- 실제 Bukkit·Paper 플러그인 jar 하나(작은 것: 예 Vault 류, 이벤트 몇 개만 쓰는 것)를 `plugins/` 에 넣어 부팅했을 때 로그에 오류 없이 켜지는지. 쓰는 API 가 아직 없으면 그 플러그인만 `NoClassDefFoundError` 로 실패하는 게 정상이다(H2~H4 가 채운다). 실패한 클래스 이름을 알려 주시면 다음 묶음의 우선순위로 쓴다.
- 입장 때 메시지·채팅 서식을 바꾸는 플러그인이 바닐라 클라이언트에서 같은 모양으로 보이는지(`§` 색 코드).
- **결정:** `plugin.yml` jar 를 `plugins/` 에 그냥 넣어도 읽도록 했다(Paper 와 같은 위치). `plugins/bukkit-plugins/` 도 읽는다. 기존에는 "bukkit-plugins 에 넣어라"고 안내했다. 답이 없으면 둘 다 읽는 지금 방식을 유지한다.
- **결정:** `org.bukkit.*` 호환 클래스는 공개 이름·서명만 따라 새로 썼다. Bukkit API 는 GPLv3 이고 Furnace 의 라이선스와의 관계(호환 클래스를 같은 jar 에 배포해도 되는지)는 판단하지 않았다. 배포 전에 확인해 주세요. 답이 없으면 호환 모듈은 `plugins.compat.bukkit=true` 기본값으로 서버 jar 에 같이 들어간다(끄면 쓰지 않는다).
