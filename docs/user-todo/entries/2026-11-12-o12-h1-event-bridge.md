# O12 H1 이벤트 다리 6종 — 확인 (2026-11-12)

결정은 없다. 실제 보호 플러그인으로 한 번 확인해 주면 좋다.

## 직접 확인하면 좋은 것
- WorldGuard 류 플러그인이 보호 구역에서 **블록 설치·아이템 버리기**를 막는지(막혀야 한다), 작물 자람·눈 녹음·침대 폭발 보호·몹 스폰 차단 플래그가 듣는지.
- 설치를 취소한 뒤 손 아이템이 줄지 않고 칸이 원래대로 보이는지(서버 시험은 통과, 실접속 확인 필요).

## 알림(차이)
- 이벤트 처리기 안에서 `world.getBlockAt(x,y,z)` 로 설치될 칸을 다시 읽으면 아직 원래 블록이다(CraftBukkit 은 놓인 블록). 이벤트 자신의 `getBlockPlaced()` 는 놓일 블록을 보인다.
- 침대·문 설치는 `BlockMultiPlaceEvent` 없이 한 칸 이벤트로 온다.
