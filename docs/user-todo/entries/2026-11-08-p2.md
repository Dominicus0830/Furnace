# Bukkit 비동기 작업 스레드 풀 (P2) — 2026-11-08
Bukkit 플러그인의 `runTaskAsynchronously` 등이 이제 Paper 와 같은 이름 붙은 플랫폼 스레드 풀(`Craft Scheduler Thread - N - 플러그인`)에서 돌고, 서버를 끌 때 돌고 있는 비동기 작업을 최대 5초 기다립니다(남으면 "Nag author(s)" 로그). 서버 단위 시험으로 확인했고 직접 확인할 것은 없습니다.

- **결정(작음):** 옛 비동기 작업의 스레드. 지금은 `plugins.compat.scheduler.async-threads=platform`(추천 — 옛 DB 드라이버가 몇 개 겹쳐도 비동기 작업 전체가 멈추지 않음). 후보: ① platform 유지(추천), ② virtual 을 기본으로(스레드 수가 적게 들지만 JDK 21 의 pinning 위험). 답이 없으면 ①.
- **후속(작음, 답 필요 없음):** Paper API `getAsyncScheduler()` 도 같은 풀로, 개발 모드 핫 리로드도 비동기 작업 기다리기, 비동기 대기열을 관리 스레드로 — 필요해지면 따로 연다.
