# 확인 요청 — 최적화 후보 두 개 검토 결과 (2026-11-20)

자세한 내용: `docs/audit/opt-candidates-serpool-spawnchunk-2026-11-20.md`

**결정 1 (쉬운 말):** 스폰 지점 주변 49칸 청크가 늘 켜져 있는 것(바닐라와 같음) 때문에 서버가 얼마나 느려지는지 쟀더니 거의 안 느려집니다(한 틱 50ms 중 0.3ms). 그래서 이 설정을 줄이거나 끄지 않고 **그대로 둡니다.** 줄이면 스폰 지점 장치·호퍼가 바닐라와 다르게 움직입니다.
- 추천: 그대로 둔다(이미 적용). 바꾸고 싶으면 게임 규칙 `spawnChunkRadius` 로 서버 주인이 직접 조절할 수 있습니다.
- 안 하면: 아무 일도 없습니다. 다만 "1명이 걸을 때 CPU 가 1.3 → 2.2코어로 늘어난" 원인은 아직 모르니, 코디네이터가 PC 측정(M-22)을 요청할 예정입니다.

**결정 2 (쉬운 말):** 청크를 클라이언트에 보내기 전 압축·변환하는 줄에서, 지금 바로 보낼 청크가 미리 만드는 청크 뒤에 줄 서는 경우가 있습니다. 순서를 바꾸는 개선(T-226)을 만들기는 쉽지만, 노트북에서만 줄이 길었고 전체 시간은 오히려 짧아서 **먼저 계측만 넣고 정말 느린지 확인한 뒤** 진행하기로 했습니다.
- 추천: 계측 먼저(이미 TASK 로 등록).
- 안 하면: 지금도 전체 시야 도착은 빨라졌으므로 큰 손해는 없습니다.
