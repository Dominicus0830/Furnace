# Spigot 이름 NMS 플러그인 대응표 (H7d) — 2026-11-08

Spigot 이름으로 컴파일된 NMS 플러그인(CommandAPI Spigot 판 등)을 Mojang 이름 shim 에 잇는 대응표를 넣었습니다. 기본은 꺼짐이고, 켜면 그런 플러그인이 있을 때만 서버 컴퓨터에서 Mojang·Spigot 매핑을 처음 한 번 받습니다(저장소·서버 jar 에는 싣지 않음). 설계·한계: `docs/feature-parity/compat-h7d-2026-11-08.md`.

- **결정(기본값):** `plugins.compat.nms.spigot-mappings` 기본을 `off`(켤 때만 받기)로 두었습니다. 서버 제공 라이브러리처럼 "Bukkit 플러그인에 필요할 때 알아서 받기"(`download` 기본)로 바꾸고 싶으시면 알려 주세요. 답이 없으면 `off` 로 둡니다.
- **직접 확인(실제 서버, 권장):** `furnace.properties` 에 `plugins.compat.nms.spigot-mappings=download` 를 쓰고 Spigot 판 NMS 플러그인(예: CommandAPI `commandapi-bukkit-plugin` 일반 판)을 `plugins/bukkit-plugins/` 에 넣어 켜 주세요. 로그의 ① "Spigot BuildData <커밋> … sha256 … 고정했다" 한 줄, ② `플러그인 X: NMS·CraftBukkit 심볼 N개 중 shim 있음 …` 한 줄, ③ 미지원 목록을 프로젝트 파일 `furnace/real-plugins/` 에 올려 주시면 — ①의 커밋·해시를 코드에 고정하고(지금은 처음 받을 때 잠금), ②③으로 실제 표에서 이름이 제대로 풀리는지(이 컨테이너에서는 실제 매핑을 받을 수 없어 가짜 표로만 시험) 확인합니다. 받기가 실패하면 그 경고 한 줄도 같이 주세요.
- **알림:** 인터넷이 없는 서버는 `plugins/.libraries/spigot-mappings/1.21.1/` 에 `server.txt`(Mojang 1.21.1 서버 매핑, sha1 `03f89854…` 인 파일만 씀)·`bukkit-cl.csrg`·`bukkit-members.csrg` 를 두고 `plugins.libraries.offline=true` 로 켜면 됩니다.
