# 엔드 포털 중력 블록 복제 옵션 (gravity-block-portal-dupe) — 2026-11-08
`furnace.properties` 에 `gravity-block-portal-dupe`(기본 `true` = 바닐라, 복제 유지)를 추가했다. `false` 로 두면 엔드 포털로 넘어간 모래·자갈·모루 등의 옛 엔티티가 제자리에 블록을 놓지 않아 복제되지 않는다. 서버 시험(`GravityBlockPortalDupeTest`)으로 확인했다. 실제 클라이언트로 남은 것:
- 기본값에서 모래를 엔드 포털 위로 떨어뜨리면 바닐라처럼 **엔드 단상에 모래 블록 1개 + 모래 아이템 1개**가 생기는지(복제). 오버월드 쪽에는 아무것도 남지 않는다 — 포털 칸은 블록으로 교체할 수 없어 옛 모래가 아이템을 떨구고, 그 아이템도 포털로 엔드에 간다.
- `gravity-block-portal-dupe=false` 로 재시작한 뒤 같은 장치에서 엔드에 **모래 블록 1개만** 생기는지(아이템 복제 없음).
- **결정:** 다른 포털(네더 포털) 복제는 바닐라에서 일어나지 않아 이 키는 엔드 포털에만 영향을 준다. 이대로 괜찮은지.
