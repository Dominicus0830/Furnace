# A12-04 이동·피해 통계 — 접속 확인 (2026-11-11)

서버 단위 시험으로 바닐라 분기식을 모두 확인했고, 실제 클라이언트에서 한 번만 보면 된다.

- 서바이벌로 접속해 걷기·달리기·웅크려 걷기·수영·사다리·보트·말·겉날개 비행을 해 보고 Esc → 통계에서 "걸어간 거리"·"달린 거리"·"점프 횟수"·"받은 피해" 등이 오르는지 본다.
- `/scoreboard objectives add w minecraft.custom:minecraft.walk_one_cm` 후 `/scoreboard objectives setdisplay sidebar w` 로 걷기 거리가 점수판에 오르는지(100 = 1블록) 본다.
