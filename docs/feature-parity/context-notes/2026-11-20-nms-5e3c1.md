# NMS shim 5e-3c-1 함정 (2026-11-20)

- **바닐라 서버는 Brigadier 기본 오류를 바꿔 둔다.** `SharedConstants` 정적 초기화가 `CommandSyntaxException.ENABLE_COMMAND_STACK_TRACES = false`,
  `BUILT_IN_EXCEPTIONS = new BrigadierExceptions()` 를 한다. 그래서 Paper 에서 `StringReader` 오류 문구는 진짜 Brigadier jar 문구가 아니라 게임 번역 문구다
  (예 잘못된 이스케이프: Brigadier `'i'`, 바닐라 `'\i'`). Paper 기대값을 뽑을 때 진짜 Brigadier 단독으로 돌리면 틀린 기대값이 나온다 — Paper 를 부트스트랩해서 뽑는다.
  Furnace 는 `PluginFormat.sharedLibrariesReady` 로 Brigadier 묶음을 붙일 때 같은 일을 한다.
- **Paper 를 직접 돌려 기대값 뽑기:** paper-1.21.1.jar + `META-INF/libraries` + Mojang 라이브러리를 클래스패스에 두고 `SharedConstants.tryDetectVersion()`·
  `Bootstrap.bootStrap()` 이면 레지스트리가 선다. 부트스트랩이 `System.out/err` 를 로거로 바꾸므로 결과는 파일로 직접 쓴다. 블록 태그는 데이터 팩을 안 읽어 비어 있다 —
  `HolderLookup.RegistryLookup.Delegate` 로 태그 조회만 바꿔 쓴다.
- **Brigadier·DFU 를 던지는 본문은 `$Lib` 도우미로.** `athrow`·`catch` 는 검증 때 그 예외 클래스를 읽는다 — `ResourceLocation`·`TagParser` 처럼 Brigadier 없는
  서버에서도 쓰이는 클래스에 Brigadier 예외를 던지는 코드를 두면 클래스 전체가 링크 실패한다(`CompatLinkTest`).
- 바닐라 `BlockStateParser` 의 `ERROR_EXPECTED_VALUE` 는 인자 차례 때문에 "Expected value for property 'minecraft:oak_log' on block axis" 처럼 블록·속성이 뒤바뀐 문구가
  나온다. 태그 뒤 속성 오류의 블록 이름은 "minecraft:"(태그는 `id` 를 정하지 않는다). 둘 다 바닐라 그대로 둔다.
