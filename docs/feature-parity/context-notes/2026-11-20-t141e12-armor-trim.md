# T-141 E12 방어구 장식(ArmorMeta·ColorableArmorMeta·ArmorTrim) (2026-11-20)

원문 기준: Paper 1.21.1(Youer 1.21.1 사본의 `CraftMetaArmor`·`CraftMetaColorableArmor`·`CraftItemMetas`·`CraftTrimMaterial`·`TrimMaterial`·`TrimPattern`). 동작만 보고 코드는 옮기지 않았다.

## 한 일
- API: `ArmorMeta`, `ColorableArmorMeta`(= ArmorMeta + LeatherArmorMeta), `trim.ArmorTrim`·`TrimMaterial`·`TrimPattern`(바닐라 10·18개 상수), `Registry.TRIM_MATERIAL`·`TRIM_PATTERN`, `org.bukkit.Translatable`.
- 메타 종류: `ARMOR`(금속 방어구 20개 + 거북 투구), `COLORABLE_ARMOR`(가죽 방어구 + 늑대 갑옷, 이제 장식도), `LEATHER_ARMOR`(가죽 말 갑옷, 장식 없음). 염색 읽기·쓰기는 `LeatherColor` 한 곳을 두 메타가 함께 쓴다.
- 직렬화는 Paper 키: `meta-type: ARMOR`, `trim: {material, pattern}`(키 문자열). 없는 키·잘못된 값은 조용히 무시(Paper 와 같다), 맵 값이 Map 이 아니면 IAE.

## Paper 와 같게 한 것
- 아이템에서 읽을 때 재료·무늬가 레지스트리 값이 아니면(인라인 재료, 모르는 키) 장식을 버린다. 메타를 되쓰면 컴포넌트가 사라진다.
- 장식의 "툴팁에 보이기"는 메타 안에서 `ItemFlag.HIDE_ARMOR_TRIM` 으로만 다룬다(`show_in_tooltip`=false 면 읽을 때 플래그가 켜지고, 적용할 때 `!플래그` 를 쓴다). 장식이 없으면 플래그는 스택에 남지 않는다. 그래서 `HIDE_ARMOR_TRIM` 이 더는 UnsupportedFeature 가 아니다(장식을 맡지 않는 일반 메타에서 trim 컴포넌트가 있을 때만 그대로 던진다).
- `ArmorTrim` 의 같음은 재료·무늬 객체 동일성 — 레지스트리가 키마다 한 객체를 준다(`TrimRegistry`, `BannerPatternRegistry` 와 같은 방식, 데이터 팩 항목은 처음 찾을 때 만든다).
- 메타 적용 가능 규칙: 금속 방어구 메타는 금속 방어구에만, 염색 가능 메타는 가죽 방어구·늑대 갑옷에만, 가죽 말 갑옷 메타는 가죽 말 갑옷과 염색 가능 방어구에 붙는다(Paper 의 첫 인터페이스 규칙).

## Paper 와 다른 점(알고 둔 것)
1. `TrimMaterial#description()`·`TrimPattern#description()`(Adventure Component)은 없다 — 이 호환 계층은 Adventure 멤버를 두지 않는다(#398 과 같은 원칙).
2. 데이터 팩이 더한 재료·무늬의 `getTranslationKey()` 는 `UnsupportedFeature`(그 설명 JSON 을 이 계층이 읽지 못함). 바닐라 값은 `trim_material.minecraft.<이름>`·`trim_pattern.minecraft.<이름>`.
3. 레지스트리 밖 `TrimMaterial`·`TrimPattern` 구현(플러그인이 직접 만든 것)을 `setTrim` 에 주면 Paper 는 적용 때 IAE 를 던지지만 여기서는 `setTrim` 시점에 던진다(같은 문구).
4. 가죽 방어구 → 가죽 말 갑옷 메타로 옮길 때 Paper 는 색도 잃지만 여기서는 색을 유지한다(E11 부터의 의도적 차이, 같은 컴포넌트라서). 장식은 Paper 처럼 버려진다.

## 함정
- 장식 컴포넌트는 서버 코덱을 거치는 날 SNBT(`ItemComponent.raw("trim")`)로 쓴다: 정규 모양은 `{material:"minecraft:quartz",pattern:"minecraft:sentry"}`(보이면 `show_in_tooltip` 생략, 숨기면 `show_in_tooltip:0b`). 날 문자열로 직접 넣으면 같은 장식인데도 스택이 합쳐지지 않을 수 있다.
- 시험 서버에서 `setItemMeta` 는 빈 메타를 "지우기"로 받아 true 를 돌려준다 — "붙일 수 없는 종류" 시험은 메타에 값을 넣은 뒤에.
