## 2026-11-12 Bukkit 값 타입·소리·입자·바이옴 (H4 묶음 C)

상세는 `compat-h4c-values-2026-11-12.md`. 함정과 대조 결과만 적는다.

- **Paper 1.21.1 `World#spawnParticle` force 기본값은 false** 다. Paper 패치가 인터페이스 10인자 기본 메서드를 true 로 바꿨지만 CraftWorld 가 그 메서드를 force=false 로 override 해서 true 는 쓰이지 않는다. 받는 사람을 고르는 12인자 판만 true. 처음 구현은 패치만 보고 true 로 했다가 독립 검토(PR #241 R1)에서 뒤집혔다 — **인터페이스 기본 메서드 패치는 구현 클래스가 override 하는지 같이 봐야 한다.**
- **1.21.1 CraftBukkit·Bukkit 본문**은 MohistMC/Youer 의 `1.21.1` 브랜치(raw.githubusercontent)에서 읽을 수 있다(1.21.1 Paper 포크 — Paper 패치 문맥 줄로 교차 확인할 것).
- **FieldRename 다리는 이름을 대문자로 바꾼 뒤 찾는다** — `Particle.valueOf("flame")` 이 Paper 에선 성공한다. getByName 다리(Enchantment·PotionEffectType)도 1.21.1 에 있다.
- **CraftParticle 은 입자 종류로 data 를 고른다** — data 의 실제 형으로 switch 하면 `DUST` + `DustTransition`(DustOptions 의 하위 형)이 전이 먼지가 되어 Paper 와 달라진다. 처음 구현이 그랬다.
- **Bukkit `Color.mixColors` 는 정수 나눗셈 평균**(`float avg = totalRed / (n + 1)` 의 오른쪽이 int). 실수로 나누면 (255,0,0)+(0,51,200) 이 (227,45,178) 로 하나 어긋난다(Paper 는 (227,44,178)).
- **`PotionEffect(type, d, a)` 3인자 생성자는 ambient=true**(Bukkit javadoc "Assumes ambient is true"). 바닐라 물약 효과는 ambient=false 라 `PotionType` 효과는 6인자로 만든다.
- **바이옴 쓰기는 Paper 도 클라이언트에 다시 보내지 않는다** — 서버 `Region#fillBiomes`(/fillbiome 용)는 chunks_biomes 를 뿌리므로 Bukkit `setBiome` 에 쓰면 Paper 와 달라진다. `Region#setNoiseBiomeAtBlock` 을 따로 둠. 읽기·쓰기 모두 높이 밖은 끝 칸으로 죈다.
- **FieldRename 의 새 이름이 이미 다른 상수 이름이면 안 된다**: `ApiRenamesTest` 가 새 이름은 실제 필드, 옛 이름은 없는 필드인지 본다. 1.21.3+ 이름 바꿈(Attribute `GENERIC_` 떼기, Sound 일부)을 최신 main 의 FieldRename 에서 그대로 가져오면 1.21.1 에 없는 상수로 바꿔 `NoSuchFieldError` 가 난다 — 1.21.1 시절 것만 넣었다.
- 시험 함정: `server.join()` 직후 `player().location()` 이 아직 (0,0,0) 일 수 있다(약 1/5 확률). 위치로 기준 칸을 잡는 시험은 두 번 읽어 같아질 때까지 기다린다(`BukkitEffectsTest`). `CraftTeleportResultTest` 도 같은 틀이라 드물게 흔들릴 수 있다.
