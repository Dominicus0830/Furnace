## 작은 바닐라 차이 정리 (2026-11-08)

후속 후보 5건을 디컴파일(1.21.1)과 대조했다.

- **같음(바꾸지 않음)**: 접속·리스폰·차원 이동 때 보더 초기화. 바닐라 `PlayerList.sendLevelInfo` 는 `server.overworld().getWorldBorder()` 로 `ClientboundInitializeBorderPacket` 을 보낸 뒤 시간·스폰·날씨 순이고, Furnace 의 세 호출 지점(접속·`sendLevelInfo`·`finishRespawn`)이 같다. 몹 불 보호(`LivingEntity.igniteForTicks` × `burning_time`)도 식 자체는 이미 같았다.
- **고침: 몹 장비의 인챈트 속성 효과.** `ItemStack.forEachModifier` 는 몹에게도 건다. Furnace 는 플레이어 쪽(`PlayerAttributes`)만 `EnchantAttributes` 를 읽고 몹은 아이템 `attribute_modifiers` 만 달았다. 그래서 화염 보호 갑옷을 입은 좀비·해골의 불 시간이 줄지 않았다. `LivingEntity.detectEquipmentUpdates` 가 칸 교체 때 인챈트 수정자도 떼고 단다(수정자 id `minecraft:enchantment.<이름>/<칸>`, 플레이어와 같다).
- **고침: 플레이어의 가마솥·가루눈 entityInside.** 플레이어는 `Entity` 가 아니라 이 블록들이 안 불렸다(`Region.checkInsideBlocksPlayer`). 이제 용암 가마솥은 `lavaHurt`(15초 불 + 4 피해), 물·가루눈 가마솥은 불붙은 플레이어의 불을 끄고(`mayInteract` 이면) 한 단계 줄이며(가루눈 가마솥은 같은 높이 물 가마솥으로), 가루눈은 불붙은 플레이어가 녹인다 — 바닐라는 `mobGriefing` 이 꺼져도 플레이어면 녹이므로 게임 규칙을 보지 않는다. `mayInteract` = 스폰 보호 밖 + 월드 보더 안(접속의 `core.mayInteract`). 이동 패킷이 없는 틱의 서버 쪽 move 에서도 돈다(서 있어도 용암 가마솥에서 탄다). 남은 것: 가루눈의 `setSharedFlagOnFire(false)`(그 틱 불 표시를 끄는 것)는 플레이어 플래그가 불 틱에서 만들어져 안 했다(시각만, 불 끄기는 `PlayerFire.afterMove` 가 이미 한다), 끼임 속도는 클라이언트 몫.
- **고침: 스폰 알 새끼.** 바닐라 `Mob.checkAndHandleImportantInteractions`(이름표 다음, 끈·`mobInteract` 보다 앞)는 든 알의 종류(`entity_data.id`, 없으면 알 종류)가 이 몹과 같으면 `SpawnEggItem.spawnOffspringFromSpawnEgg`: `AgeableMob` 은 `getBreedOffspring`, 아니면 같은 종류를 새로 만들어 `setBaby(true)`, 아기가 아니면(크리퍼 등) 아무것도 안 한다. 이 몹 자리에 `moveTo(…, 0, 0)` 으로 추가하고 알의 `custom_name` 을 새끼 이름으로, 알 하나 소비(크리에이티브 제외), 여우 새끼는 플레이어를 믿는다(`Fox.onOffspringSpawnedFromEgg`), 성공하면 `ENTITY_INTERACT`. 주민 알로 주민 우클릭도 이 경로(옛 "남은 차이" 해결); 떠돌이 상인은 `getBreedOffspring` 이 null 이라 넘어간다. `ItemEffects.spawnEggOffspring`, `ConnectionHandler` 의 엔티티 상호작용 분기. 새끼 스폰 이유는 플러그인에 `SPAWNER_EGG`.
- **고침(덤): 변환 때 아기 유지.** `Mob.convertTo` 의 `setBabyForConversion` 이 `AgeableMob`·`Zoglin` 에 없어 아기 호글린→조글린, 아기 좀비 주민→주민(치료)이 어른이 됐다. 바닐라 `convertTo` 는 `target.setBaby(isBaby())` 라 아기를 유지한다.
- **시험 안정화(`LandMobTest`)**: 몹·레벨 난수가 시드 없이(`nanoTime`) 만들어져 `frogBrain…`·`goatRams…`·`shulkerShoots…` 가 약 1%(시드 300개 중 5개) 확률로 흔들렸다. 서버 코드는 그대로 두고 시험이 `LegacyRandomSource.setSeed` 로 레벨·몹 난수를 고정한다(`LandMobTest.seed`, 시드 기본 20261108). AI 소비 난수가 바뀌어 이 시험들이 깨지면 `seedBase` 를 바꿔 본다.
- 시험: `SmallParityGapsTest`(화염 보호 몹 갑옷, 스폰 알 새끼 6종, 변환 아기 2종), `RegionPlayerCauldronTest`(용암·물 가마솥·가루눈 6종, 수정 전 3건 실패 확인).
- **독립 검토 반영(PR #154)**: (A) 가루눈 entityInside 가 눈을 부수면 `PlayerFire.afterMove` 의 블록 재탐색이 눈을 못 봐 불이 안 꺼졌다 → `Player.markInPowderSnow`(바닐라 `setIsInPowderSnow(true)`, 불붙었든 아니든 항상)를 afterMove 가 읽고 지우며, move 마다 `checkInsideBlocksPlayer` 시작에서 리셋한다. (B) 아기 조글린 상자 0.5 배(`Zoglin.setBaby` 가 `setDimensions`). (C) `EnchantAttributes` 에 폭발 보호(`explosion_knockback_resistance`, linear(0.15,+0.15)) 추가.
