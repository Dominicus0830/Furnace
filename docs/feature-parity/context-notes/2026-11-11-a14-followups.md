# 2026-11-11 A14 후속 — 예약 플러그인 이름 거부, Paper 스케줄러 API 연결

PR #201 이 A14-01~04·06~09·11·12 를 이미 고쳤다(보고서 항목 중 남은 것은 A14-05 책 취소 확인과 PR 댓글의 낮음 L2·L4 뿐). 청크 티켓 플러그인당 한도 옵션(`plugins.chunk-tickets.max-per-plugin`)도 11-08 에 구현돼 있었다. 이번 후속은 그 밖의 작은 후보 둘.

- **예약 이름 거부**: Paper 1.21.1 `SpigotPluginProviderFactory.build` 와 같게 `bukkit`·`minecraft`·`mojang`·`spigot`·`paper`(대소문자 무시)와 공백 든 이름을 Bukkit 형식 플러그인에서 거부한다(`CompatFormat.readDescriptor`, 공백은 `getName()` 이 `_` 로 바꾸기 전 원래 이름으로 본다). 예약어 거부는 `PluginDescription.read` 에 둬서 Furnace 설명 파일에도 적용한다 — 키 이름공간(`namespace()`)이 `minecraft` 와 겹치는 것을 막는다. 공백은 Furnace 설명 파일에서는 계속 허용(예전부터 `_` 로 바꿔 쓴다). 문구는 Paper 와 같다. 예약어를 포함할 뿐인 이름(`PaperLike`)은 된다.
- **Paper 스케줄러 API 연결**: H2 가 만든 `PaperSchedulers` 코어(전역·region·엔티티·비동기)는 Bukkit 타입이 없던 때라 시험에서만 쓰였다. 이제 `io.papermc.paper.threadedregions.scheduler.{ScheduledTask,AsyncScheduler,GlobalRegionScheduler,RegionScheduler,EntityScheduler}` 인터페이스(Paper API 와 같은 서명)를 호환 모듈에 두고 `Server#getAsyncScheduler/getGlobalRegionScheduler/getRegionScheduler`(와 `Bukkit` 정적 메서드), `Entity#getScheduler` 로 `CompatPaperSchedulers` 를 통해 코어에 닿게 했다. 꺼진 플러그인의 예약은 Paper 처럼 `IllegalPluginAccessException`. 작업 안에서 받는 손잡이와 돌려받는 손잡이는 같은 객체다(`PaperTask`, 첫 실행이 예약 호출 반환 전에 일 수 있어 아주 잠깐 기다림). 코어는 `Compat` 상태에서 처음 쓸 때 만들고 서버가 바뀌거나 종료되면 닫는다(옛 `LegacyScheduler` 없이 Paper 스케줄러만 쓴 서버도 종료 때 풀을 닫는다).
- 시험: `PaperSchedulerApiTest`(실제 컴파일한 Bukkit jar 로 연결·스레드·손잡이 동일성·꺼진 플러그인·예약 이름), `PluginDescriptionNameTest`.
- 남은 것(A14 쪽): A14-05 책 취소 클라이언트 확인(`docs/user-todo/entries/2026-11-08-audit-A14.md`, 사용자), PR #201 댓글 L2(건너뛴 `submit` future 의 `CancellationException`)·L4(긴 주기 반복 작업의 꺼진 뒤 다음 차례까지 남는 감싼 객체) — 개발 모드 누수 경고 오탐 가능성만 있어 필요해지면.

## PR #208 독립 검토 반영 (R1~R6)
Paper 1.21.1 Folia 스케줄러 원문과 대조한 검토(`furnace/reviews/a14-pr208.md`)를 반영했다. 재현은 `PaperSchedulerParityTest` 로 옮겼다.
- **R1** `AsyncScheduler.cancelTasks` 는 비동기만, `GlobalRegionScheduler.cancelTasks` 는 전역+region 만 취소한다(엔티티 작업은 어느 쪽도 안 건드림). 플러그인이 꺼질 때의 전체 정리는 그대로(`PluginTaskBook.cancelWhere`, 손잡이 `kind`).
- **R2** `EntityScheduler.execute`: 지연 1 미만은 1 로, 꺼진 플러그인도 엔티티가 살아 있으면 예외 없이 true(작업은 안 돈다).
- **R3** 비동기 `runAtFixedRate` 다음 목표를 `max(지금, 목표+주기)` 로 — 느린 회차 뒤 밀린 회차를 몰아 돌지 않는다. 비동기 인자 문구도 Paper 와 같게(`< 0`).
- **R4** `PaperTask` 의 바쁜 대기 제거: 코어 콜백이 받는 손잡이로 바로 묶는다.
- **R5** 엔티티 시험 흔들림: 플레이어의 엔티티 작업이 한 번 돌 때까지 틱을 내는 준비 단계(기존 `PaperSchedulersTest` 엔티티 시험도).
- **R6** `Entity#getScheduler()` 가 엔티티(CraftEntity)당 한 객체.
- 검토 참고, 이 PR 밖 후속 후보: Bukkit 플러그인 `onDisable` 안에서 `isEnabled()` 가 true 이고 예약이 성공함(Paper 는 false + `IllegalPluginAccessException`, 옛 `BukkitScheduler` 도 같음), `Server/Bukkit#isOwnedByCurrentRegion` 7종 없음.
