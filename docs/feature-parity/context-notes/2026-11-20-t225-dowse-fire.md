# T-225 물 물약 불 끄기 (2026-11-20)

- 바닐라 1.21.1 `ThrownPotion`: `onHitBlock` 에서 물 물약이면 `dowseFire` 를 (맞은 면 바깥 칸), (그 칸에서 면 반대쪽 = 맞은 칸), (바깥 칸의 수평 네 칸) 순서로 부른다. 불 태그→`removeBlock(pos,false)`, 켜진 양초→`AbstractCandleBlock.extinguish`, 켜진 모닥불→레벨 이벤트 1009 → `CampfireBlock.dowse` → `LIT=false` 설정.
- 터뜨림(`splash`)은 `onHit`(부딪힘 처리·projectile_land 뒤)에서 한다. 이전 Furnace 는 `onHitEntity`/`onHitBlock` 안에서 바로 터뜨려 불 끄기가 없었고 projectile_land 보다 먼저 사라졌다. 직접 맞은 대상은 엔티티 적중일 때만 넘긴다.
- 물 물약은 주변 4×2×4 의 `Axolotl.rehydrate`(공기 +1800, 최대 6000)도 부른다.
- 시험: `ThrownPotionWaterTest`. 시험 레벨은 평지라 불은 받침 블록을 깔아야 안 사라진다.
- 로드맵 번호는 T-225(T-224 다음 빈 번호). 도미니코 결정 사항 없음.
