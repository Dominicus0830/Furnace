# H7d Spigot → Mojang 대응표 함정 (2026-11-08)

- **Mojang 매핑 sha1 출처:** 1.21.1 버전 파일(piston-meta `v1/packages/82ba6501da174a665c1787775f946487422f2432/1.21.1.json`)의 `downloads.server_mappings` = sha1 `03f8985492bda0afc0898465341eb0acef35f570`, 7 456 063 바이트. 컨테이너 curl 은 piston-meta 가 403 이지만 웹 가져오기 도구로는 읽혔다. 같은 파일의 `downloads.server.sha1` `59353fb4…` = `git show origin/main:tools/vanilla-data/minecraft_server.1.21.1.jar | sha1sum` 으로 교차 확인.
- **hub.spigotmc.org 는 웹 가져오기로도 막혔다** — BuildData 커밋·csrg 해시를 잴 수 없어 Spigot 쪽은 처음 받을 때 잠그는 방식이다.
- **ASM 9.7 `Remapper` 에는 4인자 `mapInvokeDynamicMethodName` 이 없다**(2인자뿐). SAM 서술자를 모르므로 람다 인터페이스 메서드는 이름만으로 찾는다.
- **`ClassRemapper` 는 멤버 이름을 원래(바꾸기 전) 소유자·서술자로 묻는다.** 그래서 Spigot 리매퍼와 접미사 풀기를 한 `Remapper` 로 묶어도 멤버 찾기는 Spigot 이름 기준이 된다.
- **기본 패키지 클래스 이름 보호:** 난독화된 플러그인의 `a`·`b` 클래스를 Mojang 난독화 표로 바꾸면 안 된다 — 리매퍼는 `net/minecraft/`·`com/mojang/` 이고 Spigot 표에 있는 이름만 바꾼다.
- **H7 브랜치와 기준 브랜치 충돌:** PR #143 이 열린 채 기준 브랜치에 `exposeCompatToNative`(#150)·서버 라이브러리(#145)가 들어와 `PluginSettings`·`PluginBootstrapper`·`FurnaceTestServer` 가 겹친다. 레코드 성분 순서는 `…, compatOptions, chunkTicketLimit, exposeCompatToNative`.
