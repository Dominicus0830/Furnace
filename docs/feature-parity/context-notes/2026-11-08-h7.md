# H7 NMS 변환·값 shim 함정 (2026-11-08)

- **프레임 계산 없이 덫을 놓는다.** 플러그인 클래스는 COMPUTE_FRAMES 로 다시 쓰면 공통 상위 타입을 찾느라 클래스를 올려야 한다(없는 NMS 클래스면 실패). 그래서 COMPUTE_MAXS 만 쓰고, 덫은 스택 모양을 그대로 둔다: 인자·수신자를 pop → `NmsTrap.call(plugin, site, target, why)` → 결과 자리에 기본값(null/0) push. 덫은 늘 던지므로 그 기본값은 실행되지 않지만 검증기는 통과한다.
- **없는 생성자:** `NEW X; DUP; 인자…; INVOKESPECIAL X.<init>` 에서 NEW 를 ACONST_NULL 로 바꾸면, 그 사이 프레임의 "초기화 안 된 X"(LabelNode) 도 NULL 로 고쳐야 한다(삼항 인자처럼 분기가 끼면 프레임이 생긴다). NEW 와 `<init>` 은 선형 스택으로 짝짓는다.
- **정의 거부는 원래 바이트로 되돌리면 안 된다.** H6 의 `PluginClassLoader` 는 변환기 예외면 원래 바이트를 올렸다. 그러면 NMS 상속 클래스가 올라가 엉뚱한 곳에서 `NoClassDefFoundError` 가 난다. `UnsupportedOperationException`(= `UnsupportedNmsCall`)은 거부 신호로 그대로 던지도록 바꿨다(`ClassTransformer` 문서).
- **같은 이름 플러그인을 여러 시험에서 쓰면 "한 번만 WARN" 기록이 남는다.** `NmsTrap`·`NmsReflect` 의 경고 집합은 정적이다. 시험 `@BeforeEach` 에서 `resetWarnings()` 를 부른다.
- **표본 jar 의 다른 버전 모듈을 세면 strict 가 무의미해진다.** IF·signgui 는 1.8~1.21.x 모듈을 다 싣는다. 클래스 이름 표지(`v1_20_1`, `NMS_1_20_R3`, `Wrapper1_8_R3`, 범위 `v1_21_2_3`)로 1.21.1 이 아닌 모듈을 빼고 수만 알린다. `v1_21_0`(1.21) 모듈은 다른 버전으로 친다 — IF 는 1.21.1 모듈을 따로 둔다.
- **`getString()` 은 번역한다.** 바닐라 서버도 en_us 언어 파일을 싣고 있어 `Component.translatable("item.minecraft.diamond").getString()` 은 "Diamond" 다. Furnace `Text#plainText` 도 같다.
- **TestPlayer 의 끊김 이유는 텍스트가 아니다.** 끊기 패킷이면 "disconnect", 순서에 따라 소켓 오류 문자열이다. 이유 문구는 서버 로그 `<이름> lost connection: <이유>` 로 확인한다.
- **바닐라 값 근거:** 1.21.1 서버 jar(`tools/vanilla-data`)를 `javap -c -p` 로 읽었다 — kh=Vec3i, jd=BlockPos, ji=Direction, exc=Vec3, dcd=ChunkPos, akr=ResourceLocation, aa=ResourceLocationException, uc=DoubleTag, ue=FloatTag, xy=TextColor. 디컴파일 결과는 커밋하지 않았다.
- **Paper 표지로 이름 체계를 짐작할 수 없다.** commandapi 10.1.2 의 Spigot 판·Mojang 판이 `io/papermc/` 표지 수까지 같다(compat-h7 5.2).
