## 함정

- **해시에 생성자를 넣으면 거의 다 갈린다.** 코덱의 `X::new` 메서드 참조가 같은 클래스 생성자를 가리키는데, Paper 는 블록 생성자를 자주 고친다.
  처음엔 54/128 만 같았다 — 같은 클래스의 정적 메서드만 따라가게 해서 124/128.
- **shim 클래스에 리플렉션 목록을 쓰지 말 것.** 합친 Paper 멤버(moonrise 충돌 패치 형식 등)가 shim 로더에 없어 `getMethod`·`getDeclaredField` 가
  `ClassNotFoundException` 으로 터진다. 정답기는 메서드 핸들(`findStatic`·`findVirtual`·`findStaticGetter`)로 그 멤버 하나만 잇는다.
- 추출할 때 바닐라 로더를 닫으면 JVM 이 끝날 때 바닐라 스레드·로그 종료 훅이 `NoClassDefFoundError` 를 낸다 — 닫지 않는다.
- 가정: Paper 의 모양 패키지 패치(`Shapes`·`VoxelShape` 성능 패치)는 값을 바꾸지 않는다. 해시는 블록 클래스 자기 초기화만 본다. 정답기는 바닐라와 견준다.

## 남은 것

- 모양 표를 읽는 `getShape` 류 몸통(`SHAPE_BY_AGE[state.getValue(AGE)]`, `Map.get(state.getValue(FACING))` 등)은 연결 관용구가 아직 없다 — 다음 묶음 후보.
- 상태 정의·BlockGetter 지도 Proxy 는 도미니코 지시로 보류(11-27).
