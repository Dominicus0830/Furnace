# T-263 S3 — 월드 밖 엔티티 정답기(O3) 첫판 (2026-11-27)

시험: `furnace-compat-paper/src/test/java/org/domi/furnace/compat/shimgen/o3/EntityOracleTest.java`(fullShellsTest, CI vanilla-gates 단계).

## 하는 일

연결 파일(`src/shimspec/links-<판>/*.links`)이 엔티티 클래스에 단 멤버마다 바닐라와 shim 에 같은 상태·인자를 넣고 부른 뒤 반환값과 **바뀐 칸**을 견준다.

- 바닐라: 시험 자원 `o3/VanillaEntityProbe.java` 를 실행 때 바닐라 jar(캐시 목록 `vanilla-classpath.txt`)에 대고 컴파일해 바닐라 로더에 올린다.
  레벨은 `ExportEntityDataDefaults` 와 같은 가짜 `ServerLevel`(난수·레지스트리·프로파일러·피해 원천만). 저장소에는 바닐라를 부르는 코드만 있다.
- shim: 실행 때와 같은 따로 된 로더(전체 껍데기 jar 가 앞, 그 뒤 시험 실행 클래스패스)에 `ShimEntityProbe` 를 따로 올리고 시험 서버를 띄워
  플러그인과 같은 길(`EntityType#create`)로 월드 밖 엔티티를 만든다. 연결 줄 몸통은 껍데기 jar 에만 있어서 이 로더가 아니면 시험이 안 된다.
- 두 로더는 문자열만 주고받는다. 값 표기(`canon`)는 두 탐침에서 글자 그대로 같다.

## 상태와 인자

- 칸: 바이트·정수(0~15)·실수(6개 값)·참거짓·열거형(서수), 아이템 더미(4종 × 1~3개)·블록 상태(4종 기본 상태)·블록 자리·글(빈 값 포함). 그 밖 칸(홀더·주민 정보·입자 등)은 처음 값 그대로.
- 자리(0.25 단위)·방향. 멤버마다 시드가 정해진 무작위 12 가지.
- 바뀐 칸만 견준다 — 멤버와 상관없는 칸의 처음 값 차이(엔티티 난수로 정해지는 칸 등)는 이 멤버의 증명 대상이 아니다.
- 엔티티 종류는 **그 멤버를 재정의하지 않은** 것을 고른다(예: `Entity.lerpTargetX` 는 `LivingEntity` 가 재정의하므로 생물이 아닌 종류). 처음엔 아무 하위 종류나 골라 하위의 던지는 껍데기에 막혔다.

## 세는 것

- 증명: 다른 적 없음 + 바닐라 답이 상태에 따라 갈림(구분력, 설계 3.4-2).
- 구분력 없음: 바닐라 답이 늘 같다(상수, 아직 상태로 못 만드는 값 종류). 증명으로 세지 않는다.
- shim "아직 지원 안 함"(`UnsupportedNmsCall`): 틀린 값은 아니지만 증명도 아니다. 실패로 하지 않고 멤버 표에 이유를 적는다.
- 다름·그 밖 예외: 실패.
- 카나리: 다른 상태의 shim 결과와 견주면 구분력 있는 멤버마다 달라야 한다(비교가 무엇이든 같다고 하지 않는지).
