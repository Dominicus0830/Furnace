# 몹 목표 shim M1 (2026-11-24)

설계: 공유 폴더 `furnace/designs/mob-goals-shim-design-2026-11-24.md`(독립 검토 승인). 차이 결정 항목: `docs/user-todo/entries/2026-11-24-mob-goals-differences.md`.

- 월드 몹의 `goalSelector`·`targetSelector`(공개 필드, `Mob` 조각의 생성기 전용 생성자에서 채움)는 서버 선택기를 보는 shim. 모든 조작은 `NmsGoals.on` 으로 그 몹의 주인 스레드에서
  (`Entity#furnaceOnOwner` — 다른 월드 엔티티 조작과 같은 규칙). 서버 쪽은 `ChunkInternals.mobGoals` → `MobGoalsImpl`(호출마다 주인 확인).
- 목표 정체성: 서버 `Goal`·`WrappedGoal` 의 `compatView` 에 shim 하나를 붙인다. 클래스는 `GoalClasses` 가 서버 클래스에서 위로 올라가며 찾은 가장 가까운 바닐라 목표
  (서버 이름이 다른 `LookAtMobGoal`→`LookAtPlayerGoal`, `SitWhenOrderedToDoGoal`→`SitWhenOrderedToGoal`). 추상 부모뿐이면 `NmsGoals.ServerGoal`.
  바닐라 목표 클래스 67개는 `mob-goals.spec` 의 멤버 없는 class 줄(생성기 전용 생성자 → `NmsKinds.create`).
- 바닐라(Paper 1.21.1 jar javap): `removeGoal` 만 멈추고 빼고, `removeAllGoals` 는 멈추지 않는 `removeIf`. 집합 보기(`NmsGoalSet`)의 `remove/removeIf/clear` 는 서버
  `removeFromSet`(멈추지 않음 — 돌던 목표가 잠근 칸을 쥔 채 남는 것도 바닐라와 같다). 돌기 도중 빼면 `WrappedGoal.leaving` 표시로 그 패스에서 건너뛴다.
- 돌기 도중의 집합 변경은 순서 있는 미룬 목록(넣기·빼기 목록·취소된 넣기). 빼기는 판정 전에 목록에 걸어 예외여도 표시가 정리되고, 같은 패스에서 미룬 넣기도 판정해 취소한다.
  빠질 예정인 목표를 다시 넣으면 표시를 끄고 끝에서 빼고 넣는다(바닐라처럼 맨 뒤). 호환 보기(`available`·크기·contains)는 `visibleGoals` — 빠질 예정 제외, 미룬 넣기 포함.
- `WrappedGoal#isRunning`·`canBeReplacedBy` 는 주인 스레드의 지금 값(앞서 받은 객체도 `tick()` 뒤 값을 본다). 우선순위·안의 목표는 불변이라 만들 때 담는다.
- Paper `Goal#getFlags()` 반환형은 moonrise `OptimizedSmallEnumSet`(서명표에 없음 — javap 로 모양·예외 문구 확인, 손 클래스). `Goal$Flag` 순서는 Paper 대로 UNKNOWN_BEHAVIOR 가 0.
  UNKNOWN_BEHAVIOR 는 서버 목표가 쓰지 않아 `setControlFlag` 해도 바뀌는 것이 없다.
- 함정: 명세 `@each` 는 조각(손 shim)에도 몸통을 끼워 넣어 중복 정의가 된다 — 조각이 그 메서드를 쓰면 그 클래스 줄에 `-> @hand` 를 적는다(`WrappedGoal#canUse`).
- M2a: 플러그인이 상속한 목표는 `GoalSelector#addGoal` 때 서버 어댑터(`ChunkInternalsImpl.CompatGoal`, 콜백 `NmsPluginGoal`)로 넣는다. 보기는 플러그인 목표 객체 그대로,
  같음은 그 객체의 equals, `removeGoal` 은 같은 객체로 찾는다. 예외는 로그 한 번 뒤 그 목표만 멈추고, 플러그인이 꺼지면 두 선택기에서 빠진다(꺼진 뒤 stop 도 부르지 않는다).
  Paper `Goal` 은 깃발을 살아 있는 `goalTypes` 로 갖고 비면 UNKNOWN_BEHAVIOR(javap) — 플러그인 목표는 그대로 두고 서버는 확인마다 비트를 읽는다(서버는 UNKNOWN 칸을 쓰지 않음, user-todo G4).
- 아직: 바닐라 목표 생성자·플러그인이 만든 감싼 목표를 집합에 바로 넣기는 M2b, 월드 밖 몹의 선택기는 M3 — 지금은 UnsupportedNmsCall. 선택기 필드를 새 객체로 바꿔 끼우는 것·`aware` 필드 쓰기는 서버에 닿지 않는다(지원 밖).
