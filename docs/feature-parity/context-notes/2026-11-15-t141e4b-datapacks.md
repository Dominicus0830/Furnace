# T-141 E4b: Paper 데이터팩 API (2026-11-15)

FAWE 2.16.2 디버그 붙여넣기(`Server#getDatapackManager().getEnabledPacks()` → `Datapack#getName`)와 B6 코퍼스 `io.papermc.paper.datapack.Datapack`(WorldGuard 1곳).
기준은 Paper 33ff3dff `Add-basic-Datapack-API.patch`(PaperDatapack·PaperDatapackManager)와 Youer 1.21.1 API 사본.

## 무엇을
- furnace-api `Furnace#dataPacks()` → `DataPacks`(새 패키지 `org.domi.furnace.api.datapack`).
  - 팩 사본 record: id, 제목, 설명, required, 호환, 요청 기능, 출처, 켜짐, 채팅 링크.
  - refresh, available(이름 순), enabled(적용 순서), find, setEnabled(future).
  - 서버 구현 `DataPacksImpl` 이 `PackRepository` 를 읽는다.
  - setEnabled 는 /datapack enable·disable 과 같다(바닐라 `Pack.insert` 기본 자리, `DataPackManager.reload`, 비동기).
  - 이미 그 상태면 아무것도 안 한다. 없는 id 면 Paper 문구 그대로 ISE("Cannot toggle state of pack that doesn't exist: …").
- 호환 `io.papermc.paper.datapack`: Datapack·DatapackManager·DatapackSource(+Impl), `Server#getDatapackManager`·`Bukkit.getDatapackManager`.
  - 구현은 `CompatDatapacks`.
  - Datapack 은 만들 때의 사본이다(isEnabled 는 그때 값, equals 는 Object 그대로). 모두 Paper 와 같다.
- `org.bukkit.FeatureFlag`: VANILLA·BUNDLE·TRADE_REBALANCE, 폐기된 UPDATE_1_20·UPDATE_121.
  - `getRequiredFeatures` 는 지금 쓰는 세 플래그만 옮긴다. 폐기·모르는 플래그는 빠진다(Paper PaperFeatureFlagProviderImpl 표와 같다).

## Paper 와 다른 점(알고 둔 것)
- **Adventure Component 를 돌려주는 `getTitle`·`getDescription`·`computeDisplayName` 은 없다.** 호환 계층이 Adventure 를 싣지 않는다(다른 Component API 와 같은 한계).
  - furnace-api 사본에는 제목·설명·채팅 링크가 있다. Adventure 를 싣게 되면 이어 붙이면 된다.
- `FeatureFlag.ALL_FLAGS`(Adventure Index)도 같은 이유로 없다.
- Furnace 플러그인 jar 팩의 출처는 `DatapackSource` "plugin" 이다.
  - Paper 는 모르는 출처를 `new DatapackSourceImpl(source.toString())` 로 만든다. 그래서 `DatapackSourceImpl` 을 public 으로 뒀다(Paper 는 패키지 전용).
- setEnabled 뒤 Paper 는 `ServerResourcesReloadedEvent(PLUGIN)` 을 부르지만, 호환 계층에 그 이벤트가 아직 없다.
- 시험 서버(FurnaceTestServer)는 데이터 팩 없이 떠서 목록이 비어 있다. 켜고 끄기는 서버 시험 `DataPacksApiTest`(DataPackManager 를 붙인 코어)가 본다.
