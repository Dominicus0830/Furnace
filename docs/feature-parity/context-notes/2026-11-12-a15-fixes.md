# A15 점검 작은 수정 묶음 — Paper 1.21.1 대조 기록 (2026-11-12)

보고서 `docs/audit/findings/A15-bukkit-paper-api-surface.md` 의 A15-01(일부)·02·03·04(`isDropItems`)·08·09·10·11 을 고쳤다. 회귀 시험 `A15ConfigParityTest`(서버 없이)·`A15PluginSurfaceParityTest`(헤드리스 서버).

- **설정 읽기(A15-03)**: Paper `MemorySection#get(path, def)` 는 자기 데이터만 보고 없으면 def 다. 기본값 구역은 인자 하나짜리 getter 가 def 로 넘길 때만 쓴다. `getInt/getLong/getDouble` 은 `Number`, `getBoolean` 은 `Boolean` 일 때만 값을 쓴다(따옴표 친 `'5'` 는 def). Furnace API `ConfigSection` 의 너그러운 규칙(문자열 숫자 허용, 기본값 구역 먼저)은 그대로 두고 호환 `MemorySection` 에서만 Paper 규칙으로 읽는다. 함정: `JavaPlugin#getConfig()` 는 jar 의 config.yml 을 기본값 구역으로 달아서, 이 차이가 "사용자가 지운 키" 에서 바로 보인다.
- **copyDefaults(A15-11)**: 합친 보기만 돌려주고 데이터는 그대로다. 순서가 함정: Paper `getKeys` 는 `LinkedHashSet` 에 기본값 키를 먼저 넣어 기본값 순서(a,b,c,d)지만, `getValues` 는 자기 키를 `remove` 뒤 `put`(SPIGOT-4558)해서 기본값에만 있는 키가 앞선다(b,d,a,c). `saveToString` 은 단계마다 `getValues(false)` 로 쓰므로 파일도 b,d,a,c 이고 저장이 데이터를 바꾸지 않는다 — Furnace 는 쓰기용 합친 사본을 새로 만들어 쓴다(주석은 값이 온 쪽 것, 점 든 literal 키는 주석 없이). 빈 설정은 `""`(Paper `BLANK_CONFIG`).
- **직렬화(A15-01 일부)**: `Location`(별칭은 클래스 이름, 키 world·x·y·z·yaw·pitch, 모르는 월드면 `IllegalArgumentException("unknown world")`)·`Vector`(`@SerializableAs("Vector")`)·`PotionEffect`(`@SerializableAs("PotionEffect")`) 를 등록부에 더했다. 등록은 별칭과 클래스 이름 둘 다라 옛 Furnace 가 클래스 이름으로 쓴 PotionEffect 도 읽힌다. `getLocation/getVector/getColor` 와 isX 를 `ConfigurationSection` 에 더했다. 남은 것: `OfflinePlayer`(별칭 `Player`), `BlockVector`·`BoundingBox`·`Pattern`·`SpawnRule`, Location·Vector 의 나머지 멤버(A15-06).
- **리소스(A15-02)**: 호환 플러그인 로더만 `getResource`=`findResource`, `getResources`=`findResources`(Paper `PluginClassLoader`). `libraries:` jar 는 같은 로더 URL 이라 함께 보인다. 네이티브 플러그인 로더는 그대로 부모 먼저.
- **getOnlinePlayers(A15-08)**: 서버마다 하나인 고칠 수 없는 살아 있는 `List`(Paper `unmodifiableList(Lists.transform(...))` — `List` 캐스팅이 되고, `clear`·`removeIf` 는 비어 있어도 던진다). 순회할 때마다 그때 접속자를 어댑터로 바꾼다.
- **ChatColor(A15-10)**: Paper `getHexColor` 는 `§x` 의 x 를 소문자만 받고, 숫자 자리는 0-9a-fA-F.
- **메타데이터(A15-09)**: CraftBukkit 1.21.1 `PlayerMetadataStore` 는 UUID 로 가른다(옛 Bukkit 은 이름 소문자였다 — 옛 문서를 보고 이름으로 하지 말 것).
- **남은 것(후속)**: A15-01 `OfflinePlayer`·`BlockVector`·`BoundingBox`·`Pattern`·`SpawnRule`, A15-04 `isNewChunk`·`getExpToDrop`, A15-05 `pathSeparator`, A15-06 값 클래스 멤버, A15-07 같은 우선순위 순서. 월드가 있는 `Location` 저장·되읽기는 헤드리스 시험이 아직 없다(PR #247 검토 R3).
