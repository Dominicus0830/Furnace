  region 스레드가 아직 색인에 넣기 전이라 null — 부하(바쁜 반복 4개) 속 반복 80번 중 13번 `ClientboundAddEntityPacket:null`. 바닐라는 `PersistentEntitySectionManager.startTracking` 에서
  `visibleEntityStorage.add` 다음에 `onTrackingStart → ChunkMap.addEntity` 로 추적하고, Paper 도 EntityLookup 에 넣은 뒤 추적한다. → 색인을 추적 앞으로 옮김. 고친 뒤 80번 중 null 0번.
  덤으로 `PlayerTrackEntityEvent` 처리기가 엔티티를 지우면 예전엔 지운 뒤 다시 색인에 넣어 유령이 남을 수 있었는데, 이제는 순서상 생기지 않는다.
  결정적 회귀 시험: `furnace-test` 의 `EntityIndexBeforeSpawnTest`(같은 region 스레드의 `PlayerTrackEntityEvent` 안에서 `entityUuidById` 가 비어 있으면 실패 — 고치기 전 매번 실패).
