## 2026-11-11 A11 높음 4건: 가루눈 냉각·플레이어 질식·낙하 면역·전도체의 힘 (a11-high)

점검 보고서 `docs/audit/findings/A11-entity-physics-combat.md` 의 A11-01~04. 회귀 시험 `entity/A11HazardTest`(9개)·`world/A11SuffocationTest`(2개).

### 바닐라 근거(1.21.1 `javap -c -p`)
- 냉각 `btn.m_`(aiStep) 오프셋 678~807, travel 바로 뒤: `!isDeadOrDying` 이면 `isInPowderSnow && canFreeze` → `min(140, +1)`, 아니면 `max(0, −2)`. 그다음 `removeFrost`(`btn.dY`)·`tryAddFrost`(`btn.dZ`: `getBlockStateOnLegacy` 가 공기가 아니고 ticksFrozen > 0 이면 이동 속도에 `minecraft:powder_snow` −0.05 × 언 비율, ADD_VALUE, transient). 이어 `tickCount % 40 == 0 && isFullyFrozen && canFreeze` 면 `freeze` 1.
- `LivingEntity.canFreeze`(`btn.dC`): 관전자 아님 + 머리·몸통·다리·발·몸 칸 중 `#freeze_immune_wearables` 없음 + `Entity.canFreeze`(`#freeze_immune_entity_types` 아님).
- 피해 5배: `btn.a(brk,F)` 오프셋 152, 방패 막기 판정 뒤·투구 판정 앞. `#is_freezing` && `#freeze_hurts_extra_types`.
- 질식 `btn.aw` 오프셋 91~229: `isAlive` 면 `isInWall` → `in_wall` 1, **else if** 플레이어이고 보더 밖이면 보더 피해. 즉 같은 틱에 둘이 겹치지 않는다. `Player`·`ServerPlayer` 는 `aw`·`canFreeze` 를 덮어쓰지 않는다.
- 호흡 `btn.aw` 오프셋 270~541: `canBreatheUnderwater || MobEffectUtil.hasWaterBreathing(bsa.c: 물숨쉬기·전도체의 힘) || (플레이어 && abilities.invulnerable)` 이면 줄지 않고, **물속에서는 채우지도 않는다**(채움 가지 518 은 눈이 물 밖이거나 거품 기둥일 때만). 보고서 A11-09 는 이 점에서 틀렸다(보고서에 정정 표시).
- 낙하 면역: `btn.e(FF)I` 맨 앞 `#fall_damage_immune` → 0, `bsr.b(brk)` 에 `#is_fall && #fall_damage_immune`.

### 구현 메모
- 몹: `LivingEntity.tickFreezing`(aiStep 의 travel 뒤). 얼음 수정자는 몹 속성 저장에서 뺀다(transient).
- 플레이어: 엔티티 계층 밖이라 `PlayerVitals.tickFreezingLocked` 가 같은 식을 돈다. `isInPowderSnow` 는 `Player.inPowderSnowThisTick`(틱 머리에서 지우고 서버 move 의 `checkInsideBlocks` 가 켬). DATA_TICKS_FROZEN 은 `Player.syncLivingFlags`(본인·보는 사람·페어링), 얼음 속도 수정자는 `Player.locatedModifiers` → `syncAttributes`. 불에 녹기는 `PlayerFire.tick`(레벨 이벤트 1009). 저장 `TicksFrozen`, 리스폰 시 0.
- 플레이어 `getBlockStateOnLegacy` 는 `PlayerProbe.onPosLegacyState`(받침 블록 방식). 냉각 피해는 효과 피해(runPendingEffectHurts) 뒤에 입힌다(바닐라 eo 가 aiStep 보다 먼저). 가죽 검사는 가루눈 밖에서도 한다(TicksFrozen 은 load 에서 잘리지 않아 140 을 넘을 수 있다) — PR #200 검토 R1~R3.
- NoAI 몹: 바닐라는 move 하지 않아 얼지 않지만 Furnace 는 NoAI 몹도 move 하므로 이제 언다(아래 NoAI 차이에 포함).
- 질식 시험 함정: 눈 칸 하나만 막으면 바닐라도 `updatePlayerPose` 가 수영 자세로 바꿔 질식하지 않는다. 발·눈 두 칸을 막아야 한다. 자연 회복(허기 18 이상)이 피해를 가리므로 허기를 17 로 둔다.

### 이번에 찾은 다른 차이(고치지 않음, 후속 후보)
- **NoAI 몹이 움직인다**: 바닐라 `Mob.isEffectiveAi`(`btp.db`) = `!isNoAi`, `LivingEntity.travel` 은 `isControlledByLocalInstance`(→ isEffectiveAi) 일 때만 move 한다. 그래서 NoAI 몹은 중력·밀림·`checkInsideBlocks`(가루눈·거미줄 표시) 없이 제자리다. Furnace `LivingEntity.travel` 에는 이 문이 없어 NoAI 몹이 떨어진다. 시험이 NoAI 로 몹을 붙잡아 두는 곳이 많아 영향 범위를 따로 봐야 한다.
- **`#damages_helmet` 피해(떨어지는 모루·종유석) 투구 0.75 배와 투구 내구도**가 `LivingEntity.hurtByInner` 에 없다(`btn.a(brk,F)` 오프셋 181~213).
- 몹 `aiStep` 의 물 민감(`isSensitiveToWater`) 피해 위치가 바닐라는 push 뒤 맨 끝(오프셋 878~911), Furnace 는 점프 앞.
