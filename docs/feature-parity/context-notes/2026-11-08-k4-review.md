## K4(PR #89) 사후 검토 반영 (2026-11-08)

- Bukkit `InventoryView#setTitle` 은 Paper 처럼 그 플레이어 창 하나만 바꾼다(같은 인벤토리를 보는 다른 사람·다시 연 창은 createInventory 제목, null 은 IllegalArgumentException). 네이티브 `Player#retitleMenu`·`Player#menuTitle(Menu)` 를 더했다. `Menu#setTitle`(모두·다음에 여는 사람)은 그대로.
- `stopSound` 가 리소스 id 가 아닌 이름을 막는다(바닐라 클라이언트 접속 끊김 방지). `Sound` 높이 범위 0~2(바닐라 `/playsound`).
- 메뉴 제목 경합 2건(여는 도중 바뀐 제목, 거꾸로 온 알림): `MenuSession` 이 화면에 보낸 제목을 기억하고 연결 스레드에서 그때 제목으로 맞춘다.
- 시험: `MenuTitleSoundParityTest`, `InventoryViewTitleTest`. 보고서: 프로젝트 파일 `reviews/k4-pr89-review.md`.
