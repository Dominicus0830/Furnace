## 2026-11-08 P3 채팅·표시 이름 (p3-chat)

`docs/feature-parity/paper-vs-spigot-2026-11-08.md` 의 C2·C3·C5·D2 를 구현했다. 원문 근거는 Paper 1.21.1(커밋 `33ff3dff`) 패치: `Adventure.patch`(ChatProcessor·CraftPlayer displayName), `Fix-kick-event-leave-message-not-being-sent.patch`.

**무엇이 바뀌었나**
- **C2 받는 사람.** `AsyncPlayerChatEvent#getRecipients()` 는 바꿀 수 있고 서버가 따른다. Furnace `AsyncChatEvent#recipients()`(변경 가능, UUID 로 구분, 처음 부를 때 접속자 전원 사본)를 새로 만들고, Bukkit 쪽은 그 위의 뷰다. 서버(`handleChat`)는 만졌을 때만(`recipientsTouched`) 남은 UUID 에게만 보낸다. 서명 채팅·`chat.unsigned-as-system`·`renderer` 세 경로 모두 걸러진다. **콘솔 로그는 받는 사람과 상관없이 남는다**(Paper `viewersFromLegacy` 가 콘솔을 늘 넣는 것과 같다). 보내는 사람을 빼면 자기 채팅도 못 본다(CraftBukkit·Paper 와 같다).
- **C3 표시 이름.** `Player#getDisplayName()` 은 플레이어 이름 그대로(Paper `adventure$displayName = text(이름)`), `setDisplayName(String)` 지원(§ 서식, null=이름 그대로, 접속을 끊으면 사라짐). 저장은 서버 `Player.customDisplayName`(Furnace API `Player#customDisplayName`). 정해 두면 서식을 안 바꿔도 바닐라 채팅 "<이름>" 이 그 이름으로 나가고(`ConnectionHandler#handleChat` 이 `chatDisplayName()` 사용), 레거시 서식 `%1$s` 도 표시 이름이다.
- **C5 킥 퇴장 문구.** `PlayerKickEvent#setLeaveMessage` 지원. Furnace `PlayerKickEvent#leaveMessage` 를 새로 만들었고, 바꾸면 끊긴 뒤 퇴장 처리에서 `PlayerQuitEvent` 의 처음 메시지가 된다(SPIGOT-3034). null·빈 문자열이면 알림 없음. 기본값은 지금처럼 `"§e이름 left the game"`.
- **D2 주소 링크.** Bukkit `sendMessage(String)` 만 글 속 주소를 `OPEN_URL` 클릭 링크로 만든다(`Compat.message`). 규칙은 CraftBukkit `CraftChatMessage` 패턴: 대소문자 무시, 끝 문장부호(`. ? ! , ; :`)는 링크에서 뺀다, 포트·경로·쿼리는 공백·줄바꿈·§ 전까지 포함, 스킴이 없으면 `http://` 를 붙인다. 스타일(밑줄·색)은 더하지 않는다. **`broadcastMessage` 는 링크가 없다** — Paper 1.21.1 `CraftServer.broadcast` 는 `legacySection().deserialize` 라서다(Spigot 은 링크가 생기는 Paper≠Spigot 차이; 독립 검토 PR #151). API 공용 `DEFAULT_URL_PATTERN` 은 그대로 두고 직렬화기에 `urlScheme(…)` 옵션만 더했다.

**남은 차이(알고 둔 것)**
- 바닐라 경로(플러그인이 `setDisplayName` 을 안 부름)의 채팅 이름은 Furnace 가 바닐라처럼 팀 접두·접미·클릭·호버가 붙은 이름이다. Paper 는 `adventure$displayName`(순수 이름)을 쓰므로 팀 접두가 채팅에 안 보인다. "플러그인이 끼지 않으면 바닐라와 같게" 라는 방침에 따라 Furnace 쪽을 유지했다. 바꾸고 싶으면 `ConnectionHandler#handleChat` 의 `chatDisplayName()` 한 줄.
- 링크 패턴·`http://` 접두는 Paper 최신 main 의 `CraftChatMessage` 원문으로 확인했다(1.8 이래 같은 코드라 1.21.1 도 같다고 본다; 1.21.1 본문 직접 확인은 못 함).
- Paper 의 `sendMessage(String)` 은 `\n` 에서 줄을 나눠 따로 보낸다. Furnace 는 아직 한 메시지로 보낸다(이번 범위 밖).
- Paper 의 `PlayerChatEvent`(동기 옛 이벤트)와 `io.papermc.paper.event.player.AsyncChatEvent` 는 이 묶음 밖.
- `PlayerKickEvent#getLeaveMessage()` 의 기본 문구는 Paper 가 번역 컴포넌트에서 만든 영어, Spigot 은 `"§e이름 left the game."`(마침표) — Furnace 는 마침표 없는 Paper 쪽.
