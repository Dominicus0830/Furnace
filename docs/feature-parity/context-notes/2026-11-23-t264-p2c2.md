# T-264 P2c-2 — 월드 높이 지도 조회 (2026-11-23)

- 바닐라 1.21.1 `Heightmap$Types`(jar 바이트코드로 확인): `WORLD_SURFACE_WG`·`WORLD_SURFACE` 는 둘 다 `NOT_AIR`, `OCEAN_FLOOR_WG`·`OCEAN_FLOOR` 는 둘 다 `MATERIAL_MOTION_BLOCKING`. 차이는 쓰임(`WORLDGEN` / `CLIENT`·`LIVE_WORLD`)뿐.
- 바닐라 `ChunkAccess#getHeight(type, x, z)`: 그 지도가 청크에 없으면 `Heightmap.primeHeightmaps(this, EnumSet.of(type))` 로 지금 블록에서 만들고 `getFirstAvailable - 1` 을 준다. 다 만든 청크(`LevelChunk`)는 *_WG 지도를 들고 있지 않으므로 Bukkit `getHighestBlockYAt(x, z, *_WG)` 은 처음 부를 때 술어가 같은 살아 있는 지도와 같은 값이다.
- 함정: 그렇게 만든 *_WG 지도는 `LevelChunk#setBlockState` 가 갱신하지 않는다(살아 있는 넷만 갱신) — 바닐라·Paper 는 그 뒤 블록 변화에 낡은 값을 준다. Furnace 는 살아 있는 지도로 답해 늘 지금 값이다. 생성 때 얼려 둔 Furnace 쪽 WG 값(carve 시점)은 바닐라의 "처음 부를 때 지금 블록" 과 다르니 이 조회에 쓰지 말 것.
