# 2026-11-12 H4 묶음 D (인벤토리 이벤트) 함정

- Bukkit `CraftItemEvent`·`PrepareAnvilEvent` 는 자기 `HandlerList` 가 없다 — 처리기 목록은 부모(`InventoryClickEvent`, `PrepareInventoryResultEvent`)의 것.
  EventBridge 짝의 Bukkit 클래스는 **처리기 목록을 가진 클래스**로 등록해야 한다(`CompatPluginManager.registrationClass` 가 위로 찾아 올라간다).
  같은 리스너에 `InventoryClickEvent` 와 `CraftItemEvent` 처리기가 둘 다 있으면 제작 클릭 하나가 두 처리기에 모두 온다(Paper 와 같다).
- Paper 원문 확인 경로: `raw.githubusercontent.com/PaperMC/Paper/main/paper-server/patches/sources/net/minecraft/server/network/ServerGamePacketListenerImpl.java.patch`
  (클릭 → ClickType·InventoryAction·CraftItemEvent), `.../world/level/block/entity/BrewingStandBlockEntity.java.patch`(BrewEvent 결과),
  `paper-server/src/main/java/org/bukkit/craftbukkit/event/CraftEventFactory.java`(callPreCraftEvent, callPrepareResultEvent). 최신 main 이라 1.21.1 과 다를 수 있다 — 묶음 주머니(1.21.2+) 분기는 무시.
- 결과 칸(놓을 수 없는 칸)의 PICKUP 은 보통 칸과 다르다: 커서가 있으면 같은 아이템이고 합쳐 한 묶음에 들어갈 때만 `PICKUP_ALL`, 아니면 `NOTHING`(`CompatInventories.resultAction`).
- 닫기 이벤트 순서를 바꿨다(이벤트 → 메뉴 세션 끝). Furnace `Menu#onClose` 가 이벤트보다 먼저라고 가정한 코드가 있으면 깨진다.
