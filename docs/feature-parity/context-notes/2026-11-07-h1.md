## 2026-11-07 Bukkit·Paper 호환 어댑터 뼈대 (H1, 불만 표 69·106번)

문서: `docs/api/compat-paper.md`. 코드: `furnace-api/.../plugin/PluginFormat`, `furnace-server/.../plugin/PluginBootstrapper`·`PluginManagerImpl`(형식 연결), `furnace-compat-paper/`.

- **범위 해석**: H1 을 "로더 + 이벤트 1차"로 읽었다. 이미 Furnace 에 있는 이벤트 중 Bukkit 에도 같은 뜻이 있는 24종만 잇고, 그 이벤트가 쓰는 `Player/World/Block/Entity/Server` 최소 보기만 만들었다. 명령·스케줄러는 H2, 아이템·인벤토리는 H3 로 남겼다.
- **SPI 방식**: 서버 모듈이 호환 모듈에 의존하지 않도록 `PluginFormat`(ServiceLoader)을 두었다. 서버는 설명 파일 이름 목록을 받아 후보를 만들고, 로드할 때 `format.create(ctx, mainClass)` 로 `FurnacePlugin` 을 받는다. `fatJar` 가 호환 모듈 jar 를 합친다. 서버 시험의 클래스패스에는 호환 모듈이 없으므로 기존 "Bukkit jar 는 건너뜀" 시험은 그대로다.
- **함정(하니스 경로)**: `ServerCore` 는 `PluginHost(this, Path.of("plugins"))` 로 상대 경로를 쓰는데 `FurnaceTestServer` 는 절대 경로(임시 폴더)로 부트스트랩한다. 그래서 `dir.relativize(file)` 이 "different type of Path" 로 터지고 데이터 폴더가 임시 폴더 밖(작업 디렉터리의 `plugins/`)에 생겼다. 운영에서는 둘 다 상대라 문제없다. `PluginManagerImpl.directory(Path)` 를 열어 하니스가 맞춘다.
- **`api-version`**: Bukkit 의 `api-version` 은 "1.21" 처럼 패치 없이 쓴다. 서버의 `ApiVersion` 검사는 Furnace 플러그인용이라 형식 플러그인에는 건너뛰고, `CompatFormat.checkApiVersion` 이 1.21.1 보다 새로우면 거절한다. 없으면 경고(Bukkit 도 `Legacy plugin` 으로 경고).
- **`paper-plugin.yml`**: `dependencies.server.<이름>.load=BEFORE` 는 "그 플러그인이 이 플러그인보다 먼저", `AFTER` 는 "이 플러그인 뒤" 라서 Furnace 의 `depend/softdepend`(앞)와 `loadbefore`(뒤)로 옮긴다. `required: false` 면 softdepend. `bootstrapper`·`loader` 항목은 해석하지 않는다(무시).
- **이벤트 다리**: Furnace 이벤트 하나에 Bukkit 이벤트 객체 하나를 `WeakHashMap` 으로 공유한다. 처리기가 값을 바꿨는지는 바뀐 경우에만 되돌려 쓴다(채팅 서식 `<%1$s> %2$s` 는 기본값이면 건드리지 않아 Furnace 의 이름 서식을 깎지 않는다). 취소 상태는 구독 전후로 양쪽을 맞춘다.
- **스레드**: Bukkit 처리기는 Furnace 이벤트를 부르는 스레드에서 돈다(채팅은 비동기 스레드). 메인 스레드 직렬화는 H2.
- **확인 못 한 것(가정)**: Bukkit 이벤트 클래스의 모든 보조 메서드와 `getHandlerList` 규약은 기억에 의존해 새로 썼다(실제 Bukkit jar 와 대조하지 못했다 — 컨테이너에서 hub.spigotmc.org·papermc 접근 불가). 실제 플러그인 하나로 확인이 H4 의 일이다. `Material` 에는 `LEGACY_*` 가 없다.
