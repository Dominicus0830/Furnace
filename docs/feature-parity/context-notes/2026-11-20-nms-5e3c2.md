# NMS shim 5e-3c-2 함정 (2026-11-20)

- **아이템 구성요소 바이트 차례:** Paper `ItemStack.OPTIONAL_STREAM_CODEC` 은 구성요소 패치를 넣은 차례(Reference2ObjectArrayMap)로 쓴다. Furnace API 아이템은 구성요소를
  `TreeMap`(이름 차례)으로 들고, 서버 코덱도 그 차례로 쓴다. 바이트 대조 시험은 같은 차례로 넣은 스택만 맞는다 — 다른 차례는 "Paper 바이트를 읽어 같은 아이템"으로 확인한다.
- Paper 는 아이템 패치를 쓸 때 `ComponentSerialization.DONT_RENDER_TRANSLATABLES` 를 켠다(서버 쪽 번역 렌더링을 끈다). Furnace 는 원래 서버에서 번역하지 않아 같은 결과다.
- **바닐라 `FluidState#tick`·`BlockState#tick` 은 받은 상태로 돈다**(칸을 다시 읽지 않는다). 돌 칸에 경작지 상태로 틱을 부르면 경작지 동작(위가 막혀 흙)이 돈다 —
  다리도 상태 번호·유체 값을 받는다.
- 패킷 shim 편의 메서드(`forChunks`·`ChunkBiomeData(LevelChunk)`)는 생성되는 shim 이라 `src/shimgen/resources/packet-shim-extras.txt` 에 쓴다(src/main 에 손으로 쓴 클래스를 두면
  생성기가 그 클래스를 만들지 않아 스키마 다리 대상에서 빠진다).
