# NMS 호환 H7d: Spigot 이름 → Mojang 이름 대응표 (선택해서 켤 때만 내려받기) — 2026-11-08

사용자 결정 9: 대응표는 저장소·서버 jar 에 싣지 않고, **운영자가 켤 때만**, **필요한 플러그인이 있을 때만** 운영자 컴퓨터에서 받는다.
목표: CommandAPI(Spigot 판)처럼 Spigot 이름으로 컴파일된 NMS 플러그인이 로더를 지나 Mojang 이름 shim 에 이어지게 하기 — Paper 가 Spigot 이름 플러그인을 올릴 때 하는 변환과 같은 결과.

## 1. 켜는 법 (furnace.properties)

| 키 | 기본 | 뜻 |
|---|---|---|
| `plugins.compat.nms.spigot-mappings` | `off` | `download`: Spigot 이름 NMS 플러그인이 있을 때만 재료 세 파일을 처음 한 번 받아 캐시에 둔다. `files`: 받지 않고 아래 경로를 쓴다. `off`: 바꾸지 않는다(그 NMS 호출은 H7 덫에 걸린다) |
| `plugins.compat.nms.spigot-mappings.files` | (빈칸) | `files` 모드의 Mojang `server.txt`, Spigot 클래스 csrg, Spigot 멤버 csrg 경로(경로 구분자 `;`/`:` 로 잇는다) |

캐시는 `plugins.libraries.cache`(기본 `plugins/.libraries`) 아래 `spigot-mappings/1.21.1/`. `plugins.libraries.offline=true` 면 네트워크에 나가지 않고 손으로 둔 파일을 쓴다. 꺼져 있으면 로드 보고가 "Spigot 이름 jar 로 보인다 … spigot-mappings=download 를 쓰면" 을 알린다.

## 2. 무엇을 받나 (체크섬)

| 파일 | 출처 | 검사 |
|---|---|---|
| `server.txt` (Mojang 공식 서버 매핑, ProGuard) | `https://piston-data.mojang.com/v1/objects/03f8985492bda0afc0898465341eb0acef35f570/server.txt` | **sha1·크기 코드 고정**(`03f89854…`, 7 456 063 바이트). 값은 Mojang 버전 목록 → 1.21.1 버전 파일(`82ba6501…`)의 `downloads.server_mappings` 에서 옮겼고, 같은 파일의 `downloads.server.sha1`(`59353fb4…`)이 저장소 `main` 의 바닐라 1.21.1 서버 jar 해시와 같음을 확인했다 |
| `bukkit-cl.csrg`·`bukkit-members.csrg` (Spigot BuildData) | `hub.spigotmc.org/versions/1.21.1.json` 의 `refs.BuildData` 커밋 → `builddata/raw/info.json?at=<커밋>` 의 `classMappings`·`memberMappings` | Spigot 은 체크섬을 내지 않고 이 컨테이너에서 hub.spigotmc.org 가 막혀 값을 잴 수 없었다. 그래서 **info.json 의 `mappingsUrl` 이 위 Mojang sha1 을 가리키는지 확인**하고, 처음 받은 커밋·sha256 을 `spigot-mappings.lock` 에 적어 그 뒤로는 다른 커밋·바이트를 거부한다(처음 쓸 때 믿기). 코드 고정은 사용자 확인 뒤(user-todo) |

내려받기는 H4 묶음 B 와 같은 `LibraryResolver.HttpFetcher`(시간 제한·재시도·크기 상한)·캐시 폴더·오프라인 키를 쓴다(`SpigotMappingFiles`).

## 3. 언제 받나 / 어떤 jar 에 거나

- 서버(`PluginBootstrapper#compatOptionsFor`): 호환 jar 마다 `SpigotMappingFiles.needs` — 매니페스트 `paperweight-mappings-namespace` 가 없거나 `spigot` 이고(Paper 와 같은 판정, H7 5.2 측정: Paper 표지는 못 씀), 클래스 파일에 `net/minecraft/`·`net.minecraft.` 가 보이면 필요. 처음 필요한 jar 에서 한 번 받고(실패도 한 번만 경고), 그 경로를 그 jar 의 호환 설정에 넣는다.
- 호환 모듈(`CompatFormat` → `NmsClassTransformer.forJar`): 경로가 있으면 `SpigotMappings` 를 읽고(파일·수정 시각이 같으면 한 번만), 매니페스트가 Mojang 이면 쓰지 않는다.

## 4. 바꾸는 법

- **바이트코드:** `SpigotRemapper`(ASM `Remapper`)를 CraftBukkit 접미사 풀기와 같은 걸음에 건다. Spigot 이름 → 난독화 이름(csrg 거꾸로) → Mojang 이름(ProGuard). 멤버는 Spigot 이 붙인 이름이면 먼저 난독화 이름으로 되돌린다. 덫(H7a)·보고는 바뀐 Mojang 이름으로 판정한다.
- **상속된 멤버:** 참조한 클래스에 선언이 없으면 이 서버 shim 클래스 파일의 상위 사슬(`NmsSymbols`, Mojang 이름 → 난독화)로 찾는다(shim 이 없는 클래스는 어차피 덫). 그래도 없으면 같은 난독화 이름·서술자를 선언한 모든 클래스가 **한 Mojang 이름으로 모일 때만**(재정의) 그 이름을 쓰고, 갈리면 그대로 둔다 → 덫. 조용히 엉뚱한 멤버로 잇지 않는다.
- **리플렉션:** Paper 처럼 Spigot 이름 플러그인의 문자열 이름을 바꾼다 — `Class.forName`·`loadClass`·`Lookup.findClass`(배열 이름 포함), `getDeclaredField/getField/getDeclaredMethod/getMethod`, `Lookup.find*`. 메서드는 실행 중 인자 클래스(Mojang 이름)를 난독화 서술자로 바꿔 찾는다(반환형 없이).
- **람다:** NMS 함수형 인터페이스를 구현하는 람다의 메서드 이름은 이름만으로(ASM 9.7 이 SAM 서술자를 주지 않음) 그 클래스 사슬에서 한 이름으로 풀릴 때만 바꾼다.
- 플러그인 자기 클래스, `net/minecraft/`·`com/mojang/` 밖 이름은 건드리지 않는다(기본 패키지의 난독화된 플러그인 클래스 `a`·`b` 가 Mojang 난독화 이름과 겹쳐도 그대로).

## 5. 한계

- **실제 표로 돌려 보지 못했다.** Mojang·Spigot 매핑 원본을 이 컨테이너에서 받을 수 없다(piston-data·hub.spigotmc.org 프록시 403). 형식은 ProGuard(줄 번호 앞머리·인라인 꼬리 포함)와 csrg(클래스 2칸, 필드 3칸, 메서드 4칸, 멤버 줄의 소유자·서술자는 Spigot 또는 난독화 이름 모두 받음)를 기억으로 따랐고, 시험은 같은 모양의 가짜 표로 했다. CommandAPI Spigot 판으로 "아직 없음" 이 얼마나 줄었는지는 운영자 첫 실행 로그로 확인한다(user-todo).
- BuildTools 의 자동 멤버 이름(`--auto-member LOGGER/TOKENS/SYNTHETIC`)은 csrg 에 없다. Mojang 이름이 이미 같으면(`LOGGER`) 그대로 맞고, 아니면 덫에 걸린다.
- Spigot 이 이름을 붙이지 않은 난독화 클래스(기본 패키지 `abc$a`)를 직접 가리키는 플러그인은 바꾸지 않는다(H7 덫 판정도 `net/minecraft/` 만 본다 → 그 클래스는 `NoClassDefFoundError`).
- 플러그인 클래스가 NMS 인터페이스를 구현하며 난독화 이름 메서드를 선언하면 그 선언 이름은 바꾸지 않는다(NMS 상속은 등급 C, H7 정의 거부와 같은 범주).
- `Class#getName()` 은 Mojang 이름을 돌려준다(Paper 와 같다 — 이름을 거꾸로 바꾸지 않는다).
- 플러그인 클래스가 NMS 클래스를 상속해 Spigot(난독화) 이름 메서드를 재정의해도 그 선언 이름은 바꾸지 않는다 — 서버 쪽은 Mojang 이름을 부르므로 재정의가 걸리지 않는다(NMS 상속은 등급 C).
- `getDeclaredFields()`·`getDeclaredMethods()` 를 돌며 `f.getName().equals("b")` 처럼 이름을 비교하는 코드는 리플렉션 다리가 닿지 않는다(Paper 의 리플렉션 고쳐 쓰기도 이 경우는 바꾸지 않는 것으로 안다 — 가정).
- **메모리:** 켜면 표가 서버 수명 내내 힙에 남는다(리플렉션 다리가 실행 중에도 표를 쓴다). 실제 크기와 비슷한 가짜 표(ProGuard 13.3MB, 클래스 8천, 멤버 15만)로 재면 읽기 약 0.7초, 남는 힙 약 75~85MB 다(독립 검토 측정). 기본값 off 라 켠 서버에서만 든다. 같은 파일은 한 번만 읽고, 읽기 실패도 기억해 플러그인마다 다시 읽지 않는다.
