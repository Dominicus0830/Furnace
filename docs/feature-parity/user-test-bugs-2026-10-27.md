# 사용자 실접속 테스트 결과 정리 (2026-10-27)

사용자가 `docs/user-todo.md` 항목을 직접 접속해 테스트한 결과. 아래는 **버그로 확정된 것**과 담당 묶음이다. "OK/잘됨"인 항목은 제외.

## 묶음 A — 엔티티 외형 동기화 (패킷)
- A1. 다른 플레이어가 손에 든 아이템이 안 보임 (set_equipment 미전송 또는 형식 오류 의심)
- A2. 플레이어 스킨의 겉옷·겉머리 레이어가 안 보임 (클라 설정 `displayed_skin_parts` 가 엔티티 메타데이터 index 17 로 전파되는지)
- A3. 일부 아이템이 투명(히트박스만)으로 보임 (아이템 엔티티 메타데이터의 ItemStack 직렬화, 특정 컴포넌트/아이템 id 의심)

## 묶음 B — 소규모 버그
- B1. 토끼 청크 생성 스폰 NPE: `Rabbit.variantForSpawn(Rabbit.java:207)` 의 `Set.contains(null)` (`Set.of` 는 null 불가). 바닐라는 바이옴 키를 그대로 비교한다. 원인(바이옴 키가 null 인 경로)까지 확인.
- B2. 주크박스 위 깔때기가 음반을 넣자마자 가져감. 바닐라는 재생이 끝난 뒤에만 가져간다(재생 중에는 용기로 취급하지 않음 — 바닐라 `JukeboxBlockEntity` 의 `canTakeItem`/`Container` 규칙 확인).
- B3. 차원 이동·텔레포트 후 Y 가 한 칸 아래로 도착 (포탈 프레임 안에 끼어 이동). 모든 순간이동이 한 칸 낮음. 도착 좌표 계산(눈높이/발 위치/bounding box) 점검. 또 **관전 모드는 네더 포탈을 타면 안 됨**(바닐라: 관전자는 포탈 이동 불가).
- B4. 방패 막기 넉백: 사용자 확인 결과 바닐라에서는 방패로 막을 때 막은 쪽이 밀리지 않는다. 지난번 "공격자−자신 방향" 수정이 올바른지 바닐라 `LivingEntity.hurt`/`blockUsingShield`/`blockedByShield`(decomp)를 읽고, 방패를 든 쪽이 밀리면 제거. 공격자가 밀리는 경우(도끼 등)는 바닐라대로.

## 묶음 C — 탈것·몹 행동
- C1. 말 탑승: 어떤 방향에서 우클릭하면 탑승이 안 된다. 탈것에서 내린 직후 "내리려면 왼쪽 시프트" 미니 메시지가 사라질 때까지 탑승이 안 되는 것으로 보임 → 탑승 쿨다운/`boardingCooldown`·`passengerCooldown` 구현 점검(바닐라는 `Entity.boardingCooldown` 60틱이며 같은 엔티티 재탑승 거부 조건을 따름). 말 체력이 랜덤 범위(15~30)보다 높게 나옴 → 능력치 생성(`generateMaxHealth`: 15 + rand(8) + rand(9))과 난수 호출 순서 점검.
- C2. 워든: 소환하자마자 땅속으로 들어감(`/summon` 직후 digging). 바닐라는 `/summon` 시 EMERGING 이 아니라 기본 상태. 또 진동 4단계 경고(비명체 `warning_level`)가 동작하지 않음.
- C3. 스컬크 퍼짐: 촉매 근처에서 몹을 죽여도 스컬크가 퍼지지 않고 가끔 위로 한 칸만 생김. `SculkSpreader`·`SculkCatalystBlockEntity` 점검(커서 이동·charge 소비·`updateCursors`).
- C4. 약탈자 순찰: 게임 시간 145일인데 순찰이 안 나타남. `PatrolSpawner` 호출·틱 카운터·낮 조건·바이옴/난이도 조건 점검.

## 묶음 D — 마을·습격
- D1. 주민 AI 전반 이상: 문을 열고 닫지 않음, 일을 안 하는 듯, 종 주변에만 있음, 철 골렘 없음, 침대가 안 보이고 마을이 제대로 생성되지 않은 상태 → 먼저 **마을 구조물 생성(침대/직업 블록/문)** 이 맞는지, 그다음 POI 등록·주민 Brain(스케줄·활동)을 점검.
- D2. 종을 울려도 주민이 숨지 않음(HIDE 활동), 습격자 발광(공명)이 없음.
- D3. 종 블록이 꼭지만 보이고 몸통이 안 보임 (블록 엔티티 `bell` 의 상태/모델: 클라가 필요로 하는 블록 상태 속성 `attachment`/`facing`/`powered` 나 블록 엔티티 데이터 문제 가능).
- D4. 지도 깃발 표식이 0.3초 보이다 사라짐 → 지도 데이터 갱신 시 `banners` 맵이 유지되는지, 표식 디코레이션 패킷 재전송 조건 점검.

## 성능 관찰 (별도)
- E1. 플레이어 2명부터 청크 전송이 1명일 때보다 약간 느림 (청크 스냅샷 보관 제거 N-05 이후). 압축된 청크 프레임 공유/직렬화 큐를 측정해 원인 확인.
