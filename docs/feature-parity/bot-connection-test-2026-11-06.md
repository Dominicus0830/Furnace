# 오프라인 서버 봇 접속 시험 6차 (2026-11-06) — user-todo 정리

`docs/user-todo.md` 에 "실제 클라이언트 미확인"으로 쌓여 있던 표 가운데 **봇·오프라인 서버·바닐라 바이트코드 대조로 확인할 수 있는 것**을 모두 돌렸다.
방법은 1~5차와 같다(`online-mode=false` 서버 + mineflayer 4.39.0, `tools/bot-test/README.md`). 스크립트는 `tools/bot-test/round6/`(함정은 그 README).
기준 커밋 `187e5d18`(PR #28 병합) + 이 브랜치 수정으로 만든 fat jar 에서 모두 다시 돌린 값이다.
수정 후 전체 시험: `:furnace-api:test` 250개, `:furnace-server:test` 2636개(39 스킵) 모두 통과(2026-11-06). 바닐라 대조는 1.21.1 서버 jar 의 `javap -c -p`(난독화 이름은 괄호).

**적은 숫자는 모두 실제로 돌려 본 값이다.** 봇이 볼 수 없는 화면·소리(귀)·클라이언트가 계산하는 이동은 user-todo 의 "실제 클라이언트로만 볼 수 있는 것" 표로 모았다.

## 시험 중 찾아 고친 것 (재현 시험 포함, `EntityWorldApiTest`)
1. **마법 부여된 아이템 `/give` 가 오류**: 드롭 이벤트를 구독한 플러그인(SamplePlugin 등)이 있으면 `/give @s mace[enchantments={…}]` 가 "명령 처리 실패"로 끝났다.
   `ApiConvert.item` 이 컴포넌트 패치의 정규 값(마법 부여는 Map)을 그대로 SNBT 로 쓰다 "NBT 값이 아님" 예외. 저장할 때처럼 그 컴포넌트 코덱으로 NBT 로 바꾼 뒤 쓴다.
2. **`/give` 의 가짜 아이템(줍는 연출)에 PlayerDropItemEvent 가 불렸다**: CraftBukkit 은 이 드롭에 이벤트를 부르지 않는다(SPIGOT-2942). `Region.playerDrop(…, callEvent)` 를 더해 `/give` 는 거짓으로 부른다.

## 시험 도구 수정
- `patch-registry.js`: minecraft-data 1.21.1 의 `potion_contents` 에 1.21.2 칸(`customName`)이 섞여 성분 있는 물약이 든 창이 열리지 않던 것(PartialReadError)을 고친다. 바닐라 1.21.1(`cwu`)은 3칸.

## 봇 쪽 문제(서버 정상)
- 돌풍 폭발 뒤 봇이 땅에 박혀 되돌림이 반복된다: mineflayer 가 explosion 패킷의 블록 목록을 블록 상호작용 종류와 상관없이 공기로 지운다. 서버는 바닐라처럼 TRIGGER_BLOCK 폭발에도 목록을 보낸다.

## 확인 못 한 차이(가정, 고치지 않음)
- `@e` 선택자 개수에 죽는 중인 엔티티가 들어가는 듯하다(습격자 처치 직후 개수). 바닐라 `EntitySelector` 는 `isAlive` 를 본다 — 다음에 확인.
- `/attribute … get` 출력 소수 형식("0.115")이 바닐라와 같은지 확인 안 함.
