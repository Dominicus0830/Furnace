## 찾아 고친 것 (이 브랜치, 재현 시험 포함)

1. **`/data get entity @s` 뒤 플레이어 저장 실패.** 경로 연산용 `NbtTags.thaw` 가 복사 없이 제자리에서 배열을 바꿔, 살아 있는 어깨 앵무새 태그의
   `int[]` 가 `NbtArray` 로 바뀌었다. 그 뒤 저장이 "미지원 값: class NbtArray" 로 실패해 재접속하면 어깨 앵무새가 사라졌고, playerdata 에 임시 파일이
   남았다. 데이터 접근자 4곳(엔티티·블록·블록 엔티티 질의·저장소)이 복사본을 풀고, `PlayerShoulders.save` 가 복사본을 넣고, 저장 실패 때 임시 파일을 지운다.
   시험: `DataCommandsTest.readingPlayerDataDoesNotCorruptLiveShoulderTag`(수정 전 실패 확인).
2. **플레이어가 떨어져도 경작지가 안 밟힘.** 플레이어는 `Entity` 가 아니라 낙하 피해만 따로 계산하고 블록의 `fallOn` 을 부르지 않았다. 내려앉은 낙하 거리를
   `PlayerVitals` 가 기록하고, 이동 처리에서 `getOnPosLegacy` 칸이 경작지면 바닐라 `FarmBlock.fallOn` 조건(레벨 난수 < 낙하 거리 − 0.5, 부피 > 0.512,
   플레이어는 mobGriefing 무관)으로 흙으로 바꾼다. 시험: `PlayerFarmlandTrampleTest`(수정 전 실패 확인). 거북 알 밟기는 몹 쪽도 아직 없어 그대로 둔다.
3. **`/setblock`·`/fill` 이 블록 NBT 를 버림.** `chest{Items:[…]}` 가 빈 상자를 놓았다. `BlockInput.place` 처럼 놓은 뒤 블록 엔티티에 불러오고,
   바꾸기 전에 `Clearable.tryClear`(clone 과 같은 함수)로 내용물을 비운다. 시험: `DataCommandsTest.setblockAndFillLoadBlockEntityNbtAndClearOldContents`.
   주크박스·독서대는 tryClear 대상에서 아직 빠져 있다(clone 도 같음).
4. **방랑 상인 타이머가 level.dat 에 저장되지 않음.** `FurnaceMain` 이 오버월드 공유 상태를 네더·엔드 반복문 안에서 `OVERWORLD` 인지 검사해 붙이고 있어
   한 번도 붙지 않았다. 그래서 오버월드 region 마다 따로 타이머를 돌리고(region 이 여럿이면 상인이 더 자주 나올 수 있음) 저장도 안 됐다.
   오버월드를 만든 직후 붙이도록 고쳤다. 시작 경로라 단위 시험은 없고 봇 재시험으로 확인했다(아래).
