# M4g-c2 Aquifer System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement vanilla-compatible NoiseBasedAquifer for Furnace so underground water/lava pockets match vanilla oracle output.

**Architecture:** Aquifer sealed interface (DisabledAquifer + NoiseBasedAquifer), aquifer noises added to NoiseRouter from noise_router JSON, `NoiseChunk.generateBlockIds()` integrates aquifer in fill loop with real density values, oracle extended with `aquifer:cx:cz` for enabled-aquifer fixtures.

**Tech Stack:** Java 21 sealed interfaces, existing XoroshiroRandomSource/NormalNoise stack, JUnit 5 parity tests.

---

## Key Facts Before Starting

- Oracle currently has aquifer **disabled** (`false, // aquifersEnabled` in OracleMain.java:85). Current surface fixtures = DisabledAquifer output.
- `NoiseBasedAquifer` gets its 4 noise DFs from **NoiseRouter** (barrierNoise, fluidLevelFloodednessNoise, fluidLevelSpreadNoise, lavaNoise). Noise params come from `noise_router` JSON keys `barrier`, `fluid_level_floodedness`, `fluid_level_spread`, `lava`.
- `aquiferRandom` seeding = `positionalFactory.fromHashOf("minecraft:aquifer").forkPositional()` — where `positionalFactory` is the one in `DensityFunctionParser`. Verified via javap bytecode of `RandomState.class` (line 36-41).
- `noise_settings/overworld.json` already has `"aquifers_enabled": true` and `"ore_veins_enabled": true`.
- `NoiseChunk.stoneMask()` only returns `boolean[]` and discards density values. NoiseBasedAquifer needs density for barrier pressure calculation. Solution: new `NoiseChunk.generateBlockIds(stoneId, aquifer)` that returns `int[]` block state IDs.
- Existing `stoneMask()` is kept (benchmark + NoiseChunkTest still use it).

- [ ] **Step 2: Implement `dumpAquiferChunk()` method**

```java
private static void dumpAquiferChunk(
    long seed, int cx, int cz,
    NoiseBasedChunkGenerator generator,
    RandomState randomState,
    NoiseGeneratorSettings settings,
    Aquifer.FluidPicker fluidPicker,
    Registry<Biome> biomeRegistry,
    MultiNoiseBiomeSource biomeSource,
    Path outDir
) throws Exception {
    ChunkPos chunkPos = new ChunkPos(cx, cz);
    LevelHeightAccessor heightAccessor = LevelHeightAccessor.create(FixtureFormat.MIN_Y, FixtureFormat.HEIGHT);
    ProtoChunk chunk = new ProtoChunk(chunkPos, UpgradeData.EMPTY, heightAccessor, biomeRegistry, null);

    Beardifier emptyBeardifier = new Beardifier(
        new ObjectArrayList<Beardifier.Rigid>().iterator(),
        new ObjectArrayList<JigsawJunction>().iterator()
    );
    chunk.getOrCreateNoiseChunk(ca ->
        NoiseChunk.forChunk(ca, randomState, emptyBeardifier, settings, fluidPicker, Blender.empty())
    );

    generator.fillFromNoise(Blender.empty(), randomState, null, chunk).join();

    BiomeManager biomeManager = new BiomeManager(
        (x, y, z) -> biomeSource.getNoiseBiome(x, y, z, randomState.sampler()),
        BiomeManager.obfuscateSeed(seed)
    );
    WorldGenerationContext worldGenContext = new WorldGenerationContext(generator, heightAccessor);
    generator.buildSurface(chunk, worldGenContext, randomState, null, biomeManager, biomeRegistry, Blender.empty());

    int totalBlocks = FixtureFormat.HEIGHT * 16 * 16;
    int headerSize  = 4 + 8 + 4 + 4;
    ByteBuffer buf  = ByteBuffer.allocate(headerSize + totalBlocks * 2).order(ByteOrder.LITTLE_ENDIAN);
    buf.putInt(0x41515546); // "AQUF" magic
    buf.putLong(seed);
    buf.putInt(cx);
    buf.putInt(cz);

    for (int y = FixtureFormat.MIN_Y; y < FixtureFormat.MIN_Y + FixtureFormat.HEIGHT; y++) {
        for (int localZ = 0; localZ < 16; localZ++) {
            for (int localX = 0; localX < 16; localX++) {
                int worldX = cx * 16 + localX;
                int worldZ = cz * 16 + localZ;
                BlockState state = chunk.getBlockState(new net.minecraft.core.BlockPos(worldX, y, worldZ));
                short id = (short) net.minecraft.world.level.block.Block.BLOCK_STATE_REGISTRY.getId(state);
                buf.putShort(id);
            }
        }
    }

    Path out = outDir.resolve("aquifer_" + seed + "_" + cx + "_" + cz + ".bin");
    try (FileOutputStream fos = new FileOutputStream(out.toFile())) {
        fos.write(buf.array());
    }
    System.out.printf("Wrote %s (%d bytes)%n", out, buf.capacity());
}
```

- [ ] **Step 1: Add `generateBlockIds(int stoneId, Aquifer aquifer)` method to NoiseChunk**

Insert after the `stoneMask()` method (around line 485). The body is nearly identical to `stoneMask()` but returns `int[]` instead of `boolean[]`:

```java
/**
 * 전체 청크(16×384×16)에 대해 블록 state ID를 보간된 density 기반으로 채운다.
 * density > 0 → stoneId, density ≤ 0 → aquifer.computeSubstance(ctx, density).
 * index = (y - minY) * 256 + lz * 16 + lx (stoneMask 와 동일).
 */
public int[] generateBlockIds(int stoneId, Aquifer aquifer) {
    int minY   = this.cellNoiseMinY * this.cellHeight;
    int height = this.cellCountY   * this.cellHeight;
    int[] blocks = new int[height * 16 * 16];

    initializeForFirstCellX();

    int chunkBlockZ = this.firstCellZ * this.cellWidth;

    for (int cx = 0; cx < this.cellCountXZ; cx++) {

                double[] bounds = cellBoundsOf(this.wrappedFinalDensity);
                if (bounds[1] < -SKIP_EPS) {
                    // all air/fluid in this cell — call aquifer for each block
                    int yBase = cy * this.cellHeight;
                    int xBase = cx * this.cellWidth;
                    int zBase = cz * this.cellWidth;
                    for (int iy = 0; iy < this.cellHeight; iy++) {
                        int blockY = (this.cellNoiseMinY + cy) * this.cellHeight + iy;
                        int yOff = blockY - minY;
                        int rowBase = yOff * 256;
                        for (int iz = 0; iz < this.cellWidth; iz++) {
                            int blockZ = chunkBlockZ + cz * this.cellWidth + iz;
                            for (int ix = 0; ix < this.cellWidth; ix++) {
                                int blockX = chunkBlockX + cx * this.cellWidth + ix;
                                int lx = blockX & 15;
                                int lz = blockZ & 15;
                                // density at cell skip is guaranteed < 0, use cell minimum
                                this.cellStartBlockX = blockX - ix; // update context
                                this.cellStartBlockY = blockY - iy;
                                this.cellStartBlockZ = blockZ - iz;
                                this.inCellX = ix;
                                this.inCellY = iy;
                                this.inCellZ = iz;
                                int idx = rowBase + lz * 16 + lx;
                                if (idx >= 0 && idx < blocks.length) {
                                    blocks[idx] = aquifer.computeSubstance(this, bounds[1]);
                                }
                            }
                        }
                    }
                    continue;
                }
                if (bounds[0] > SKIP_EPS) {
                    // all stone
                    int yBase = cy * this.cellHeight;
                    int xBase = cx * this.cellWidth;
                    int zBase = cz * this.cellWidth;
                    for (int iy = 0; iy < this.cellHeight; iy++) {
                        int blockY = (this.cellNoiseMinY + cy) * this.cellHeight + iy;
                        int yOff = blockY - minY;
                        int rowBase = yOff * 256;
                        for (int iz = 0; iz < this.cellWidth; iz++) {
                            int blockZ = chunkBlockZ + cz * this.cellWidth + iz;
                            for (int ix = 0; ix < this.cellWidth; ix++) {
                                int blockX = chunkBlockX + cx * this.cellWidth + ix;
                                int lx = blockX & 15;
                                int lz = blockZ & 15;
                                int idx = rowBase + lz * 16 + lx;
                                if (idx >= 0 && idx < blocks.length) {
                                    blocks[idx] = stoneId;
                                }
                            }
                        }
                    }
                    continue;
                }

                fillCellCaches();

                for (int iy = this.cellHeight - 1; iy >= 0; iy--) {
                    int blockY = (this.cellNoiseMinY + cy) * this.cellHeight + iy;
                    double ty = (double) iy / this.cellHeight;
                    updateForY(blockY, ty);

                    for (int ix = 0; ix < this.cellWidth; ix++) {
                        int blockX = chunkBlockX + cx * this.cellWidth + ix;
                        double tx = (double) ix / this.cellWidth;
                        updateForX(blockX, tx);

                        for (int iz = 0; iz < this.cellWidth; iz++) {
                            int blockZ = chunkBlockZ + cz * this.cellWidth + iz;
                            double tz = (double) iz / this.cellWidth;
                            updateForZ(blockZ, tz);

                            double density = this.wrappedFinalDensity.compute(this);
                            int lx = blockX & 15;
                            int lz = blockZ & 15;
                            int yOff = blockY - minY;
                            int idx = yOff * 256 + lz * 16 + lx;
                            if (idx >= 0 && idx < blocks.length) {
                                if (density > 0.0) {
                                    blocks[idx] = stoneId;
                                } else {
                                    blocks[idx] = aquifer.computeSubstance(this, density);
                                }
                            }
                        }
                    }
                }
            }
        }

        swapSlices();
    }

    stopInterpolation();
    return blocks;
}
```

```java
@Override
public int computeSubstance(DensityFunction.FunctionContext ctx, double density) {
    int blockX = ctx.blockX();
    int blockY = ctx.blockY();
    int blockZ = ctx.blockZ();

    int gx = gridX(blockX);
    int gy = gridY(blockY);
    int gz = gridZ(blockZ);

    // Squared distance to current grid cell center
    int dxCell = blockX - gx * X_SPACING;
    int dyCell = blockY - gy * Y_SPACING;
    int dzCell = blockZ - gz * Z_SPACING;

    // Iterate (gx-1..gx+1) × (gy-1..gy+1) × (gz-1..gz+1) — 27 cells max
    // But vanilla only checks a subset based on proximity
    double nearestD1 = Double.MAX_VALUE;
    double nearestD2 = Double.MAX_VALUE;
    FluidStatus nearest1 = null;
    FluidStatus nearest2 = null;

    for (int ox = -1; ox <= 1; ox++) {
        for (int oy = -1; oy <= 1; oy++) {
            for (int oz = -1; oz <= 1; oz++) {
                int cgx = gx + ox;
                int cgy = gy + oy;
                int cgz = gz + oz;

                FluidStatus status = getAquiferStatus(cgx, cgy, cgz);
                if (status == null) continue;

                // Get actual source position (stored during computeFluid)
                // For now use center of cell * spacing
                int sx = cgx * X_SPACING;
                int sy = cgy * Y_SPACING;
                int sz = cgz * Z_SPACING;

                double dx = blockX - sx;
                double dy = blockY - sy;
                double dz = blockZ - sz;
                double d2 = dx*dx + dy*dy + dz*dz;

                if (d2 < nearestD1) {
                    nearestD2 = nearestD1;
                    nearest2 = nearest1;
                    nearestD1 = d2;
                    nearest1 = status;
                } else if (d2 < nearestD2) {
                    nearestD2 = d2;
                    nearest2 = status;
                }
            }
        }
    }

    if (nearest1 == null) return 0; // air

    // Check if block is below nearest fluid level
    if (!nearest1.isAt(blockY)) return 0; // above fluid → air

    // If only one source, use it directly
    if (nearest2 == null || nearest2.fluidLevel() == WAY_BELOW_MIN_Y) {
        return nearest1.fluidBlockId();
    }

    // Similarity check — barrier noise
    double sim = similarity((int) nearestD1, (int) nearestD2);
    if (sim > 0) {
        double pressure = calculatePressure(ctx, density, nearest1, nearest2);
        // shouldScheduleFluidUpdate if sim > FLOWING_UPDATE_SIMULARITY && fluid types match
        if (sim > FLOWING_UPDATE_SIMULARITY && nearest1.fluidBlockId() == nearest2.fluidBlockId()) {
            shouldScheduleFluidUpdate = true;
        }
        if (pressure <= 0) return 0; // barrier holds → air
    }

    return nearest1.fluidBlockId();
}
```

`calculatePressure(ctx, density, s1, s2)`:
```java
private double calculatePressure(DensityFunction.FunctionContext ctx, double density,
                                  FluidStatus s1, FluidStatus s2) {
    // If density is very negative, no barrier needed
    // barrier noise modulates the threshold
    double barrierVal = barrierNoise.compute(ctx);
    double d1 = s1.fluidLevel();
    double d2 = s2.fluidLevel();
    double midY = (d1 + d2) / 2.0;
    double yDist = Math.abs(ctx.blockY() - midY);
    // Simplified: pressure based on density + barrier noise
    return (density + barrierVal) * 2.0 + yDist / Math.max(1, Math.abs(d1 - d2));
}
```
