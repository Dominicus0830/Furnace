# M4g-c3 Carver System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port vanilla 1.21.4 cave/canyon carver system to Furnace for bit-exact parity with oracle output.

**Architecture:** Three overworld carvers (cave p=0.15, cave_extra_underground p=0.07, canyon p=0.01) seeded per-origin-chunk via `WorldgenRandom.setLargeFeatureSeed(worldSeed, originX, originZ)`. Origin loop: originX ∈ [cx-8, cx+8], originZ ∈ [cz-8, cz+8]. After fillFromNoise + buildSurface, carvers replace terrain blocks with air/water/lava. NoiseWorldSource calls carving after buildSurface.

**Tech Stack:** Java 21, existing XoroshiroRandomSource/NoiseChunk/Aquifer stack, LegacyRandom (new, Java 48-bit LCG), JUnit 5 parity tests.

## Key Facts Before Starting

- **Carver order:** fillFromNoise → buildSurface → applyCarvers (single pass, no AIR/LIQUID split in 1.21.4).
- **Seeding:** `WorldgenRandom` (LegacyRandom-based) seeded via `setLargeFeatureSeed`. NOT XoroshiroRandomSource.
- **LegacyRandom** = Java `java.util.Random` 48-bit LCG. `RandomSource.create(long)` in vanilla produces this type. Used in `createTunnel`'s `branchRandom`.
- **Cave carver `carve()` count cascade:** `a = nextInt(15)+1; b = nextInt(a)+1; count = nextInt(b)`. Typically 0-3 tunnels/rooms per origin chunk.
- **`createTunnel` yScale = `getYScale()` = 1.0** for CaveWorldCarver (NOT config.yScale). config.yScale is only used in createRoom.
- **`carveEllipsoid` relX/Z use block-center offset (+0.5):** `relX = (bx + 0.5 - x) / hRadius`. Y uses bottom-of-block offset: `relY = (by - 0.5 - y) / vRadius`.
- **`canReach` formula:** `dx*dx + dz*dz - remaining*remaining <= (thickness + 18.0)^2` where remaining = maxStep - step.
- **`shouldSkip` (cave):** `return relY <= floorLevel || relX*relX + relY*relY + relZ*relZ >= 1.0`.
- **`getCarveState`:** `y <= lavaLevel (minY+8)` → lavaId; else `aquifer.computeSubstance(ctx, 0.0)` (density=0 → air/water/lava from aquifer).
- **Replaceable blocks** (hard-coded set): stone, granite, diorite, andesite, tuff, deepslate, dirt, grass_block, podzol, coarse_dirt, mycelium, rooted_dirt, moss_block, pale_moss_block, mud, sand, red_sand, gravel, suspicious_gravel, sandstone, red_sandstone, calcite, packed_ice, raw_iron_block, raw_copper_block, water, terracotta, white/orange/magenta/light_blue/yellow/lime/pink/gray/light_gray/cyan/purple/blue/brown/green/red/black_terracotta, iron_ore, deepslate_iron_ore, copper_ore, deepslate_copper_ore, snow, snow_block.
- **`topMaterial` (grass regeneration after carving):** When carvedBlock == grass_block or mycelium AND block below is dirt → replace dirt with grass_block. Simplified for now: skip this feature (if mismatches appear near cave openings, add it then).
- **`CarvingMask`:** Prevents double-carving. `boolean[HEIGHT * 16 * 16]` per chunk. index = `(y - minY) * 256 + lz * 16 + lx`.
- **Oracle hard-codes 3 carvers for ALL origin chunks** (valid for standard biomes; test fixtures chosen in plains/forest regions).
- **Fixture magic:** `0x43525652` ("CRVR"), same 20B header as surface/aquifer: magic(4) + seed(8) + cx(4) + cz(4).

// 바닐라 Java 48-bit LCG — WorldgenRandom(carver 시드)과 createTunnel branchRandom 공용
package org.domi.furnace.server.world.gen.carver;

public final class LegacyRandom {

    private static final long MULTIPLIER = 0x5DEECE66DL;
    private static final long ADDEND     = 0xBL;
    private static final long MASK       = (1L << 48) - 1;

    private long seed;

    public LegacyRandom(long seed) {
        setSeed(seed);
    }

    public void setSeed(long seed) {
        this.seed = (seed ^ MULTIPLIER) & MASK;
    }

    private int next(int bits) {
        seed = (seed * MULTIPLIER + ADDEND) & MASK;
        return (int)(seed >>> (48 - bits));
    }

    public int nextInt() {
        return next(32);
    }

    public int nextInt(int bound) {
        if (bound <= 0) throw new IllegalArgumentException();
        if ((bound & -bound) == bound) return (int)((bound * (long)next(31)) >> 31);
        int bits, val;
        do {
            bits = next(31);
            val  = bits % bound;
        } while (bits - val + (bound - 1) < 0);
        return val;
    }

    public long nextLong() {
        return ((long)next(32) << 32) + (next(32) & 0xFFFFFFFFL);
    }

    public float nextFloat() {
        return next(24) / (float)(1 << 24);
    }

    public double nextDouble() {
        return (((long)next(26) << 27) + next(27)) * (1.0 / (1L << 53));
    }

    public boolean nextBoolean() {
        return next(1) != 0;
    }
}
```

package org.domi.furnace.server.world.gen.carver;

public final class WorldgenRandom extends LegacyRandom {

    public WorldgenRandom() {
        super(0L);
    }

    /** 바닐라 WorldgenRandom.setLargeFeatureSeed(worldSeed, chunkX, chunkZ) */
    public void setLargeFeatureSeed(long worldSeed, int x, int z) {
        setSeed(worldSeed);
        long a = nextLong() | 1L;
        long b = nextLong() | 1L;
        setSeed((long)x * a + (long)z * b ^ worldSeed);
    }
}

// 바닐라 FloatProvider 포팅 — carver 설정 float 범위 샘플링
package org.domi.furnace.server.world.gen.carver;

import com.google.gson.JsonObject;

public interface FloatProvider {

    float sample(LegacyRandom random);

    static FloatProvider fromJson(JsonObject json) {
        String type = json.get("type").getAsString();
        return switch (type) {
            case "minecraft:uniform" -> {
                float min = json.get("min_inclusive").getAsFloat();
                float max = json.get("max_exclusive").getAsFloat();
                yield new Uniform(min, max);
            }
            case "minecraft:trapezoid" -> {
                float min     = json.get("min").getAsFloat();
                float max     = json.get("max").getAsFloat();
                float plateau = json.get("plateau").getAsFloat();
                yield new Trapezoid(min, max, plateau);
            }
            case "minecraft:clamped_normal" -> {
                // Used in some carver configs but not the 3 overworld ones
                float mean   = json.get("mean").getAsFloat();
                float stddev = json.get("standard_deviation").getAsFloat();
                float minV   = json.get("min").getAsFloat();
                float maxV   = json.get("max").getAsFloat();
                yield new ClampedNormal(mean, stddev, minV, maxV);
            }
            default -> throw new IllegalArgumentException("Unknown FloatProvider type: " + type);
        };
    }

    // Shortcut for constant float values (used in canyon config yScale which is 3.0f directly)
    static FloatProvider constant(float value) {
        return r -> value;
    }

    record Uniform(float minInclusive, float maxExclusive) implements FloatProvider {
        @Override public float sample(LegacyRandom r) {
            return minInclusive + r.nextFloat() * (maxExclusive - minInclusive);
        }
    }

    record Trapezoid(float min, float max, float plateau) implements FloatProvider {
        @Override public float sample(LegacyRandom r) {
            // Vanilla TrapezoidFloat: plateau portion is flat, sides are linear
            float span = max - min;
            float halfSpan = span / 2.0f;
            float squishFactor = plateau / span;
            float value = (halfSpan - plateau / 2.0f) + r.nextFloat() * span;
            float sign = Math.signum(value);
            float flatOffset = (plateau / 2.0f) * sign;
            return (value * value / halfSpan - flatOffset) * sign + (min + max) / 2.0f;
        }
    }

    record ClampedNormal(float mean, float stddev, float min, float max) implements FloatProvider {
        @Override public float sample(LegacyRandom r) {
            // Box-Muller not matching LegacyRandom — vanilla uses Gaussian via nextGaussian
            // For now: sample via rejection (most values land in [min,max])
            float v;
            do {
                // Java Random.nextGaussian uses polar method:
                double v1, v2, s;
                do {
                    v1 = 2 * r.nextDouble() - 1;
                    v2 = 2 * r.nextDouble() - 1;
                    s  = v1 * v1 + v2 * v2;
                } while (s >= 1 || s == 0);
                double multiplier = Math.sqrt(-2 * Math.log(s) / s);
                v = (float)(v1 * multiplier * stddev + mean);
            } while (v < min || v > max);
            return v;
        }
    }
}
```

// 바닐라 HeightProvider 포팅 — carver 시작 Y 결정 (above_bottom / absolute / uniform)
package org.domi.furnace.server.world.gen.carver;

import com.google.gson.JsonElement;
import com.google.gson.JsonObject;

public interface HeightProvider {

    int sample(LegacyRandom random, int minY, int height);

    static HeightProvider fromJson(JsonObject json) {
        String type = json.get("type").getAsString();
        return switch (type) {
            case "minecraft:uniform" -> {
                int min = parseVerticalAnchor(json.get("min_inclusive"), minY -> minY); // placeholder
                int max = parseVerticalAnchor(json.get("max_inclusive"), minY -> minY);
                // Actually we need to defer resolution until sample time since minY is runtime
                yield new Uniform(json.get("min_inclusive").getAsJsonObject(),
                                  json.get("max_inclusive").getAsJsonObject());
            }
            default -> throw new IllegalArgumentException("Unknown HeightProvider: " + type);
        };
    }

    /** Resolves a VerticalAnchor JSON element given minY */
    static int resolveAnchor(JsonObject anchor, int minY) {
        if (anchor.has("above_bottom")) return minY + anchor.get("above_bottom").getAsInt();
        if (anchor.has("absolute"))     return anchor.get("absolute").getAsInt();
        if (anchor.has("below_top"))    throw new UnsupportedOperationException("below_top anchor not implemented");
        throw new IllegalArgumentException("Unknown anchor: " + anchor);
    }

    private static int parseVerticalAnchor(JsonElement el, java.util.function.IntUnaryOperator ignored) {
        // Unused — just for compile
        return 0;
    }

    record Uniform(JsonObject minAnchor, JsonObject maxAnchor) implements HeightProvider {
        @Override
        public int sample(LegacyRandom random, int minY, int height) {
            int min = resolveAnchor(minAnchor, minY);
            int max = resolveAnchor(maxAnchor, minY);
            if (min > max) return min;
            return min + random.nextInt(max - min + 1);
        }
    }
}

```java
private static void dumpCarverChunk(
    long seed, int cx, int cz,
    NoiseBasedChunkGenerator generator,
    RandomState randomState,
    NoiseGeneratorSettings settings,
    Aquifer.FluidPicker fluidPicker,
    Registry<Biome> biomeRegistry,
    MultiNoiseBiomeSource biomeSource,
    Path outDir
) throws Exception {
    ChunkPos chunkPos = new ChunkPos(cx, cz);
    LevelHeightAccessor heightAccessor = LevelHeightAccessor.create(FixtureFormat.MIN_Y, FixtureFormat.HEIGHT);
    ProtoChunk chunk = new ProtoChunk(chunkPos, UpgradeData.EMPTY, heightAccessor, biomeRegistry, null);

    Beardifier emptyBeardifier = new Beardifier(
        new ObjectArrayList<Beardifier.Rigid>().iterator(),
        new ObjectArrayList<JigsawJunction>().iterator()
    );
    chunk.getOrCreateNoiseChunk(ca ->
        NoiseChunk.forChunk(ca, randomState, emptyBeardifier, settings, fluidPicker, Blender.empty())
    );

    // 1. Fill terrain
    generator.fillFromNoise(Blender.empty(), randomState, null, chunk).join();

    // 2. Surface rules
    BiomeManager biomeManager = new BiomeManager(
        (x, y, z) -> biomeSource.getNoiseBiome(x, y, z, randomState.sampler()),
        BiomeManager.obfuscateSeed(seed)
    );
    WorldGenerationContext worldGenContext = new WorldGenerationContext(generator, heightAccessor);
    generator.buildSurface(chunk, worldGenContext, randomState, null, biomeManager, biomeRegistry, Blender.empty());

    // 3. Carvers — replicate NoiseBasedChunkGenerator.applyCarvers loop
    // Get aquifer from the noise chunk (already created above)
    net.minecraft.world.level.levelgen.NoiseChunk noiseChunk =
        chunk.getOrCreateNoiseChunk(ca ->
            NoiseChunk.forChunk(ca, randomState, emptyBeardifier, settings, fluidPicker, Blender.empty()));
    net.minecraft.world.level.levelgen.Aquifer aquifer = noiseChunk.aquifer();

    // CarvingContext needs NoiseChunk, RandomState, settings.surfaceRule(), and height accessor
    net.minecraft.world.level.levelgen.carver.CarvingContext carvingCtx =
        new net.minecraft.world.level.levelgen.carver.CarvingContext(
            generator, randomState.registryAccess(), heightAccessor,
            noiseChunk, randomState, settings.surfaceRule());

    // Hard-code 3 overworld configured carvers
    var carverReg = randomState.registryAccess()
        .registryOrThrow(net.minecraft.core.registries.Registries.CONFIGURED_CARVER);
    var caveCarver       = carverReg.getOrThrow(net.minecraft.resources.ResourceKey.create(
        net.minecraft.core.registries.Registries.CONFIGURED_CARVER,
        net.minecraft.resources.ResourceLocation.parse("minecraft:cave")));
    var caveExtraCarver  = carverReg.getOrThrow(net.minecraft.resources.ResourceKey.create(
        net.minecraft.core.registries.Registries.CONFIGURED_CARVER,
        net.minecraft.resources.ResourceLocation.parse("minecraft:cave_extra_underground")));
    var canyonCarver     = carverReg.getOrThrow(net.minecraft.resources.ResourceKey.create(
        net.minecraft.core.registries.Registries.CONFIGURED_CARVER,
        net.minecraft.resources.ResourceLocation.parse("minecraft:canyon")));

    java.util.List<net.minecraft.world.level.levelgen.carver.ConfiguredWorldCarver<?>> carvers =
        java.util.List.of(caveCarver, caveExtraCarver, canyonCarver);

    net.minecraft.world.level.chunk.CarvingMask carvingMask =
        ((ProtoChunk)chunk).getOrCreateCarvingMask();

    net.minecraft.world.level.levelgen.WorldgenRandom worldgenRandom =
        new net.minecraft.world.level.levelgen.WorldgenRandom(
            new net.minecraft.world.level.levelgen.LegacyRandomSource(0L));

    java.util.function.Function<net.minecraft.core.BlockPos, net.minecraft.core.Holder<Biome>> biomeAccessor =
        pos -> biomeSource.getNoiseBiome(pos.getX() >> 2, 0, pos.getZ() >> 2, randomState.sampler());

    for (int originX = cx - 8; originX <= cx + 8; originX++) {
        for (int originZ = cz - 8; originZ <= cz + 8; originZ++) {
            ChunkPos originPos = new ChunkPos(originX, originZ);
            for (var carver : carvers) {
                worldgenRandom.setLargeFeatureSeed(seed, originX, originZ);
                if (carver.isStartChunk(worldgenRandom)) {
                    carver.carve(carvingCtx, chunk, biomeAccessor, worldgenRandom, aquifer, originPos, carvingMask);
                }
            }
        }
    }

    // 4. Dump blocks
    int totalBlocks = FixtureFormat.HEIGHT * 16 * 16;
    int headerSize  = 4 + 8 + 4 + 4;
    ByteBuffer buf  = ByteBuffer.allocate(headerSize + totalBlocks * 2).order(ByteOrder.LITTLE_ENDIAN);
    buf.putInt(0x43525652); // "CRVR" magic
    buf.putLong(seed);
    buf.putInt(cx);
    buf.putInt(cz);

    for (int y = FixtureFormat.MIN_Y; y < FixtureFormat.MIN_Y + FixtureFormat.HEIGHT; y++) {
        for (int localZ = 0; localZ < 16; localZ++) {
            for (int localX = 0; localX < 16; localX++) {
                int worldX = cx * 16 + localX;
                int worldZ = cz * 16 + localZ;
                net.minecraft.world.level.block.state.BlockState state =
                    chunk.getBlockState(new net.minecraft.core.BlockPos(worldX, y, worldZ));
                short id = (short) net.minecraft.world.level.block.Block.BLOCK_STATE_REGISTRY.getId(state);
                buf.putShort(id);
            }
        }
    }

    Path out = outDir.resolve("carver_" + seed + "_" + cx + "_" + cz + ".bin");
    try (FileOutputStream fos = new FileOutputStream(out.toFile())) {
        fos.write(buf.array());
    }
    System.out.printf("Wrote %s (%d bytes)%n", out, buf.capacity());
}
```

package org.domi.furnace.server.world.gen.carver;

public final class CarvingMask {

    private final boolean[] carved;
    private final int minY;

    public CarvingMask(int minY, int height) {
        this.minY   = minY;
        this.carved = new boolean[height * 16 * 16];
    }

    private int index(int lx, int y, int lz) {
        return (y - minY) * 256 + lz * 16 + lx;
    }

    public boolean get(int lx, int y, int lz) {
        int idx = index(lx, y, lz);
        return idx >= 0 && idx < carved.length && carved[idx];
    }

    public void set(int lx, int y, int lz) {
        int idx = index(lx, y, lz);
        if (idx >= 0 && idx < carved.length) carved[idx] = true;
    }
}

// 바닐라 WorldCarver 추상 포팅 — carveEllipsoid + carveBlock 공통 로직
package org.domi.furnace.server.world.gen.carver;

import java.util.Set;
import org.domi.furnace.server.world.ChunkColumn;
import org.domi.furnace.server.world.gen.NoiseSettings;
import org.domi.furnace.server.world.gen.Aquifer;
import org.domi.furnace.server.world.gen.df.DensityFunction;

public abstract class WorldCarver {

    // Replaceable block names (overworld_carver_replaceables tag + sub-tags, expanded)
    private static final Set<String> REPLACEABLE_NAMES = Set.of(
        "minecraft:stone","minecraft:granite","minecraft:diorite","minecraft:andesite",
        "minecraft:tuff","minecraft:deepslate",
        "minecraft:dirt","minecraft:grass_block","minecraft:podzol","minecraft:coarse_dirt",
        "minecraft:mycelium","minecraft:rooted_dirt","minecraft:moss_block",
        "minecraft:pale_moss_block","minecraft:mud","minecraft:muddy_mangrove_roots",
        "minecraft:sand","minecraft:red_sand","minecraft:suspicious_sand",
        "minecraft:gravel","minecraft:suspicious_gravel",
        "minecraft:sandstone","minecraft:cut_sandstone","minecraft:chiseled_sandstone","minecraft:smooth_sandstone",
        "minecraft:red_sandstone","minecraft:cut_red_sandstone","minecraft:chiseled_red_sandstone","minecraft:smooth_red_sandstone",
        "minecraft:calcite","minecraft:packed_ice","minecraft:raw_iron_block","minecraft:raw_copper_block",
        "minecraft:water",
        "minecraft:terracotta","minecraft:white_terracotta","minecraft:orange_terracotta","minecraft:magenta_terracotta",
        "minecraft:light_blue_terracotta","minecraft:yellow_terracotta","minecraft:lime_terracotta","minecraft:pink_terracotta",
        "minecraft:gray_terracotta","minecraft:light_gray_terracotta","minecraft:cyan_terracotta","minecraft:purple_terracotta",
        "minecraft:blue_terracotta","minecraft:brown_terracotta","minecraft:green_terracotta","minecraft:red_terracotta",
        "minecraft:black_terracotta",
        "minecraft:iron_ore","minecraft:deepslate_iron_ore","minecraft:copper_ore","minecraft:deepslate_copper_ore",
        "minecraft:snow","minecraft:snow_block","minecraft:powder_snow"
    );

    protected abstract boolean isStartChunk(CarverConfig config, LegacyRandom random);

    protected abstract boolean carve(
        ChunkColumn col, CarverConfig config, int chunkX, int chunkZ,
        NoiseSettings settings, Aquifer aquifer,
        org.domi.furnace.server.world.BlockRegistry reg,
        CarvingMask mask, LegacyRandom random, ChunkPos originChunk);

    /** Vanilla canReach: dx²+dz² - remaining² ≤ (thickness+18)² */
    protected static boolean canReach(int targetChunkX, int targetChunkZ,
                                       double x, double z, int step, int maxStep, float thickness) {
        double midX = targetChunkX * 16 + 8;
        double midZ = targetChunkZ * 16 + 8;
        double dx = x - midX;
        double dz = z - midZ;
        double remaining = maxStep - step;
        double radius = thickness + 18.0;
        return dx*dx + dz*dz - remaining*remaining <= radius*radius;
    }

    /** Vanilla getCarveState: y≤lavaLevel → lava; else aquifer.computeSubstance(ctx, 0.0) */
    protected int getCarveState(int x, int y, int z, int lavaLevelY, Aquifer aquifer,
                                 int lavaId) {
        if (y <= lavaLevelY) return lavaId;
        return aquifer.computeSubstance(new DensityFunction.SinglePointContext(x, y, z), 0.0);
    }

    /**
     * Carves one block: checks replaceability, gets carved state, sets block.
     * Returns true if carved.
     */
    protected boolean carveBlock(ChunkColumn col, int lx, int y, int lz,
                                  int worldX, int worldZ,
                                  int lavaLevelY, Aquifer aquifer,
                                  CarvingMask mask,
                                  org.domi.furnace.server.world.BlockRegistry reg,
                                  int lavaId, boolean[] isAboveSurface) {
        int current = col.getBlock(lx, y, lz);
        String name = reg.nameOf(current);

        // Track grass/mycelium surface indicator
        if ("minecraft:grass_block".equals(name) || "minecraft:mycelium".equals(name)) {
            isAboveSurface[0] = true;
        }

        if (!REPLACEABLE_NAMES.contains(name)) return false;

        int carved = getCarveState(worldX, y, worldZ, lavaLevelY, aquifer, lavaId);
        // carved == stoneId would mean aquifer says solid here (not possible at density=0)
        // carved == 0 → air, waterId → water, lavaId → lava

        col.setBlock(lx, y, lz, carved);
        mask.set(lx, y, lz);
        return true;
    }

    /**
     * Vanilla carveEllipsoid.
     * hRadius / vRadius already include per-step scaling and multipliers.
     * skipChecker: shouldSkip(relX, relY, relZ, floorLevel) — depends on carver type.
     */
    protected boolean carveEllipsoid(
            ChunkColumn col, int chunkX, int chunkZ, CarverConfig config,
            NoiseSettings settings, Aquifer aquifer,
            org.domi.furnace.server.world.BlockRegistry reg,
            double x, double y, double z, double hRadius, double vRadius,
            CarvingMask mask, SkipChecker skipChecker, int lavaId) {

        int chunkMinX = chunkX * 16;
        int chunkMinZ = chunkZ * 16;
        int chunkMidX = chunkMinX + 8;
        int chunkMidZ = chunkMinZ + 8;

        // Early reject if ellipsoid is too far from chunk
        double distCheck = 16.0 + hRadius * 2.0;
        if (Math.abs(x - chunkMidX) > distCheck || Math.abs(z - chunkMidZ) > distCheck) {
            return false;
        }

        int minY  = settings.minY();
        int lxMin = Math.max(0, (int)Math.floor(x - hRadius) - chunkMinX - 1);
        int lxMax = Math.min(15, (int)Math.floor(x + hRadius) - chunkMinX);
        int lzMin = Math.max(0, (int)Math.floor(z - hRadius) - chunkMinZ - 1);
        int lzMax = Math.min(15, (int)Math.floor(z + hRadius) - chunkMinZ);

        int yMinRaw = (int)Math.floor(y - vRadius) - 1;
        int yMaxRaw = (int)Math.floor(y + vRadius) + 1;
        int yMin = Math.max(minY + 1, yMinRaw);
        // Vanilla subtracts 7 from maxY to avoid carving near sky
        int yMax = Math.min(minY + settings.height() - 1 - 7, yMaxRaw);

        int lavaLevelY = minY + config.lavaLevelAboveBottom();
        boolean carved = false;

        for (int lx = lxMin; lx <= lxMax; lx++) {
            int worldX = chunkMinX + lx;
            double relX = (worldX + 0.5 - x) / hRadius;

            for (int lz = lzMin; lz <= lzMax; lz++) {
                int worldZ = chunkMinZ + lz;
                double relZ = (worldZ + 0.5 - z) / hRadius;

                if (relX * relX + relZ * relZ >= 1.0) continue;

                boolean[] isAboveSurface = {false};

                // Loop Y downward
                for (int by = yMax; by > yMin; by--) {
                    if (mask.get(lx, by, lz)) continue;
                    double relY = (by - 0.5 - y) / vRadius;
                    if (skipChecker.shouldSkip(relX, relY, relZ)) continue;
                    carved |= carveBlock(col, lx, by, lz, worldX, worldZ,
                        lavaLevelY, aquifer, mask, reg, lavaId, isAboveSurface);
                }
            }
        }
        return carved;
    }

    @FunctionalInterface
    protected interface SkipChecker {
        boolean shouldSkip(double relX, double relY, double relZ);
    }

    /** Simple (chunkX, chunkZ) pair for origin chunk position */
    record ChunkPos(int x, int z) {
        int getMiddleBlockX() { return x * 16 + 8; }
        int getMiddleBlockZ() { return z * 16 + 8; }
        int getBlockX(int localX) { return x * 16 + localX; }
        int getBlockZ(int localZ) { return z * 16 + localZ; }
    }
}

// 바닐라 CaveWorldCarver 비트정확 포팅 — worm tunnel + room 알고리즘
package org.domi.furnace.server.world.gen.carver;

import org.domi.furnace.server.world.BlockRegistry;
import org.domi.furnace.server.world.ChunkColumn;
import org.domi.furnace.server.world.gen.Aquifer;
import org.domi.furnace.server.world.gen.NoiseSettings;

public final class CaveWorldCarver extends WorldCarver {

    private static final int RANGE    = 16;
    private static final int MAX_STEP = RANGE * 2 - 1; // 31

    @Override
    public boolean isStartChunk(CarverConfig config, LegacyRandom random) {
        return random.nextFloat() < config.probability();
    }

    @Override
    public boolean carve(ChunkColumn col, CarverConfig config, int chunkX, int chunkZ,
                          NoiseSettings settings, Aquifer aquifer, BlockRegistry reg,
                          CarvingMask mask, LegacyRandom random, ChunkPos originChunk) {
        CarverConfig.Cave cave = (CarverConfig.Cave) config;

        // Count cascade: a=nextInt(15)+1; b=nextInt(a)+1; count=nextInt(b)
        int a     = random.nextInt(15) + 1;
        int b     = random.nextInt(a)  + 1;
        int count = random.nextInt(b);

        int lavaId = reg.defaultStateId("minecraft:lava");

        for (int i = 0; i < count; i++) {
            double startX    = originChunk.getBlockX(random.nextInt(16));
            double startY    = cave.y().sample(random, settings.minY(), settings.height());
            double startZ    = originChunk.getBlockZ(random.nextInt(16));
            double hRadMult  = cave.horizontalRadiusMultiplier().sample(random);
            double vRadMult  = cave.verticalRadiusMultiplier().sample(random);
            double floorLevel = cave.floorLevel().sample(random);

            SkipChecker skipChecker = (relX, relY, relZ) ->
                relY <= floorLevel || relX * relX + relY * relY + relZ * relZ >= 1.0;

            int tunnelCount = 1;
            if (random.nextInt(4) == 0) {
                double yScale      = cave.yScale().sample(random);
                float roomThick    = 1.0f + random.nextFloat() * 6.0f;
                createRoom(col, cave, chunkX, chunkZ, settings, aquifer, reg, mask,
                    startX, startY, startZ, roomThick, (float) yScale, lavaId, skipChecker);
                tunnelCount += random.nextInt(4);
            }

            for (int t = 0; t < tunnelCount; t++) {
                float yaw       = random.nextFloat() * 6.2831855f;
                float pitch     = (random.nextFloat() - 0.5f) / 4.0f;
                float thickness = getThickness(random);
                int maxStep     = MAX_STEP - random.nextInt(MAX_STEP / 4);

                createTunnel(col, cave, chunkX, chunkZ, settings, aquifer, reg,
                    random.nextLong(), startX, startY, startZ,
                    (float) hRadMult, (float) vRadMult, thickness, yaw, pitch,
                    0, maxStep, 1.0f, mask, lavaId, skipChecker);
            }
        }
        return true;
    }

    private float getThickness(LegacyRandom r) {
        float t = r.nextFloat() * 2.0f + r.nextFloat();
        if (r.nextInt(10) == 0) {
            t *= r.nextFloat() * r.nextFloat() * 3.0f + 1.0f;
        }
        return t;
    }

    private void createRoom(ChunkColumn col, CarverConfig.Cave config, int chunkX, int chunkZ,
                             NoiseSettings settings, Aquifer aquifer, BlockRegistry reg,
                             CarvingMask mask,
                             double x, double y, double z, float thickness, float yScale,
                             int lavaId, SkipChecker skipChecker) {
        // hDist = 1.5 + sin(PI/2) * thickness = 1.5 + thickness
        double hDist = 1.5 + thickness;
        double vDist = hDist * yScale;
        carveEllipsoid(col, chunkX, chunkZ, config, settings, aquifer, reg,
            x + 1.0, y, z, hDist, vDist, mask, skipChecker, lavaId);
    }

    private void createTunnel(
            ChunkColumn col, CarverConfig.Cave config, int chunkX, int chunkZ,
            NoiseSettings settings, Aquifer aquifer, BlockRegistry reg,
            long worldSeed, double x, double y, double z,
            float hRadMult, float vRadMult,
            float thickness, float yaw, float pitch,
            int startStep, int maxStep, float yScale,
            CarvingMask mask, int lavaId, SkipChecker skipChecker) {

        // branchRandom = LegacyRandom.create(worldSeed) — vanilla RandomSource.create(long)
        LegacyRandom br = new LegacyRandom(worldSeed);
        int splitStep = br.nextInt(maxStep / 2) + maxStep / 4;
        boolean isThin = br.nextInt(6) == 0;
        float yawDir = 0, pitchDir = 0;

        for (int step = startStep; step < maxStep; step++) {
            float sinStep = (float) Math.sin((float) step * Math.PI / maxStep);
            double hDist  = 1.5 + sinStep * thickness;
            double vDist  = hDist * yScale;

            float cosPitch = (float) Math.cos(pitch);
            x += Math.cos(yaw) * cosPitch;
            y += Math.sin(pitch);
            z += Math.sin(yaw) * cosPitch;

            pitch    *= isThin ? 0.92f : 0.7f;
            pitch    += pitchDir * 0.1f;
            yaw      += yawDir * 0.1f;
            pitchDir *= 0.9f;
            yawDir   *= 0.75f;

            pitchDir += (br.nextFloat() - br.nextFloat()) * br.nextFloat() * 2.0f;
            yawDir   += (br.nextFloat() - br.nextFloat()) * br.nextFloat() * 4.0f;

            if (step == splitStep && thickness > 1.0f) {
                createTunnel(col, config, chunkX, chunkZ, settings, aquifer, reg,
                    br.nextLong(), x, y, z, hRadMult, vRadMult,
                    br.nextFloat() * 0.5f + 0.5f,
                    yaw - (float)(Math.PI / 2), pitch / 3.0f,
                    step, maxStep, 1.0f, mask, lavaId, skipChecker);
                createTunnel(col, config, chunkX, chunkZ, settings, aquifer, reg,
                    br.nextLong(), x, y, z, hRadMult, vRadMult,
                    br.nextFloat() * 0.5f + 0.5f,
                    yaw + (float)(Math.PI / 2), pitch / 3.0f,
                    step, maxStep, 1.0f, mask, lavaId, skipChecker);
                return;
            }

            if (br.nextInt(4) == 0) continue;

            if (!canReach(chunkX, chunkZ, x, z, step, maxStep, thickness)) return;

            carveEllipsoid(col, chunkX, chunkZ, config, settings, aquifer, reg,
                x, y, z,
                hDist * hRadMult, vDist * vRadMult,
                mask, skipChecker, lavaId);
        }
    }
}

```java
// 바닐라 CanyonWorldCarver 포팅 — 협곡 알고리즘 (spline width profile)
package org.domi.furnace.server.world.gen.carver;

import org.domi.furnace.server.world.BlockRegistry;
import org.domi.furnace.server.world.ChunkColumn;
import org.domi.furnace.server.world.gen.Aquifer;
import org.domi.furnace.server.world.gen.NoiseSettings;

public final class CanyonWorldCarver extends WorldCarver {

    private static final int RANGE    = 8;
    private static final int MAX_STEP = RANGE * 2 - 1; // 15; actual steps ~ 15 * 16 = 240

    @Override
    public boolean isStartChunk(CarverConfig config, LegacyRandom random) {
        return random.nextFloat() < config.probability();
    }

    @Override
    public boolean carve(ChunkColumn col, CarverConfig config, int chunkX, int chunkZ,
                          NoiseSettings settings, Aquifer aquifer, BlockRegistry reg,
                          CarvingMask mask, LegacyRandom random, ChunkPos originChunk) {
        CarverConfig.Canyon canyon = (CarverConfig.Canyon) config;

        int lavaId  = reg.defaultStateId("minecraft:lava");

        // Start position
        double startX = originChunk.getBlockX(random.nextInt(16));
        int    startY = canyon.y().sample(random, settings.minY(), settings.height());
        double startZ = originChunk.getBlockZ(random.nextInt(16));

        float  yaw          = random.nextFloat() * 6.2831855f;
        float  vertRot      = canyon.verticalRotation().sample(random);
        float  yScale       = canyon.yScale().sample(random); // constant 3.0f
        float  thickness    = canyon.shapeThickness().sample(random);

        // maxStep: range * 16 for canyon
        int maxStep = (int)((MAX_STEP * 16.0f) * canyon.shapeDistanceFactor().sample(random));

        // Width array: 4 stored widths interpolated via Catmull-Rom spline
        // Vanilla initializes 4 widths with same value, then updates per step
        float[] widths = new float[4];
        for (int i = 0; i < 4; i++) widths[i] = thickness;

        double x = startX, y = startY, z = startZ;
        float yawDir = 0, pitchDir = 0;

        for (int step = 0; step < maxStep; step++) {
            // Shift width array (slide window)
            float w = canyon.shapeHorizontalRadiusFactor().sample(random);
            // Catmull-Rom spline evaluation at t=0.25 for current width
            // Vanilla: width = widths interpolated; for simplicity use linear interpolation
            float hWidth = catmullRomSpline(widths, 0.25f);
            float vWidth = hWidth * yScale;

            // Advance position
            float cosPitch = (float) Math.cos(vertRot);
            x += Math.cos(yaw) * cosPitch;
            y += Math.sin(vertRot);
            z += Math.sin(yaw) * cosPitch;

            vertRot *= 0.7f;
            vertRot += pitchDir * 0.05f;
            yaw     += yawDir * 0.05f;
            pitchDir *= 0.8f;
            yawDir   *= 0.5f;
            pitchDir += (random.nextFloat() - random.nextFloat()) * random.nextFloat() * 2.0f;
            yawDir   += (random.nextFloat() - random.nextFloat()) * random.nextFloat() * 4.0f;

            // Update width array
            widths[0] = widths[1];
            widths[1] = widths[2];
            widths[2] = widths[3];
            widths[3] = w; // sample new width

            if (!canReach(chunkX, chunkZ, x, z, step, maxStep, thickness)) return true;

            // Canyon skip: only check horizontal ellipse
            SkipChecker skipChecker = (relX, relY, relZ) -> relX * relX + relZ * relZ >= 1.0;

            // Canyon vertical shape: full height (relY not clamped by floor)
            carveEllipsoid(col, chunkX, chunkZ, canyon, settings, aquifer, reg,
                x, y, z, hWidth, vWidth, mask, skipChecker, lavaId);
        }
        return true;
    }

    private static float catmullRomSpline(float[] p, float t) {
        // Catmull-Rom: p[0]..p[3], evaluate at t (0..1)
        float t2 = t * t, t3 = t2 * t;
        return 0.5f * (
            2 * p[1] +
            (-p[0] + p[2]) * t +
            (2 * p[0] - 5 * p[1] + 4 * p[2] - p[3]) * t2 +
            (-p[0] + 3 * p[1] - 3 * p[2] + p[3]) * t3
        );
    }
}
```

**Note:** The canyon algorithm above is a first approximation. The vanilla canyon algorithm is complex (multiple width samples per step, specific Catmull-Rom evaluation). If parity tests show mismatches, read the `CanyonWorldCarver` bytecode more carefully and port exactly. The cave carver parity will catch more issues; canyon issues will show up in the fixture comparison.
