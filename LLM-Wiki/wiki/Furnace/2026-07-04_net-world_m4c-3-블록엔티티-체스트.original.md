# 2026-07-04 net·world — M4c-3 블록엔티티 코어 + 체스트 컨테이너

## 작업 요약
블록엔티티 인프라(청크 저장·전송) + 싱글체스트 컨테이너 UI(creative). 커밋 0d7d7c5(코어), 2051765(체스트).

## 문제 / 목적
청크 패킷 blockEntityCount=0 하드코딩, Anvil block_entities 미구현, 컨테이너 상호작용 전무. M4c-3 = 코어+체스트(사용자 범위 결정, 사인·화로 제외).

## 해결 방법 / 구현 내용
**코어(0d7d7c5)**: ChestBlockEntity({x,y,z, ItemStack[27]} 순수 홀더 — 다형 레지스트리 안 만듦), ChunkColumn blockEntities 맵, ChunkSnapshot BlockEntitySnapshot 카피, ChunkSerializer `[byte packedXZ][short y][VarInt typeId=1][NBT|TAG_END]` 배열 write, NbtWriter.writeCompound(네트워크 무명 root), AnvilChunkCodec block_entities 왕복.

**체스트(2051765)**: 0x38 Use Item On에 열기 분기(region 스레드서 getBlock 판별 → netty 복귀 — 스레드 소유 준수로 왕복 2회), OpenScreen 0x33(GENERIC_9x3=2)+ContainerSetContent 0x13(체스트 27 + 플레이어 slots[9..44] 36), Container Click 0x0E는 changedSlots 클라 예측 그대로 수용(PICKUP만), Close 0x0F. breakBlock 시 엔티티 제거+열림 세션 강제닫기(same-region 한정). 아이템 변경 → ChunkColumn.markDirty → saveDirtyChunks 영속.

## 핵심 함정 (중요)
- **paperweight v2 캐시 vanillaServer.jar = 1.21.4** — 이걸로 datagen 돌리면 틀린 패킷 id(open_screen 0x35 등). 공식 Mojang 1.21.1 server.jar 재다운로드 후 `--reports`로 재생성. **기존 실측 id(client_information 0x0A, use_item_on 0x38)와 교차검증 필수**. 정본 = tasks/m4c-3-blockentity/sources/packets-1.21.1.json.
- M4c-2 components opaque blob trick은 0x32(Slot 단일) 전용 — Container Set Content/Click은 다중 Slot이라 무효. M4c-3은 component 없는 아이템만 처리, component 있으면 Click 패킷 전체 폐기(경계 파싱 불가).

## 알려진 제약
더블체스트·열림 애니메이션·QUICK_MOVE·stateId 재동기화 미구현. 강제닫기 same-region 한정. 실클라 수동 검증 잔여(sonnet-chest result.md 8단계 절차).
