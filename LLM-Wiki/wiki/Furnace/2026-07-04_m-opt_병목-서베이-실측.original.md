# 2026-07-04 M-opt — 병목 전수 서베이 + 실측

## 작업 요약
4영역(생성·로딩·캐싱·전송) 병목 조사 + ChunkGenBenchmark 실측. 우선순위 확정. 코드 무변경(조사만). 정본 = tasks/m-opt-survey/workers/sonnet-survey/result.md.

## 실측 (JDK 26 주의 — 명세 Java 21, 상대 비중 중심)
- generate() 42ms/청크 (두 에이전트 독립 재실행 39~42ms 일치). 시야 10(441청크) 단일스레드 환산 18.5초.
- generateBlockIds(density+aquifer) **19ms 최대 병목**. buildSurface **10ms 2위**. construct 1ms, ChunkColumn fill 1ms, biome 2ms.
- stoneMask 셀 스킵 90% 유효(4ms). aquifer/OreVeinifier 개별 compute ≈15ms(차분 추정).

## 확정 병목 (실독)
- `NoiseWorldSource.worldSurfaceHeightAt:407` — 높이 조회 1회 = 청크 전체 재생성(42ms). 캐시 없음("캐시는 S3+" 주석 자인).
- `NoiseWorldSource.collectNeighborBiomes:458` — decorate마다 이웃 9청크 재샘플, proto.biomeIds와 중복.
- `ChunkSection.blocks():77` — 매 호출 16KB 신규 할당. 스냅샷 1회 ≈384KB.
- `ChunkColumn.setBlock:70` — 블록 1개마다 캐시 3종 무효화. 로드 경로 4096×24회.
- `ChunkSerializer:51` — 상수 스카이라이트 2048B×26 매 전송 재할당.
- `RegionFile` — 섹터 회수 없음(append-only 무한 증가), region 단위 락.

## 우선순위 확정
- **P0**: generateBlockIds(aquifer) 출력 불변 최적화 · buildSurface 정밀 분석(후속 서베이) · 스카이라이트 static final 캐시.
- **P1**: worldSurfaceHeightAt 캐시 · PaletteStorage 선형탐색(생성 경로 실측 1ms라 하향, 로드 경로는 미측정) · fromNbt setBlock→setGeneratedBlock(wgOceanFloor 의존 추적 선행 — [[2026-07-04_worldgen_wgOceanFloor-라이브갱신-심층발산-해소]] 참조) · CompressionEncoder 버퍼 재사용.
- **P2**: RegionFile compaction · 락 세분화 · buildClimateCache(실측 1ms라 하향).
- 불가침: worldgen byte-exact parity — RNG 소비 순서·블록 출력·heightmap 게이팅 불변 수단만.
