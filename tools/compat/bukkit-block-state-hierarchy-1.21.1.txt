# Bukkit(Paper 1.21.1) 블록 엔티티 종류 → CraftBukkit 블록 상태 클래스 → 인터페이스, 그리고 블록 상태 인터페이스 상위 형식.
# 출처: Paper 1.21.1 CraftBlockStates 등록표·Craft*State 클래스 선언과 paper-api 인터페이스 선언(Youer 1.21.1 사본). 이름·계층만 옮겼다.
# 'T <블록 엔티티 종류> <Craft 클래스> <상위 Craft 클래스> <인터페이스>' / 'A <추상 Craft 클래스> <상위 Craft 클래스> <인터페이스...>' / 'I <인터페이스> <상위...>'.
# 뺀 상위 형(아직 메서드를 구현하지 않아 표시 인터페이스로 둘 수 없다): TileState 의 PersistentDataHolder,
#   Lootable 류의 PaperLootableBlockInventory. (TileStateInventoryHolder 는 손으로 써서 BlockInventoryHolder 를 넓힌다.)
# 손으로 쓴 인터페이스·클래스(머리말 없음)는 생성기가 건드리지 않는다: BlockState·BrewingStand·Sign·CraftBrewingStand 등.
